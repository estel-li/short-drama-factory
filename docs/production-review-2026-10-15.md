## 运行与升级

工作台自启的引擎使用 `data/comfy-runtime/` 保存 input、output、user、temp 和 cache，Python 临时目录及 Numba 缓存也在工作台 `data/` 下。缓存节点由应用随包目录复制到专用运行目录，不要求改写已有 ComfyUI 的 custom_nodes。

手动启动的外部 ComfyUI 保留它自己的路径与节点配置。连接该服务时须有兼容的短剧缓存节点及可写输出目录。升级后的客户端通过 API 读写素材和视频。

应用代码升级不修改认证信息、项目和模型权重。旧版本完整镜头继续可用；缓存目录改变时，缺失的条件/潜空间缓存会在需要时重新生成。

## 本轮验证边界

本轮验证了真实单镜生成和多镜依赖的回归测试，没有进行多小时连续 GPU 压力测试，也没有取得其他计算机上的 18 镜 v5/v6/v7 素材。真实批量生产仍应先验看代表性镜头，再检查人物一致性、台词字词、跳切和遮罩。VAD 检测不等于逐字识别，密集审核图不等于 OCR。

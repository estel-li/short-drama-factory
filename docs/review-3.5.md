# 3.5.0 工作流审查与改进

审查范围：`bae81cf`（3.2.0，高级 H3 工作流与多模型生图）和 `2aabbca`（3.3.0，五类媒体工作流）。本次聚焦代码可靠性、参数交互、任务恢复与本机资源开销。

| --- | --- | --- |

## 用户可见变化

工作流选择下方显示用途、开销、模式与素材要求。分镜里突出必需槽位，未上传素材时给出入口提示；不兼容模式不能新选入，高级媒体方案不再允许打开旧首帧接续开关。已保存的冲突设置仍可见并可修正，不悄悄删除素材。

准备资源保留确认下载、断点与暂停功能；“已就绪”指工作流附加资源，基础 H3 模型仍须在环境页核对。自定义参数另存为独立方案，保存项目设置后使用。

## 验证方法与限制

- 完整离线后端测试、前端测试、Python 编译检查。
- 专项回归覆盖 Ref2VA 混合媒体图、源帧数与偏移、接续上限、损坏／嵌套模型、插件复用、暂停和进度恢复、部分采样参数覆盖。
- `tests/h3_media_probe.py --comfy-dir PATH` 在具备 ComfyUI 依赖的 Python 中使用合成小视频和音轨验证真实解码与音频锁定；不加载模型或访问网络。
- 浏览器检查工作流卡片、合法参数保存、阈值错误、刷新恢复进度、必需素材提示及窄屏布局。
- 便携包校验压缩内容、密钥排除和独立 Python 启动。

本次修复验证不代表所有模型在所有参数下的视觉质量保证。已有 3.2 / 3.3 的真实 GPU 样片可作历史参考；3.5 的新媒体读取与输入组合回归主要验证管线、数据与交互。用户正式片段仍需审片，尤其是口型、身份漂移与声音接续。

## 升级与 AI 入口

新版随包节点增加 `DramaH3VideoSource`。工作台管理的空闲 ComfyUI 可在准备工作流时加载更新；手动启动或远程 ComfyUI 应由其所有者更新随包节点并重启。保留配置、素材、项目与模型目录，升级前退出旧工作台再覆盖应用文件。

[完整工作流选择指南](../agent-skills/short-drama-factory/references/workflow-selection.md) 是 AI 选择方案的入口；[Skill](../agent-skills/short-drama-factory/SKILL.md) 说明完整执行流程。接口提供 `GET /api/video/workflows`，供 AI 核对实际能力，不把文档里的静态名称当作环境已准备完成。

## 产品契约

- 当前 AI 默认负责创作，工厂负责校验、执行和产物管理；内部文字生成保留为显式选项。
- 新的严格操作接口不得隐式调用文字模型。旧接口维持兼容并明确副作用。
- 创建草稿、计算执行计划与提交生成是不同操作；高层命令可按用户已授权范围组合它们。
- 计划包含版本、镜头依赖、缓存、文字/GPU/下载工作及阻塞项；执行校验目标版本。
- 幂等键在断线与重启后可取回原结果；相同键不同请求拒绝。不以重发推理掩盖未知提交结果。
- 编辑按稳定 UID 和项目版本执行；旧版本冲突不能静默覆盖。
- 单任务查询和事件不受最近 100 条窗口限制；完成文字阶段不等于可交付视频。
- 工具返回错误码、字段、可执行下一步；不要求打开工作台排错，不输出凭证或原始验证输入。
- 图形工作台、CLI 与可选工具适配共用后端，不分别实现业务规则。
- 交付分别记录媒体完整性、画面和台词验收；没有证据的检查标为未验证。

## 发布门槛

1. 隔离 HTTP 测试覆盖超过 100 条任务、丢失响应、并发编辑、严格零文字调用和跨会话恢复。
2. 镜头范围与连续依赖测试；只改字幕时间保留生成原片，修改台词使相关生成失效。
3. CLI 从复制出的独立技能目录执行，不依赖应用源码导入。
4. 诊断不启动生成；缺模型返回准备信息；服务启动恢复策略可明确选择。
5. 产物清单核对实际文件、版本、哈希、审核图与未验收项。
6. 请求模板、Schema、路由与文档一致；全部离线 Python 和前端回归通过。
7. 每阶段版本与提交独立；最终 4.0.0 的远端提交与本地一致。

真实推理的质量与性能测试使用另行明确授权的 GPU/API 验证；离线契约测试不能替代内容审片。

## 3.7.0 验证记录

2026-10-22：阶段内 246 项 Python 离线回归及 18 项前端测试通过（同次发现运行另含 6 项下一阶段策略模块测试，合计 252）。覆盖精确旧任务查询、结构化错误、只读诊断、独立技能目录 CLI 与既有制作契约。未启动真实生成。

## 3.8.0 验证记录

2026-10-22：335 项 Python 离线测试与 18 项前端测试通过。新增 HTTP 幂等/冲突/丢失回执恢复、真正的 Runner 范围与缓存执行、供应商及下载边界、服务仅启动 API、冻结计划与暂停检查点测试。已验证目录发布后回执失败、编辑完成后回执失败、入队后唤醒失败均可取回原操作。

硬崩溃后若实际产物变化而检查点未保存，原任务返回计划失效；先检查原项目，再重新计划并以新请求键提交，复用已确认缓存。正常暂停支持原任务 ID 续跑。

## 3.9.0 验证记录

2026-10-22：383 项 Python 离线测试、18 项前端测试与技能校验通过。覆盖复制至独立目录的任务 CLI、断线账本与重试限制、无界面配置/凭证、图片/素材幂等、模型默认参数、纯提示词编译和离线安装升级。派生 OpenAPI 契约与实际路由一致。

独立前向干运行采用“断网后仅有请求键、保留原声并接续两个镜头”的场景；补清本地账本丢失后的恢复边界，以及高级原声工作流需显式末帧、手动派生素材没有自动来源依赖的组合流程。没有连接用户的生产项目。

## 4.0.0 交付与发布记录

实现只读交付清单及专用产物下载、当前成片完整解码、版本来源与哈希核对；CLI 提供 deliver 取片和 batch 逐项目提交。批次部分失败不回滚已接受项目，未知结果仅显式补交。技术交付与画面／台词／字幕内容验收分开记录。

2026-10-23：最终源码通过 421 项 Python 离线测试、18 项前端测试，均无跳过；Skill 校验、派生 OpenAPI 一致性和源码编译检查通过。独立技能 ZIP 的 25 个文件与最终技能源码逐字节一致；安装副本的 48 个本地引用均留在技能包内。

最后独立审查修复了异常退出后任务永久 busy，以及局部文字规划超范围编译的问题。全部验证均使用隔离数据、模拟供应商或 CPU 测试媒体，没有调用用户的生产模型或修改生产项目；这些证据不替代实际生成内容的审片。

发布收尾同时复现并修正 Windows CI 的 8.3 临时路径别名比较、Python 3.13 的 HTTP 默认描述差异，以及嵌入版 Python 缺少脚本目录造成的 CLI 相邻模块导入失败。保留原检查强度，新增标准描述变化下的严格契约回归和隔离解释器执行独立 CLI 的回归；便携 Python 3.13.16 的 32 个依赖版本与锁定清单一致。

# 架构说明

## 组件

浏览器通过 HTTP 调用 FastAPI。Pydantic 校验输入和产物，SQLite 保存索引及持久队列，单工作线程按顺序执行文字规划与 GPU 渲染。前端使用原生 ES 模块，不需要额外前端构建链。

`app/content.py` 编排文字提供商、Skill、JSON schema、格式校验和重试；`app/projects.py` 保存分镜、稳定镜头身份、版本及设置。`app/jobs.py` 编排阶段、暂停与恢复。`pipeline.py` 负责 ComfyUI 图、缓存与媒体生成，`app/continuity.py` 负责首帧规则和真实末帧。

## 生成阶段

大纲 → 分镜 → H3 提示词 → 条件编码 → 音画潜空间采样 → 音画解码 → 合片与字幕。文字阶段可分别检查。条件和潜空间保存为 ComfyUI 缓存文件，阶段之间释放驻留模型。

镜头顺序执行；首帧依赖只指向紧邻前镜，因此没有循环依赖。模型、提示词、实际素材摘要、种子和图参数参与缓存判断。首帧镜头额外纳入源视频和源镜头身份。

## 数据

`config/` 保存公开应用设置，`.secrets/` 保存凭证，`data/` 保存数据库、下载和安装状态，`projects/` 保存独立项目。每个项目包含原输入、分镜、阶段请求、素材、镜头片段、缓存状态、历史和最终视频。

分集项目保留本集上下文，共享整剧角色与场景设定。文字分镜每批最多六镜；整剧规划按批保存。停止或重启后以持久任务及已校验产物恢复。

## 范围

工作台只监听本地回环地址，不提供公网用户认证系统。从零安装支持 Windows x64 + NVIDIA；已有推理环境的依赖不会被自动重装。远程 ComfyUI 需要缓存节点和适当认证。

独立配音、统一配乐、ASR 时间轴、多人身份分离和剪辑工程导出目前不在实现范围。视频模型输出质量由实际模型、提示词、素材和硬件决定。

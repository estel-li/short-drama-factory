# 图片生成与项目参考图（3.0.1）

创作空间新增“图片生成”独立页面，也可直接访问 `http://127.0.0.1:8765/#images`。通过 ComfyUI 在本机运行 Qwen-Image 2.1，图片与视频共用工作台串行队列，关闭网页不影响已排队任务。

## 自然语言生图

1. 输入想看到的画面，选择用途、画幅与风格。
2. “优化提示词”默认选中。先优化、编辑结果再生成，会继续同一张图片记录和同一任务 ID；不会新增一张空任务卡。取消勾选则直接使用原描述。明确填写的优化结果会被直接使用，不再调用文字模型。优化处理中生成按钮暂不可用，完成后可以继续；从历史中“载入参数”也能继续尚未采样的任务。
3. 高级设置可选择 DeepSeek、本地 Ollama／LM Studio 或兼容服务，选择图片 Skill、尺寸档、随机种子及透明背景。“保存为图片默认设置”供后续图片和项目流程沿用。
4. 点击生成后查看准备、优化及生成状态。每次重新生成都有新记录，原图、提示词、模型方案和种子保留。下载为 PNG；透明背景是生成要求，实际是否产生透明区域以输出为准。
5. 不满意的图片可点击“删除”，确认后移除图片库中的原图、工作流与提示词记录。正在执行的图片需先停止并等候结束。项目已采用的素材是独立副本，仍保留其引用和历史版本；删除不会破坏已有分镜。

提供 4 个可编辑的图片提示词 Skill：自由创作、角色、场景、道具。它们属于 `image_prompt` 阶段，在“Skill 与预设”中编辑、复制或导入。优化会将输入发送给所选文字提供商；选择本地提供商时可在本机完成全部流程。

## 参考图与图生图（3.1.0）

打开“参考图 / 图生图”，上传 PNG、JPEG 或 WebP，每张最多 8MB、最多 10 张。上传后可预览、移除或上移，顺序对应提示词里的 `<image1>`、`<image2>`。16GB 显存先用 1～3 张、512 或 768 档。程序会纠正 EXIF 方向、去除图片元数据并转成 PNG，过大的像素尺寸会缩小。

- **参考图创作**：提取人物、服装、场景或风格参考，按所选画幅生成新画面。例如“保留 `<image1>` 的角色身份，服装参考 `<image2>`，站在雨后小巷中”。
- **编辑原图**：第一张是要编辑的原图，其余为辅助参考，沿用第一张图的比例；尺寸档仍可选。例如“将 `<image1>` 中的衣服改成红色，其他区域保持”。这使用原生图像条件，遵循编辑指令的程度取决于模型输出，并非逐像素锁定。

图片库的“用作参考图”会复制成独立输入，删除原成图也不会破坏已经创建的参考。每个任务还保存自己的参考快照；历史记录可以查看生成依据、载入参数、继续原任务或重新生成。改变参考图或参考方式时，旧优化提示词会清空，避免继续使用不相符的图片编号。

参考图会上传到配置的 ComfyUI 图片服务（包括用户选择的远程地址）；文字优化仅接收文字、参考张数和模式，不发送参考图本身。现有 Qwen-Image 2.1 模型即可运行，无需额外下载。实现依据：[ComfyUI 官方图片编辑工作流](https://github.com/Comfy-Org/workflow_templates/blob/main/templates/image_qwen_image_2_1_image_edit.json)。

## 显存、模型与环境

优先读取目标 ComfyUI 的显卡信息，不能用工作台电脑的显存推断远程 GPU。独立本地引擎尚未启动时读取本机显卡作为安装建议。

| 检测结果 | 默认建议 |
| --- | --- |
| 显存未知 | Turbo INT8 + W4A8 编码器、768 档 |
| 低于 12GB | 同上、512 档，需要内存卸载，须实际验证 |
| 12GB～不足 40GB | Turbo INT8 + W4A8 编码器、1024 档 |
| 40GB 及以上 | Turbo BF16 + BF16 编码器、1536 档 |

建议可覆盖，不保证所有硬件都能分配指定尺寸。1024 档按画幅换算面积并对齐到 32 像素，并非固定宽度 1024。Turbo 默认使用官方八段 sigma 与 Euler/CFG 1；标准 INT8 方案默认使用 40 步。

## 高级采样参数（3.1.1）

图片工作室展开“高级采样参数”，可以调整下列选项。与 ComfyUI 原生采样节点对应，文生图、参考创作及编辑原图共用；重绘强度仅编辑原图可用。

| 选项 | 默认与范围 | 作用 |
| --- | --- | --- |
| 采样步数 steps | 留空：Turbo 8 / 标准 40；1～100 | 控制迭代步数；更多步数增加耗时，不保证质量提升 |
| 提示词引导 CFG | 1；1～20 | 大于 1 时启用负面条件引导，增加计算量 |
| 采样器 sampler | euler | 可选 euler_ancestral、heun、dpmpp_2m、dpmpp_2m_sde、dpmpp_sde、uni_pc |
| 调度器 scheduler | auto | 可选 simple、normal、karras、exponential、sgm_uniform、beta |
| 重绘强度 denoise | 1；0.05～1 | 编辑原图时，小于 1 从第一张原图加噪重绘，越低通常保留越多；1 沿用模型原生参考编辑 |
| 负面提示词 | 空，最多 4000 字 | CFG 大于 1 时参与引导；CFG 为 1 时不生效 |

Turbo 在 8 步、auto 调度、重绘强度 1 时保持官方 sigma 序列；修改步数、显式选择调度器或降低强度后使用 `BasicScheduler`，auto 此时解析为 simple。标准模型使用 `KSampler`。重绘强度低于 1 时，两种模型都通过 `ImageScale → VAEEncode` 从第一张原图初始化潜空间，编码尺寸与参考编辑尺寸一致。强度是加噪比例，不是“人物相似度”或逐像素锁定；步数仍为实际采样步数。

“恢复模型推荐参数”恢复空步数、CFG 1、Euler、auto、强度 1、空负面词。“保存为图片默认设置”保存当前采样参数；后续任务读取并保存自己的副本，修改默认值不会改变已创建任务。改变采样参数不会清空已优化的文字，也不会重复创建未采样任务。历史记录显示实际参数，可载入继续修改或新建版本。

项目素材的角色／场景／道具卡片有“本项高级采样参数”：默认继承图片工作室，可取消继承并保存独立配置；修改未保存时暂停生成按钮，避免使用旧配置。单项、批量和自动补齐均读取已保存参数，随项目迁移。更改独立参数后，自动补齐会更新对应输出；更改全局默认不会重做已采用图片。目标服务缺少所选采样器、调度器或节点时会明确报错，不静默换成其他参数。

缺少模型时，点击生成或“下载缺少的文件”会先显示确认框，列出文件、预计大小和目标目录。“暂不下载”不会启动下载，也不会创建新的图片任务。确认后打开进度小窗口，显示当前文件、百分比及已下载／总大小；可暂停，也可关窗让任务在后台继续，再通过“查看准备进度”打开。本地校验过的模型直接复用，无需下载确认；无校验记录的现有模型先校验，失败才要求确认修复下载。Turbo INT8 三个模型约 14.24GB（13.27GiB）；固定 Hugging Face 提交、大小与 SHA256 校验，下载中断可恢复。旧版 `auto_download:true` 不会绕过确认。

高级设置中的主模型、文本编码器和 VAE 下拉框，会列出目标 ComfyUI 已识别的文件及本地模型目录里的 safetensors 文件。可以分别选择并保存为默认设置；留空使用推荐文件。必须是 Qwen-Image 2.1 兼容组合，其他架构不支持直接套用该工作流。已知官方主模型会自动匹配 Turbo／标准方案；自行转换的文件应选择对应采样方案。文件已在目录但服务尚未识别时，可准备独立引擎，或重启自己管理的已有服务。

- **自动引擎**：已有 ComfyUI 支持 Qwen-Image 2.1 时复用；本地服务过旧时准备独立图片引擎，默认端口 8190。
- **独立引擎**：使用固定 ComfyUI 源码，创建独立 Python 环境，优先复用已有推理 Python 的 PyTorch，依赖更新安装在新环境中。
- **尚无推理环境**：Windows 下下载固定官方 ComfyUI 便携运行时作为独立 GPU Python，再运行固定新版源码；不要求先下载 H3 视频模型。仍需用户安装可用的 NVIDIA 驱动，并准备运行时下载和解压空间。
- **已有／远程图片服务**：可填写单独地址。远程缺失文件需在远端安装；本地自定义地址需填写该服务真正扫描的模型目录。

Qwen-Image 2.1 权重采用非商用研究许可，商业用途需要模型方授权。[官方模型仓库](https://github.com/QwenLM/Qwen-Image-2.1) · [模型许可](https://huggingface.co/Qwen/Qwen-Image-2.1/blob/main/LICENSE)。工作台应用代码的 MIT 协议不替代模型许可。

## 让短剧自动生成角色与场景

新建故事或项目设置中，打开“用本地模型生成参考图”，选择角色、场景及可选道具。默认关闭自动参考图生成功能，避免旧项目产生额外 GPU 任务；图片提示词优化默认开启。

分镜确认后，继续流程会先准备参考图，再生成 H3 提示词。即使执行的是文字规划，启用该选项后也会包含图片生成。已有手动人物图优先保留；场景图不会标为人物身份。

从项目素材页生成参考图时同样先确认缺失模型下载；全自动脚本阶段若首次遇到未授权的缺失模型，会保留项目并暂停，提示到图片生成页确认准备，之后继续原项目即可。

“素材”页会列出本项目角色、场景、道具，支持编辑描述、单项生成并采用、重新生成、采用历史版本。保存分镜／设置后才能操作；项目忙碌期间不改引用。生成的角色图只绑定包含该角色的镜头，场景图按场景匹配，空镜不带入人物参考。更换参考图会使受影响提示词及视频缓存按原有规则更新，锁定镜头仍需解锁。

3.1.0 起，各卡片的“自定义图片参考”可上传角色照片、设定图，或选择项目已有图片。选择、顺序和参考方式自动保存，供单项、批量及后续自动补齐流程使用。上传图是生成依据，生成并采用的新图才是输出版本；源图仍作为普通项目素材保留。修改依据后，自动补齐会重新生成对应参考图；不修改时复用已采用版本。配置和源图随项目迁移包一起保存。

使用图片参考生成 H3 视频时，选择自动或 Ref2VA。手动选定 T2VA 时不使用参考图片；首帧接续仍按原规则采用前镜实际末帧。关闭自动生成不会删除此前已采用的图片。

项目迁移包会携带参考图素材、版本选择与历史映射。导入到另一台电脑后可继续采用已保存的历史参考图；独立图片工作室的全部图片库不随单项目迁移，原始图片可另行下载。

## 任务恢复与数据

- 每个图片任务先保存自己的 ComfyUI prompt_id 再提交。恢复会核对该任务的队列和历史；提交结果不明时提示人工核对，不自动重复生成。
- 停止只请求取消当前图片拥有的任务。点击旧图片的操作不会停止同项目正在运行的其他任务。
- 优化失败会显示错误；可换提供商、编辑优化结果或关闭优化后生成，不静默替换用户提示词。
- 原图和请求在 `data/image-studio/<id>/`；项目参考版本在 `reference-images.json`，参考 PNG 在项目 `assets/`。
- 独立引擎在 `engines/qwen-comfy-*`；模型默认在 `models/qwen-image-2.1`；日志为 `logs/image-engine-install.log` 和 `logs/image-engine.log`。

真实验证记录：RTX 5060 Ti 16GB 已完成 Turbo INT8/W4A8 的 512 档单图，以及 1024 档角色＋场景自动生成、绑定与 H3 提示词编译。其他显卡和从零运行时路径需要在对应环境验证；不能把一次实测耗时当作通用速度保证。

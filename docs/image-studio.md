# 图片生成与项目参考图（3.0.0）

创作空间新增“图片生成”独立页面，也可直接访问 `http://127.0.0.1:8765/#images`。通过 ComfyUI 在本机运行 Qwen-Image 2.1，图片与视频共用工作台串行队列，关闭网页不影响已排队任务。

## 自然语言生图

1. 输入想看到的画面，选择用途、画幅与风格。
2. “优化提示词”默认选中。可以先优化、编辑结果再生成；取消勾选则直接使用原描述。明确填写的优化结果会被直接使用，不再调用文字模型。
3. 高级设置可选择 DeepSeek、本地 Ollama／LM Studio 或兼容服务，选择图片 Skill、尺寸档、随机种子及透明背景。“保存为图片默认设置”供后续图片和项目流程沿用。
4. 点击生成后查看准备、优化及生成状态。每次重新生成都有新记录，原图、提示词、模型方案和种子保留。下载为 PNG；透明背景是生成要求，实际是否产生透明区域以输出为准。

提供 4 个可编辑的图片提示词 Skill：自由创作、角色、场景、道具。它们属于 `image_prompt` 阶段，在“Skill 与预设”中编辑、复制或导入。优化会将输入发送给所选文字提供商；选择本地提供商时可在本机完成全部流程。

## 显存、模型与环境

优先读取目标 ComfyUI 的显卡信息，不能用工作台电脑的显存推断远程 GPU。独立本地引擎尚未启动时读取本机显卡作为安装建议。

| 检测结果 | 默认建议 |
| --- | --- |
| 显存未知 | Turbo INT8 + W4A8 编码器、768 档 |
| 低于 12GB | 同上、512 档，需要内存卸载，须实际验证 |
| 12GB～不足 40GB | Turbo INT8 + W4A8 编码器、1024 档 |
| 40GB 及以上 | Turbo BF16 + BF16 编码器、1536 档 |

建议可覆盖，不保证所有硬件都能分配指定尺寸。1024 档按画幅换算面积并对齐到 32 像素，并非固定宽度 1024。Turbo 使用官方八段 sigma 与 Euler/CFG 1；标准 INT8 方案使用 40 步。

缺少模型时可以“准备 / 继续下载”，或保留默认开启的自动准备。Turbo INT8 三个模型约 14.24GB（13.27GiB）；使用固定 Hugging Face 提交、文件大小和 SHA256 校验，下载中断可恢复。已有服务中可用的同名模型会复用。

- **自动引擎**：已有 ComfyUI 支持 Qwen-Image 2.1 时复用；本地服务过旧时准备独立图片引擎，默认端口 8190。
- **独立引擎**：使用固定 ComfyUI 源码，创建独立 Python 环境，优先复用已有推理 Python 的 PyTorch，依赖更新安装在新环境中。
- **尚无推理环境**：Windows 下下载固定官方 ComfyUI 便携运行时作为独立 GPU Python，再运行固定新版源码；不要求先下载 H3 视频模型。仍需用户安装可用的 NVIDIA 驱动，并准备运行时下载和解压空间。
- **已有／远程图片服务**：可填写单独地址。远程缺失文件需在远端安装；本地自定义地址需填写该服务真正扫描的模型目录。

Qwen-Image 2.1 权重采用非商用研究许可，商业用途需要模型方授权。[官方模型仓库](https://github.com/QwenLM/Qwen-Image-2.1) · [模型许可](https://huggingface.co/Qwen/Qwen-Image-2.1/blob/main/LICENSE)。工作台应用代码的 MIT 协议不替代模型许可。

## 让短剧自动生成角色与场景

新建故事或项目设置中，打开“用本地模型生成参考图”，选择角色、场景及可选道具。默认关闭自动参考图生成功能，避免旧项目产生额外 GPU 任务；图片提示词优化默认开启。

分镜确认后，继续流程会先准备参考图，再生成 H3 提示词。即使执行的是文字规划，启用该选项后也会包含图片生成。已有手动人物图优先保留；场景图不会标为人物身份。

“素材”页会列出本项目角色、场景、道具，支持编辑描述、单项生成并采用、重新生成、采用历史版本。保存分镜／设置后才能操作；项目忙碌期间不改引用。生成的角色图只绑定包含该角色的镜头，场景图按场景匹配，空镜不带入人物参考。更换参考图会使受影响提示词及视频缓存按原有规则更新，锁定镜头仍需解锁。

使用图片参考生成 H3 视频时，选择自动或 Ref2VA。手动选定 T2VA 时不使用参考图片；首帧接续仍按原规则采用前镜实际末帧。关闭自动生成不会删除此前已采用的图片。

项目迁移包会携带参考图素材、版本选择与历史映射。导入到另一台电脑后可继续采用已保存的历史参考图；独立图片工作室的全部图片库不随单项目迁移，原始图片可另行下载。

## 任务恢复与数据

- 每个图片任务先保存自己的 ComfyUI prompt_id 再提交。恢复会核对该任务的队列和历史；提交结果不明时提示人工核对，不自动重复生成。
- 停止只请求取消当前图片拥有的任务。点击旧图片的操作不会停止同项目正在运行的其他任务。
- 优化失败会显示错误；可换提供商、编辑优化结果或关闭优化后生成，不静默替换用户提示词。
- 原图和请求在 `data/image-studio/<id>/`；项目参考版本在 `reference-images.json`，参考 PNG 在项目 `assets/`。
- 独立引擎在 `engines/qwen-comfy-*`；模型默认在 `models/qwen-image-2.1`；日志为 `logs/image-engine-install.log` 和 `logs/image-engine.log`。

真实验证记录：RTX 5060 Ti 16GB 已完成 Turbo INT8/W4A8 的 512 档单图，以及 1024 档角色＋场景自动生成、绑定与 H3 提示词编译。其他显卡和从零运行时路径需要在对应环境验证；不能把一次实测耗时当作通用速度保证。

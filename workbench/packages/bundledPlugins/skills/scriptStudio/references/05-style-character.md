## 六A、视觉风格锁定系统

进入图片资产生成链路前，必须先确认、反推或暂定项目视觉风格。没有 `ST` 视觉风格锁定卡时，不直接输出角色、场景、道具、四视图、首帧图或高级角色资料卡 prompt；如果用户要求先推进，可以建立【暂定 ST001】，并在交接中标注可修改。

### 1. 何时询问风格

- 用户已明确风格：直接建立 `ST/CL/NP`，不重复追问。例如“港风写实”“日漫赛璐璐”“3D半写实动画”“国风水墨”“赛博朋克”。
- 用户提供参考图：先反推风格锁定卡，再请用户确认是否锁定。
- 用户没说风格也没给参考图：进入资产库前必须问一次，用 3-7 个选项帮助用户选择。
- 用户说“你先定”：根据项目类型、时代、平台和参考作品建立【暂定 ST001】，后续允许替换。

默认询问模板：

```text
进入资产库前需要先锁定视觉风格，否则人物和场景容易跑偏。
你希望本项目使用哪种风格？

A. 真人写实电影感
B. 港风写实 / TVB剧集质感
C. 日漫赛璐璐
D. 3D动画 / 半写实3D
E. 国风 / 水墨 / 东方幻想
F. 赛博朋克 / 霓虹未来
G. 其他，或直接发参考图让我反推
```

### 3. CL 色彩光影设计卡与 ST 的关系

`CL` 不是单独的一句“电影级光影”，而是 `ST` 的光影执行层。`ST` 规定项目像什么，`CL` 规定当前项目或场景如何打光。角色图、场景图和 06 视频提示词都必须把 `CL` 翻译成当前可见光源、光线方向、亮暗区域、色温、反差和禁止项。

如果 `ST/CL` 风格光影与当前场景真实光源冲突，按以下优先级处理：

```text
当前场景真实光源和剧情时段优先；
项目风格的画面质感、反差、颗粒/线条/渲染媒介保留；
NP 风格防跑偏负面词保留；
不要机械输出两套互相冲突的光影。
```

示例：

```text
港风医院冷白灯：医院走廊顶部冷白荧光灯作为主光，人物脸部受光偏冷，但仍保持港风写实的强明暗反差、现实剧集质感和轻微胶片颗粒；禁止韩剧式冷白精修、禁止过度磨皮。
```

### 6. 常用风格锁示例

以下示例用于建立 `ST/CL/NP` 时参考，不要求原样照搬。最终图片 prompt 仍要结合项目题材、时代、人物阶层、场景和用户参考图转译成自然语言。

```text
ST001_真人写实电影感：
现代写实电影质感，真实亚洲人物比例，自然皮肤纹理，生活化妆发，服装符合职业和阶层，场景材质真实可触摸，不做网红写真或广告大片精修感。

CL001_真人电影自然光：
真实场景光源为主，窗光、台灯、街灯或屏幕光有明确来源，低到中等饱和度，适度明暗反差，保留真实阴影和环境色反射。

NP001_真人写实防跑偏：
塑料皮肤，磨皮过度，网红脸，明星精修大片感，过度妆容，假睫毛夸张，AI 光滑脸，卡通感，畸形手指，随机文字，水印。

ST001_日漫赛璐璐：
二维日漫赛璐璐画风，干净线稿，清晰角色轮廓，角色五官符合动画设定，发型和服装块面明确，背景简洁但有空间层次，整体像番剧设定图。

CL001_日漫赛璐璐光影：
清晰色块阴影，明暗边界干净，少量高光点，色彩明快但不荧光，背景光影服务角色轮廓，不使用真实摄影胶片颗粒。

NP001_日漫防跑偏：
真人照片感，写实皮肤毛孔，3D渲染感，油画厚涂，过度复杂纹理，韩式网红脸，低质量线稿，脏污线条，模糊，畸形肢体。

ST001_3D半写实动画：
3D半写实动画电影质感，角色比例略带动画化但不过度夸张，皮肤和布料有细腻材质，场景模型结构清晰，整体为高质量 CG 动画资产感。

CL001_3D动画电影光影：
柔和电影级三点布光或环境实景光，角色有清晰轮廓光和眼神光，材质反射合理，阴影干净，色彩有层次但不扁平。

NP001_3D半写实防跑偏：
二维插画感，赛璐璐平涂，真人照片感，廉价游戏建模，塑料玩具质感，过度光滑皮肤，低模，贴图拉伸，畸形手指，随机文字。

ST001_国风水墨：
东方国风水墨审美，宣纸肌理，留白构图，人物服饰和场景符合中国古典或新国风语境，山石、云雾、建筑、植物有笔墨韵味。

CL001_国风水墨光影：
柔和散射光，淡墨层次，低饱和雅色，远景雾气和留白形成空间深度，光影不追求强写实摄影灯感。

ST001_赛博朋克：
近未来城市科幻质感，霓虹广告、潮湿街面、金属与玻璃材质、电子屏和人造光源形成空间层次，人物造型有科技感但保持项目设定身份。

CL001_赛博朋克霓虹光：
高反差冷暖霓虹混光，蓝紫/青绿/红橙局部光源，湿润反光地面，背光和边缘光突出轮廓，暗部保留细节但不过曝。

NP001_赛博朋克防跑偏：
古装国风，田园自然光，日系校园清新感，韩式网红脸，廉价塑料科幻，低质量霓虹糊成一片，随机文字，水印，畸形肢体。
```

### 7. 图片 Prompt 组合规则

任何可复制给图像模型的 prompt，不得只写“继承 ST001 / CL001 / NP001”。必须按以下顺序把它们展开：

```text
资产身份：角色 / 场景 / 道具的具体设定。
风格转译：把 ST 的媒介类型、人物审美、场景审美、画面质感写成自然语言。
光影转译：把 CL 写成当前资产可执行光源、方向、亮区、暗区、色温和反差。
资产限制：角色一致性 / 场景空间 / 道具外观 / 禁止变化点。
负面提示词：NP + 当前资产专属负面词。
```

内部编号可以出现在资产卡、记录表和交接说明中；最终投喂 prompt 必须让图像模型不依赖 Skill 也能看懂。

### 角色四视图定稿图 Prompt 结构

当本模块为核心角色生成“角色定稿图 / 角色资产图 / 人物参考图 / 角色设定图”时，默认输出**人物四视图设定图**。除非用户明确要求单张头像、表情包、动作图或透明抠图，不要只输出单人单角度美图。

四视图布局必须参考以下结构：

```text
横向宽图，影棚灰色背景。
左侧 35%-40%：同一角色的大头 / 胸像近景，用于脸型、发型、五官、气质识别。
右侧 60%-65%：同一角色的三个全身视图，从左到右依次为正面全身、侧面全身、背面全身。
四个视图必须是同一人物、同一年龄感、同一脸型、同一发型、同一服装、同一鞋子、同一配饰。
```

默认正向 prompt 模板：

```text
生成一张角色四视图设定图，横向宽图，影棚灰色背景，干净均匀布光，角色设计稿 / character turnaround sheet 风格。

角色：[角色名]，[年龄段]，[性别/体态]，[身份/职业]。
外貌：[脸型、五官、发型、肤色、年龄感、核心气质]。
服装：[上衣、外套、下装、鞋子、包/首饰/道具等配饰]。
表情与气质：[常用表情、情绪底色、人物状态]。

画面排列：
左侧为大头/胸像近景，清楚展示脸型、五官、发型、眼神和气质；
右侧依次排列三个全身视图：正面全身、侧面全身、背面全身；
四个视图之间留出干净间距，比例统一，角色身高和服装细节一致。

背景：影棚灰色背景，柔和均匀灯光，无场景道具，无复杂背景。
风格：[写实 / 动画 / 3D / 动漫 / 国风等，按项目风格填写]。
限制：四个视图必须是同一个角色；脸型、发型、服装、鞋子、配饰必须完全一致；不要生成多个不同人物；不要换装；不要改变发色；不要随机文字；不要水印；不要 logo。
```

默认负向 prompt 要包含：

```text
不同角色，多人，换脸，换发型，换衣服，服装前后不一致，鞋子不一致，配饰丢失，脸型不一致，年龄变化，姿势夸张，动作戏，复杂场景，室内家具，文字，标签，水印，logo，随机符号，低清晰度，脏背景，噪点，过度锐化。
```

验收标准：

1. 左侧大头和右侧三视图必须像同一个人。
2. 正面、侧面、背面服装结构必须能互相对上。
3. 背面必须能看清发型后轮廓、外套后片、包带 / 配饰后侧状态。
4. 背景必须是影棚灰色或中性灰，不要生成真实场景。
5. 如果四视图中任一视图换脸、换装、换发型，判定为失败，不进入定稿图。

### 高级角色设定资料卡 Prompt 结构

高级角色设定资料卡与四视图共存，不替代四视图。四视图负责“角色一致性基础”，高级资料卡负责“生产级资产归档、团队交接、局部细节、比例和设计说明”。普通角色默认只输出四视图；核心角色、高价值角色、重要反派、怪物、幻兽、机甲、IP 核心角色，或用户明确说“高级角色卡 / 角色资料卡 / 像设定集一样 / 资产卡更高级”，才额外输出高级资料卡 prompt。

默认比例：

```text
高级角色设定资料卡：横版 3:2，白色或浅灰影棚背景。
如用户要宣发展示版，可额外输出 16:9 横版展示版；不要用 9:16 竖版做资料卡。
```

高级资料卡必须包含：

1. **标题与基础信息**：角色名、年龄/年龄段、身高、性格关键词、叙事功能。文字无法保证清晰时，允许只留标题区和信息栏空位。
2. **面部特写**：脸型、眼睛、发型、识别点、常用情绪底色。
3. **配色方案**：发色、肤色、眼睛、上衣、裤子、鞋子、关键道具/发光色等色块。
4. **三视图**：正面全身、侧面全身、背面全身；必须同脸、同发型、同服装、同鞋、同体型。
5. **全身比例参照**：头顶、下巴、肩部、腰部、膝盖、脚底等比例线，人物比例不能漂。
6. **与成年人/标准人体比例对比**：用灰色剪影对比身高和体型。
7. **细节展示**：6-8 个局部细节框，如眼神、发型、衣料、袖口、手部、道具、鞋子、裤脚、标志性姿态。

默认正向 prompt 模板：


验收标准：

1. 高级资料卡必须与四视图定稿图是同一个角色。
2. 面部特写、三视图、比例图、细节图不能互相换脸或换衣。
3. 3:2 资料卡信息密度要完整，不要只生成大图加几块装饰。
4. 配色方案必须来自角色本身，不要随机加无关色。
5. 细节展示必须展示可复用识别点，不要放无意义的装饰局部。
6. 文字乱码严重时不判定视觉失败，但要建议下一版改成“文字区域留空，后期手动排字”。

### 角色资产红线

- 角色定稿后，脸型、年龄感、核心气质、标志性识别点不能随意变化。
- 如果模型生成结果“好看但不像角色”，必须判定为失败。
- 如果角色和同剧其他角色剪影相似，必须重做识别点。
- 角色外观与剧本身份冲突时，先回到创作模块确认，不要硬定稿。
- 不用高级角色设定资料卡替代四视图；高级资料卡只能作为归档和交接增强，角色一致性基础仍以四视图/定稿角色图为准。
- 不把高级资料卡强制套给所有角色；普通工具人、只出现一次的小角色默认不输出，避免资产库过重。

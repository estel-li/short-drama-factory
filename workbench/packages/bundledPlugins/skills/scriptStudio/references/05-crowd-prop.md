## 九、人群/群演调度卡模板

`CR` 不是人物资产，也不是场景图片资产。它是给 04/06 使用的文字调度卡，用来决定某个公共场景在某个故事时段是否有人、多少人、站在哪些景深层次、如何移动、是否允许遮挡主角。

使用原则：

1. **场景母版永远保持空场**：SC 图片只提供环境结构，不继承“空无一人”的剧情状态。
2. **人群只在视频提示词里动态出现**：公共空间、街道、商场、学校、医院、车站、餐厅营业时段等，需要由 CR 卡把人群写进 04/06。
3. **私密空间默认禁止额外人物**：卧室、客厅、审讯室、密谈包间等，如果剧本没写第三人，04/06 要在限制里写“不允许出现额外人物、路人、群演”。
4. **人群不得抢戏**：路人只服务真实感、空间压力、时代质感或遮挡调度；不能看镜头，不能围观主角，不能遮挡关键表情和关键道具。
5. **声音只交环境层级**：CR/PR 交给 06 时只写人群声、道具声、动作声和对白清晰度，不生成 BGM；BGM 仍交给 07。

```markdown
# CR001_场景名_人群密度卡

## 1. 绑定信息

- CR 编号：
- 绑定场景：SC001_场景名
- 适用故事时段：白天 / 黄昏 / 夜晚 / 上班高峰 / 下班高峰 / 深夜 / 特殊事件
- 适用大分镜：B01-B03
- 是否影响剧情：只做真实环境 / 制造压迫 / 制造遮挡 / 制造误会 / 制造危险 / 参与剧情

## 2. 密度等级

- 空场：0 人，只保留主角和剧本明确人物。
- 稀疏：1-3 人，远处零星经过，几乎不影响主角。
- 日常：4-10 人，前景或中景有少量路人，空间有生活感。
- 繁忙：10-30 人，前中远景都有行人，方向交错，但主角脸部和动作仍清楚。
- 高峰拥挤：30 人以上，远景大量人头攒动，前景有人擦肩经过；只在街口、车站、商场高峰等场景使用。

## 3. 景深层次分布

- 前景：人数范围、是否虚化、是否擦肩经过、是否允许短暂遮挡画面边缘。
- 中景：人数范围、与主角同向/反向/横向移动，是否保持安全距离。
- 远景：人数范围、人头攒动/排队/散步/等车/进出店门等背景行为。

## 4. 人群类型

- 年龄与身份：白领、学生、老人、游客、店员、快递员、摊贩、家长、小孩等。
- 服装与时代：符合地点、季节、城市和阶层；不要所有人同服装。
- 行为：走路、买东西、看手机、等车、交谈、撑伞、提购物袋等。

## 5. 移动与遮挡规则

- 移动方向：同向 / 反向 / 横穿 / 进店 / 出店 / 排队缓慢移动。
- 速度：慢行 / 正常步速 / 高峰急行 / 停留。
- 遮挡：可短暂遮挡身体边缘，不得遮挡主角脸部、关键表情、关键道具和动作标点。
- 与主角互动：无互动 / 擦肩而过 / 被动让路 / 远处看一眼；禁止围观、禁止集体看镜头，除非剧情明确。

## 6. 声音与氛围

- 环境声：人群低声交谈、脚步声、车流声、店铺声、广播声等。
- 声音强度：弱 / 中 / 强；不得盖过主角台词，除非剧情需要。

## 7. 视频提示词禁止项

- 不要空街、不要空商场、不要只有主角孤零零站在公共空间（除非 CR 设为空场）。
- 不要复制粘贴同脸路人，不要所有路人同服装、同动作、同方向。
- 不要让路人看镜头、围观主角、抢镜、挡住主角脸部和关键动作。
- 不要新增与剧情无关的主要角色。
- 不要把场景母版中的“空场”理解为视频必须空无一人；CR 启用时必须按 CR 生成人群。
```

示例：

```text
CR001_铜锣湾下班人流：绑定 SC003_铜锣湾街口，密度为高峰拥挤。前景 3-5 名路人从镜头边缘擦肩经过并轻微虚化；中景 8-12 名行人与主角同向和反向交错移动；远景街口 20 人以上持续进出店铺和斑马线。人群类型包含白领、学生、游客、快递员、提购物袋的中年人、撑伞老人。路人不得看镜头，不得遮挡主角脸部和关键道具，不要同脸复制。
```

### 小道具视频朝向规则

手机、照片、信封、戒指、硬币、钥匙、证件等小道具进入 AI 视频分镜 / Seedance / Sora 提示词时，必须在资产卡和分镜限制中写清：

1. 哪一面朝镜头。
2. 哪一面背向镜头 / 贴手心 / 扣在桌面 / 朝向角色身体。
3. 哪些面禁止生成屏幕、文字、图案或错误结构。
4. 如果镜头不需要观众看清信息，优先让非信息面朝镜头，避免模型自动把道具正面怼给镜头。
5. 对手机类道具，必须区分“屏幕正面”和“摄像头背面”；背面严禁生成 UI、聊天气泡、发光屏幕或文字。

示例：

```text
限制：手机背面朝镜头，黑色玻璃背板和斜排双摄清晰可见；屏幕正面朝向角色手心，不可见；禁止把手机背面生成成屏幕或微信界面。
```

### 道具单实例锁 / Prop Single-Instance Lock

当同一个关键道具既出现在 `SC` 场景母版、`SCV` 角度图或 `FF` 首帧图里，又需要单独上传 `PR` 道具参考图时，必须建立“道具单实例锁”。多参考图不会天然告诉视频模型“这是同一个物体”，如果只写“参考手机道具图”，模型可能把场景里的手机和 PR 图里的手机理解为两个道具。

触发条件：

1. 固定摆放道具已经在场景图或首帧图中可见，例如桌上的手机、墙上的钟、柜台上的收银机、吧台上的酒瓶。
2. 同一个 PR 道具后续还要特写、被拿起、被移动、被递交或跨段延续。
3. `素材` 映射中同段同时存在 `SC/SCV/FF` 和同一件 `PR` 道具参考。
4. 道具数量错误会造成明显穿帮，例如桌上一个、手里一个，或背景又复制一个。

决策规则：

- **固定陈设，不参与剧情**：优先只放进 `SC` 场景母版或 `SCV` 角度图，不单独上传 `PR`。例如墙钟、固定招牌、不可移动灯具。
- **关键道具已在 FF 首帧中锁定位置，但本段不需要特写**：优先使用 `FF + 文字限制`，PR 可不上传。
- **关键道具已在 SC/SCV/FF 中出现，且本段需要外观细节**：可以上传 `PR`，但必须写明 `PR` 只补同一件道具的外观，不新增第二个实例。
- **关键道具尚未在场景或首帧中出现，剧情中首次进入画面**：`PR` 可以作为新增道具参考，但必须写清进入动作、初始位置、数量和段末状态。
- **角色拿起或移动道具**：必须写清原位置变化。角色拿起手机后，桌面原位置必须变为空；不能桌上留一部、手里又出现一部。

资产卡新增字段：

```markdown
## PR001_道具名_单实例锁

- 道具实例：PR001 = [具体道具名称]
- 实例属性：固定陈设 / 可移动叙事道具 / 外观修正参考
- 已出现位置：SC001 场景母版 / SC001_V02 角度图 / FF001 首帧图 / 尚未出现
- 绑定可见对象：如“@图6 首帧中桌面右下角那一部碎屏手机”
- 数量限制：全片 / 本段只允许出现 1 个 PR001
- PR 图用途：只参考外观、材质、裂纹、颜色、屏幕状态；不是新增道具
- 位置继承：桌面右下角 / 角色右手 / 吧台内侧 / 墙面左上角
- 移动规则：如果角色拿起，原位置必须为空；如果放下，手中必须为空
- 禁止项：禁止第二个同款道具；禁止桌上和手里同时各出现一个；禁止复制到背景、地面、沙发或其他桌面
```

交给 04/06 的标准句：

```text
道具单实例锁：PR001 碎屏手机就是 @图6 首帧中桌面右下角那一部手机。全片只允许出现这一部手机。@图3 不是新增道具，只用于修正这同一部手机的外观细节；如果角色拿起手机，桌面原位置必须变为空，不得保留第二部手机。
```

参考图用途映射中必须写成：

```text
@图3 = PR001 碎屏手机外观参考，只参考机身颜色、裂纹形态、边框磨损和背面双摄细节；不新增第二部手机，不改变 @图6 首帧中桌面右下角那一部手机的位置。
```

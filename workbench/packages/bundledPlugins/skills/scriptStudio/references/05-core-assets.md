## 一、什么时候调用本模块

用户出现以下需求时，调用本模块：

1. “建立资产库 / 素材库 / 角色资产 / 场景资产 / 道具资产”
2. “帮我整理参考图 / 统一角色图 / 管理出图结果”
3. “这个项目后面要持续出图、分镜、做 AI 视频”
4. “把项目档案里的角色、场景、道具整理成资产表”
5. “帮我规划文件夹结构 / 命名规则 / 版本管理”
6. “这几张图怎么编号，怎么传给分镜或视频模型”
7. “我要留档，后续新对话继续用”

如果用户只是要写故事，先回到 `01-script-creation.md`。  
如果用户只是要诊断剧本，先回到 `02-script-doctor.md`。  
如果用户只是要改台词，先回到 `03-dialogue-expert.md`。  
如果用户已经有定稿剧本并要转 AI 视频分镜，先确认是否已有资产库；没有则建议先建立本模块。

资产库完成后必须交接给 04/06：保留已有平台节奏档案和节奏档位，不在 05 内重判剧情节奏；列出当前段真正需要的角色、场景、道具、首帧、调度和 SCV 图，提醒单组 06 可投喂图片参考最多 9 张，超出时给筛选、合并、转文字或拆组建议。

## 二、资产库的核心目标

资产库要解决 5 个问题：

1. **一致性**：同一个角色、场景、道具在不同场次、不同模型、不同生成批次中不漂移。
2. **可追溯**：每张图、每条 prompt、每个版本都知道来源、用途、状态。
3. **可交接**：剧本、台词、分镜、AI 视频 prompt 都使用同一套资产编号。
4. **可扩展**：后续新增角色、场景、道具、服装、镜头参考时，不破坏旧编号。
5. **可复盘**：知道哪些资产已定稿、哪些只是参考、哪些被废弃。

### 目录使用原则

- `参考图`：用于启发，不保证最终采用。
- `定稿图`：已经被用户确认，可在后续分镜、出图、视频生成中反复引用。
- `废弃`：不要删除失败图，移入废弃并记录原因，避免后续重复踩坑。
- `资产总表.md` 是核心索引。没有进入资产总表的图片，不算正式资产。

## 四、资产编号规则

所有资产必须有稳定编号。编号一旦确认，不因角色改名、场景改名而改变。

| 类型 | 前缀 | 示例 | 用途 |
|---|---|---|---|
| 角色 | CH | CH001_花十 | 主角、配角、群像人物 |
| 场景 | SC | SC001_茶餐厅 | 固定地点、关键空间 |
| 道具 | PR | PR001_银色打火机 | 有叙事作用的物件 |
| 服装 | CO | CO001_花十黑夹克 | 角色造型、换装 |
| 妆发 | MU | MU001_露夏短发 | 发型、妆容、伤痕 |
| 风格 | ST | ST001_港风写实 | 总体画风 |
| 色彩光影 | CL | CL001_暖黄茶餐厅 | 调色、布光母版、光影连续性 |
| 风格防跑偏负面词 | NP | NP001_港风防跑偏 | 防止人物、场景、画面质感跑到错误审美；给图片 prompt 和 06 Avoid 转译使用 |
| 镜头参考 | CA | CA001_长焦过肩暧昧 | 构图、焦段、运镜参考 |
| 声音参考 | AU | AU001_茶餐厅环境声 | 环境音、角色声线、音乐 |
| 视频参考 | VI | VI001_街口慢推镜头 | 动态、节奏、运镜 |
| 调度图 | MAP | MAP001_SC001_B01-B02 | 人物站位、移动路线、摄影机安全区、轴线 |
| 场景多角度空间包 | SCV | SCV001_SC001_便利店窗边 | 核心/高穿帮场景的 PLAN 俯视图、V01-V04 空场角度图和关键空间细节；只锁定空间视角，不生成角色和人群 |
| 空间侧别锁定 | SB | SB001_便利店窗边_内外侧 | 玻璃、门窗、柜台、吧台、车窗、栏杆等分界面；锁定内外侧、摄影机侧、人物允许区和禁止区 |
| 人群/群演调度 | CR | CR001_铜锣湾下班人流 | 路人数量、类型、景深层次、移动方向、遮挡规则；只作为文字调度卡，不生成到场景母版图里 |
| 首帧图 | FF | FF001_B05_便利店窗边首帧 | 锁定某一视频段第 0 秒构图、人物初始位置、道具位置、空间内外侧、摄影机侧和光影；只用于视频起始画面，不替代场景/角色/道具资产 |

### 版本号规则

```text
资产编号_名称_v主版本.子版本_状态
```

示例：

```text
CH001_花十_v1.0_定稿
CH001_花十_v1.1_改发型
SC001_茶餐厅_v0.3_参考
PR001_银色打火机_v2.0_定稿
```

版本解释：

- `v0.x`：探索阶段，不稳定。
- `v1.0`：第一版定稿，可进入分镜和视频生成。
- `v1.x`：小改，不改变资产核心身份。
- `v2.0`：大改，外观、时代、身份识别明显变化。

## 五、资产状态规则

每个资产必须标注状态。

| 状态 | 含义 | 能否交给分镜/视频 |
|---|---|---|
| 待补 | 只有名字或描述，未生成图 | 不建议 |
| 参考 | 可启发，但未确认 | 可作为参考，不可作为唯一依据 |
| 候选 | 有 2-5 个可选方向 | 不建议，需用户定稿 |
| 定稿 | 用户确认，进入资产总表 | 可以 |
| 需重做 | 方向错误或不稳定 | 不可以 |
| 废弃 | 明确淘汰 | 不可以 |

输出任何资产表时，必须明确状态，不能只列名字。

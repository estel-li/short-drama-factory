## 核心原则速记（开头冗余 1/3）

> 与 Skill 1-4 共享底线 + 本 skill 专属红线。

1. **真实反馈，不捧杀**：剧本的戏剧动作不清楚就直说"这场戏镜头落不下去，问题在剧本结构"，不硬拍
2. **镜头服务剧本与情绪，不为构图押韵而押韵**：每个镜头的取值（焦段/光圈/景深与焦点锁/机位/构图/运镜）必须能回答"为什么这么拍"
3. **每镜必须服务于情绪锚点**：每个分镜必须能映射到"情绪锚点表"的某个节拍。映射不上 = 该镜头无效。**禁止为切而切**
4. **抽象描述必须转译**："他内心崩溃了" → 摄影机能拍的具象画面（如"茶碗在他手里出现压痕"）。**不允许任何抽象/文学/心理描写直接进入分镜**
5. **分镜衔接遵循 5 维度**：轴线 / 视线 / 动作 / 物件 / 景别跳跃。衔接错乱 = 观众出戏
6. **运镜衔接有 5 模式**：同向 / 反向 / 静切动 / 动切静 / 同质叠加。不允许一段戏内运镜方式过多导致风格混乱
7. **构图雷区主动规避**：断关节 / 头顶贴边 / 视线无空间 / 物体穿身 / 微距主体不明等
8. **每镜必须从【情境映射库】选定情境 ID + 用 80/15/5 权重合成**：核心组合锁死（80%）、辅助锚点选 1-2（15%）、增强项仅在情绪命中点用（5%）
9. **雷区分两类**：A 类艺术性雷区可在白名单情境下解锁（如库布里克式正面居中）；B 类工程性雷区永不解锁（如物体穿身）
10. **双视角对齐是内部思考，不暴露给用户**：演员视角 + 观众视角必须对齐再输出，但思考过程不写进文档
11. **AI 易错点必须用"限制"字段强制纠正**：包括"必须有"和"必须无"两类
12. **运镜中文歧义时加英文**：避免 AI 模型识别错误。无歧义不加，避免冗余
13. **不写剧本，不改台词，不评剧情**：只做视听转译；遇到剧情漏洞引导回 Skill 2/3/4
14. **基础跨段衔接默认保留**：每段仍要输出“下一段衔接 / 段末状态 / 通用后缀衔接约束”，保持原 04/06 的正常提示词样式。新增的点位、调度图、本视频第一帧状态、禁止错误站位，只是“强连续增强层”，默认仅在同场景连续、回切同场景、批量生成易穿帮时叠加；切换新场景后不继承上一场点位表、MAP/SB、SCV 或视频延长逻辑。
15. **短视频平台节奏继承**：如果上游提供平台节奏档案，分镜必须继承前 3 秒钩子、前 15 秒冲突、呼吸感许可、禁止拖慢点和完播目标。慢镜头、空镜、沉默可以用，但必须说明它服务什么信息或情绪。
16. **相邻段边界要给下游建议**：如果下游是 Seedance / 豆包 / 火山方舟，04 在大分镜阶段要判断相邻段之间是视频延长、首帧图 + 调度图、只首帧图、只调度图还是普通衔接。视频延长只建议给同场景顺延关系；首帧图和调度图用于同场景复杂空间、场景首现多人调度、窗内外/柜台内外/车内外、多人走位、轴线和遮挡风险。
17. **独立批量强连续优先**：如果两段属于同场景强连续，但不使用视频延长，后续给 Seedance / 豆包 / 火山方舟的强连续提示词不能只依赖“上一段、承接 B01、仍然、继续、同一场景”等上下文词。必须在保留原提示词样式的基础上，把当前视频第一帧的可见状态写清：人物在什么点位、身体朝向谁、道具在哪、光线是什么、摄影机在哪个安全区。
17.1 **交给 06 的时长写法**：04 可以在大分镜前置单元输出 `建议时长`、`节奏策略` 和 `节奏分配`，但不要把 `0-3s / 3-6s` 这类硬时间码写成 Seedance 最终投喂正文。06 负责把总时长、画幅、模式放在代码框外，正文按 `镜头1 / 镜头2 / 镜头3` 或软时间节奏推进。
17.2 **快切 / 蒙太奇只给软节奏**：快切、蒙太奇、广告卡点、音乐卡点可以写“每镜约 0.5-1 秒”“连续 6 个短镜头”“最后一镜稍停”等节奏建议；精确剪辑点、绝对卡点和最终时长控制交给后期剪辑时间轴，不要求视频模型逐秒精确执行。
17.3 **短视频镜头密度联动**：用于短视频平台、竖屏短剧、红果、抖音、快手、小红书、视频号等项目时，04 必须把“建议时长、节奏档位、分镜数量”联动判断。默认由 AI 自动判定 `电影感中速 / 短视频中高密度 / 高密度动作或强钩子 / 慢节奏但高信息`，用户指定时覆盖自动判断；10 秒以上只有 1-2 个镜头必须标记为慢节奏风险，除非命中强情绪压迫、重要台词交锋、单镜头调度、反派登场、仪式感、高级悬疑凝视或同场景视频延长等白名单，并写清慢镜头功能。
17.4 **节奏档位必须交给 06**：每个大分镜前置单元必须写 `节奏档位判定 / 判定理由 / 建议镜头密度 / 交给 06 的执行说明`。代码式管理话术不进入 06 纯净提示词，但 06 必须把档位翻译成镜头轨的动作密度、转接速度、慢词控制和段末钩子。
18. **光影必须可执行**：`光影` 不是“电影级布光 / 高级光影”的形容词栏。每镜必须写清光源来源、主光方向、亮区、暗区、脸部受光、轮廓光或背景分离、色温和明暗反差；需要丁达尔光、烟雾、尘埃、雨雾时必须写光束从哪里进入、穿过什么、落在哪个区域。
19. **情绪必须拆成表演过程**：`主体动作/表情` 不能只写“悲伤 / 愤怒 / 害怕 / 心动”。必须写眼神、眨眼、嘴部、呼吸、肩颈、手部或身体重心的可见变化，并在 `限制` 里写清禁止过度表演，如不要假哭、不要夸张皱眉、不要大喊、不要情绪失控，除非剧本明确爆发。
20. **人群是视频调度，不是场景母版**：公共空间必须判断是否需要路人/群演；如启用 05 的 `CR` 人群调度卡，要把人数、前中远景分布、人群类型、移动方向和遮挡规则写进分镜。场景母版只参考空间结构，不继承“空无一人”的状态；私密空间或无需路人时，必须在限制里写“不允许出现额外人物、路人、群演”。
21. **情绪运镜与动作戏速查按需启用**：只有打斗、追逐、动作戏、强情绪运镜、特殊转场、心理视觉化，或用户明确要求“换运镜 / 动作戏更强 / 打斗招式”时，才读取 `04b-camera-action-cheatsheet.md`。普通文戏不要硬套速查组合；具体动作戏按类型只补读命中的 04b 子库，不默认读取全部动作子库；启用时只选少量组合，并把组合标签改写进 11 必填字段。
22. **摄影机行为锁先于运镜命名**：运镜 不能只写

## 04b 速查库调用规则

`04b-camera-action-cheatsheet.md` 是可选参考库，不是默认上下文。先读它做摄影机行为锁、转场和动作类型路由；只有命中具体动作类型时，再补读对应子库。

触发条件：

- 剧本出现打斗、追逐、逃亡、暗杀、兵器、拳脚、超能力、轻功、摔倒、撞击、爆炸、强动作转场。
- 用户说“运镜不够 / 换运镜 / 动作戏更强 / 打斗招式 / 追逐怎么拍 / 来点高级转场”。
- 强情绪镜头需要视觉化，例如窒息推近、呼吸跟拍、视线盲区、记忆闪回、雨幕隔离。

动作子库选择：

- 自由格斗、拳脚、摔投、擒拿、缴械、地面控制、近身搏斗：读 `04b-free-combat.md`。
- 武侠、冷兵器、刀剑枪棍、暗器、轻功、飞檐走壁、内力交锋：读 `04b-wuxia-weapons.md`。
- 超能力、异能、法术、念力、瞬移、护盾、元素、重力、空间裂隙：读 `04b-superpower-action.md`。
- 战场、军阵、群战、骑兵、弓箭、攻城、撤退、指挥官视角：读 `04b-battlefield-action.md`。
- 普通追逐、特殊转场、强情绪运镜、心理视觉化：只用 04b 本体。

使用限制：

- 4-8 秒视频单元最多选 1 个核心组合；10-15 秒视频单元最多选 2-3 个组合。
- 混合动作段最多补读 2 个动作子库，以当前段主要动作类型优先。
- 不把 `N-1 / S-3 / F-7 / B-6` 等内部编号写进用户可投喂提示词。
- 速查组合和子库规则必须落回 04 的字段：`运镜` 写摄影机行为，`主体动作/表情` 写动作过程，`限制` 写禁止错误动作和空间穿帮，`下一段衔接` 写动作结果。
- 如果速查组合和 SCV/MAP/SB/FF 冲突，优先保留已确认资产与空间逻辑，重选或改写运镜。

# 第一部分  工作流程（6 个 Phase）

## Phase 0 · 接收识别 + 双前置询问

收到剧本后，依次完成：

### 0.1 自动识别剧本

确认是剧本而非大纲/小说。如果是大纲：
> 你提供的是大纲（无具体动作/对白），分镜需要场景化的动作和台词。建议：
> 1. 回到 Skill 2 把这段大纲写成完整剧本，再回来
> 2. 或者你接受我"按大纲补全合理动作 + 自创对白"——这种情况下我会标注哪些是我补的

### 0.2 询问参考图（智能识别 + 提示）

```
【参考图询问】
为保证 AI 视频生成的角色 / 环境一致性，建议提供：
- 环境参考图（建议标记为 @图1）
- 角色参考图（建议标记为 @图2、@图3...）

请告知映射关系，例：
   @图1 = 茶餐厅环境
   @图2 = 花十
   @图3 = 露夏

无参考图也可推进，但角色一致性会显著下降。
是否提供？（"是 + 映射" / "否，继续" / "我之后补"）
```

**接收后建立映射表**，写入本次会话的"参考图档案"：

```
本次会话参考图：
  @图1 = ____
  @图2 = ____
  @图3 = ____
```

后续所有分镜中提及角色 / 环境时，**自动使用 @图N 引用**。

### 0.2b 资产库风格继承检查

如果用户提供了 05 资产库，或当前项目已经进入出图 / 视频生产链路，先检查是否存在：

- `ST` 视觉风格锁定卡
- `CL` 色彩光影设计卡
- `NP` 风格防跑偏负面词包

继承规则：

1. 如果资产库已有 `ST/CL/NP`，分镜必须继承项目风格方向、人物审美、场景审美、画面质感、当前场景光影基调和风格禁止项。
2. 不要再向用户询问一个与 `ST/CL/NP` 冲突的泛化风格后缀；除非用户明确说“换风格 / 重做视觉风格 / 不沿用资产库风格”。
3. 如果资产库没有风格锁，但任务明显要进入资产出图或 AI 视频生成，先根据剧本、参考图和项目类型反推一版暂定风格；也可以询问用户一次想要的风格方向。
4. 交给 06 时可以在代码块外写 `ST/CL/NP` 管理信息，但最终 Seedance 纯净提示词必须把它们翻译成自然语言，不得只写内部编号。

### 0.3 询问通用后缀（不预设档位）

```
【通用后缀询问】
通用后缀 = 给 AI 视频模型的质量约束 prompt（IMAX 级、8K、无字幕等）。
是否启用？

A. 启用 + 我根据剧本的类型/质感反推一份给你过目
B. 启用 + 你给我一段自定义描述
C. 不启用
D. 沿用上次会话的后缀

请选择。
```

## Phase 2 · 角色内心 + 观众接收（双视角内部思考）

> **关键：本 Phase 不输出。** 仅在内部完成思考。

### 思考流程

```
【内部思考 · 不输出】

演员视角：
  - 角色在这场戏的内在动机是什么？
  - 表面行为 vs 真实情绪的差距是什么？
  - 角色不会说出口的潜台词是什么？
  - 演员会用身体的哪个部位来"演"潜台词？
    （眼神 / 手指 / 嘴角 / 肩膀 / 呼吸节奏）

观众视角：
  - 观众需要在这段戏接收到什么信息？
  - 观众容易遗漏的细节是什么？
  - 哪些镜头必须给"特写"，否则观众接收不到？
  - 这段戏的"情绪命中"靠哪一个镜头实现？

对齐判断：
  - 演员视角想表达的，观众视角能否接收？
  - 不齐 → 增加镜头 / 改变景别 / 调整节奏
  - 对齐 → 进入 Phase 3
```

如果 AI 在思考过程中发现**剧本本身存在情绪断点**（演员演不出来 / 观众接收不到），**主动停下来告诉用户**：

```
【需要你先决策】
这段戏的情绪逻辑有断点：
- 露夏从"害羞"到"鼓起勇气邀请"中间没有铺垫
- 我可以："硬拍"（用镜头创造铺垫，比如增加一个低头深呼吸的特写）
   或："这是剧本的问题"（建议你回 Skill 2/4 改剧本/台词，再来分镜）
你怎么选？
```

## Phase 3 · 视听转译（抽象→具象）

把剧本里所有"摄影机拍不到的"描述转换成"能拍的"。

### 转译原则

| 类别 | 抽象描述（不可拍） | 具象转译（可拍） |
|---|---|---|
| 心理 | 内心崩溃 | 茶碗指节发白；杯沿出现细裂纹；周围声音渐弱 |
| 时间 | 时间停滞 | 灰尘悬浮；水珠悬空；环境音消失 |
| 决心 | 心一横 | 握紧拳头；咬肌跳动；瞳孔收缩 |
| 试探 | 鼓起勇气 | 吸管搅拌奶茶的动作慢一拍；抬头时机比对方晚 0.5 秒 |
| 暧昧 | 心动 | 眼神短暂下移再上移；指尖无意识摩挲杯沿 |
| 距离 | 关系疏远 | 物理距离拉大；中间放置障碍物；同框但不同景深 |
| 命运 | 不祥预感 | 风吹动纸张；蜡烛火苗倾斜；远处铃铛单声 |

> 这张表会持续扩充（详见附录 C）。

### 转译输出

不单独输出"转译表"——直接把转译结果用于 Phase 5 的分镜中。

## Phase 4 · 大分镜切片

按**情绪节拍 + 戏剧动作单元**切，不机械按秒数。

### 切片原则

- 每段大分镜 ~15 秒（弹性 12-18 秒）
- 一个**完整情绪转折** = 一段大分镜
- 一个**完整戏剧动作**（如"邀请→接受"）= 一段大分镜
- 切点应落在"情绪转折点"或"动作完成点"
- 如果下游明确是 Seedance 2.0 / 豆包视频 / 火山方舟，或用户要求短视频平台成片，优先把每段大分镜控制为 4-15 秒；超过 15 秒必须拆成两个可独立生成的单元。
- 如果下游是 Seedance 2.0，04 的 `建议时长` 只作为生成参数交接，最终由 06 放在代码框外；大分镜和分镜正文优先写镜头顺序、动作先后和软节奏，不写硬时间戳。

### 短视频平台分镜节奏规则

当作品用于短视频平台发布时，按以下规则叠加到 Phase 4-5：

1. **首段前 3 秒必须有可见钩子**：冲突姿态、反差画面、异常道具、强表情、危险动作、谜题信息至少占一项。禁止只用普通空镜、慢走背影、天气铺垫开场。
2. **空镜必须带信息**：空镜只能用于交代关键环境线索、时间压力、人物缺席、危险来源、情绪反差或视觉记忆点；纯“好看”的空镜删除。
3. **慢推必须推进**：慢推、长焦凝视、沉默停顿必须让情绪、悬念、关系或信息发生变化；如果只是维持同一状态，缩短或替换为动作标点。
4. **每段大分镜都有继续看的理由**：在大分镜前置单元写明“本段钩子 / 信息增量 / 情绪推进 / 段末继续看的理由”。
5. **呼吸镜头必须标注功能**：如果某镜头是呼吸镜头，在主体动作或限制中写清“功能：情绪回落 / 蓄力 / 悬念加深 / 关系变化 / 视觉记忆点”。
6. **连续慢镜头之间必须有变化**：动作、视线、声音、光线、景别或道具状态至少变化一项。
7. **结尾镜头服务完播或下一段**：最后一个镜头要么完成情绪命中，要么制造疑问、反转、关系变化或下一段动作牵引。
8. **节奏档位决定镜头密度**：先自动判定档位，再按时长决定镜头数量。`电影感中速` 沿用原密度：4-6 秒 1-2 镜，7-9 秒 2-3 镜，10-12 秒 3-5 镜，13-15 秒 4-6 镜；`短视频中高密度`：4-6 秒 2 镜，7-9 秒 3-4 镜，10-12 秒 4-6 镜，13-15 秒 6-8 镜；`高密度动作或强钩子`：4-6 秒 2-3 镜，7-9 秒 4-5 镜，10-12 秒 5-7 镜，13-15 秒 7-10 镜。短视频平台下，10 秒以上只有 1-2 个镜头时必须在前置单元标注“慢节奏风险”，并说明为什么不能拆成更多镜头。
9. **慢节奏白名单**：只有强情绪压迫、重要台词交锋、单镜头调度、反派登场、仪式感、高级悬疑凝视、同场景视频延长或用户明确要求电影感长停顿时，10-15 秒才允许 1-2 个镜头。即使命中白名单，也必须写清慢镜头承担的情绪、悬念、信息、人物关系、视觉记忆点或下一段蓄力功能。

9. 场景母版是空场环境参考，不等于视频必须空无一人；是否有人群由本段 `人群/路人调度` 决定。
10. 如果资产库提供 SCV 多角度空间包，每个大分镜必须选择推荐场景角度参考；反打、横移、回切和高穿帮镜头不能只写“参见场景母版”，要写明使用 V01/V02/V03/V04 或 PLAN。
11. SCV 角度图只解决当前镜头从哪个方向看同一空间，不替代 MAP 点位、SB 内外侧、FF 第 0 秒首帧或 SC 场景母版。
12. 首帧图是按风险启用的增强层，不是每段默认流程。A 必须首帧、B 建议首帧时，输出首帧图需求；C 可不用首帧时保持原分镜样式。
13. 首帧图不替代 `本段第一帧状态`。如果启用 FF，仍要用文字把第 0 秒可见事实写清楚，方便 06 独立投喂。
14. 场景首次出现且人物多、站位复杂、进出和遮挡关系难控时，即使不是强连续，也要建议 FF 首帧图 + MAP/SB 调度图。
15. 如果 FF 首帧图与 SCV 角度图、MAP 调度图、SB 空间侧别锁定卡或点位表冲突，停止进入 06，先要求重做首帧或修正资产。
16. 不要把 06 的高级增强藏到后面。04 输出大分镜时必须给出下游 06 模式建议和按需增强建议：默认推荐 C 导演轨纯净版；用户明确要求完整字段、1-3 个镜头高精度控制、审查镜头漏项或教学拆解时推荐 A 标准字段化详细版；一镜到底、复杂运镜、动作戏、强遮挡转场、多人调度或强声音叙事时推荐 B 导演执行增强版。
17. 如果资产库提供 ST/CL/NP，每段大分镜必须输出 `风格交接`；交给 06 的风格内容必须是自然语言摘要，不得只写 `ST001 / CL001 / NP001`。
18. 如果 ST 的光影倾向与本段真实光源冲突，以本段场景光源、剧情时段和角色位置为准，同时保留 ST 的画面质感、反差、颗粒/渲染媒介和 NP 风格禁止项。

### 强连续增强判定

生成大分镜前，先判断本段只需要“基础衔接”，还是需要叠加“强连续增强”。

所有段落默认保留基础衔接：

- 每个分镜写 `下一段衔接`。
- 每段末尾写通用后缀中的一致性约束、道具约束、段末状态。
- 允许短写“段末手机屏幕亮起 / 到站出口灯牌入画”等可见状态；分镜编号只能作为括号备注，不得替代画面状态。

满足以下情况时，在基础衔接之上叠加强连续增强：

- 同一场景、同一故事时间，人物动作从上一段直接延续到下一段。
- 同一场景内隐含跳秒，但人物、道具、光线和站位不能自由重置。
- 切到别处后又回到同一场景，且剧情没有说明人物离场、换位、换装或时间大跳。
- 用户明确要求“少穿帮 / 保持站位 / 保持空间调度 / 批量生成连续片段”。

如果切换新场景，默认不叠加强连续空间延续，不继承上一场点位表、MAP/SB、SCV 或视频延长逻辑；只保留角色身份、服装发型、道具状态、情绪任务和平台节奏。

如果新场景第一次出现但人物很多、站位复杂、移动路线和遮挡关系难控，这不是强连续，但仍要建议“首帧图 + 调度图”作为首现调度增强。

不满足强连续或首现调度条件时，不要硬加调度图、点位表和禁止错误点位，但基础衔接不能省略。

### 首帧风险等级判定

生成每个大分镜前，先判断首帧风险等级。首帧功能只解决“第 0 秒画面锚定”和“空间侧别防穿帮”，不要把它当作所有视频段的必选流程。

**A 必须首帧**：

- 玻璃、窗户、门框、柜台、吧台、车窗、栏杆、围挡、镜面等内外侧容易混淆。
- 人物可能坐到桌子/柜台/窗户错误一侧，或 AI 可能把窗外和室内互换。
- 同场景强连续或回切强连续，且用户要批量生成，不能等上一段视频出完再拿尾帧。
- 关键道具位置、人物起始点位、摄影机侧别必须精准，否则直接穿帮。
- 05 已经标注 SB 空间侧别锁定卡、MAP 调度图或“高穿帮风险”。
- 场景首次出现且人物很多、初始站位和遮挡关系复杂。

**B 建议首帧**：

- 首镜构图承担强叙事信息，例如屏幕内容、表情遮挡、雨痕玻璃、门缝偷看。
- 光影关系复杂，冷暖光、反射、轮廓光、丁达尔光落点需要稳定。
- 强情绪近景或多人同画面，首秒姿态、视线、手势影响表演可信度。
- 用户明确说“效果优先，成本可以高”，但该段没有 A 级空间穿帮风险。

**C 可不用首帧**：

- 跨场景新段落、简单单人镜头、无精确空间侧别要求。
- 用户希望 AI 自由发挥，且穿帮风险低。
- 普通衔接段已有清楚的 `人物位置关系`、`下一段衔接` 和 `段末状态`。

首帧策略输出规则：

1. A 必须首帧：在大分镜前置单元写 `是否需要首帧图：是`，并交给 05 输出 FF 首帧需求卡和首帧图 prompt；没有 FF 时可先继续分镜，但必须标注“进入 06 前建议补 FF”。
2. B 建议首帧：写 `是否需要首帧图：建议`，给出是否生成 FF 的理由；用户跳过时，06 走文字锁定增强。
3. C 可不用首帧：写 `是否需要首帧图：否`，保持旧版 04/06 基础样式，不强行加入首帧字段。
4. 启用 FF 时，`本段第一帧状态` 必须复述 FF 的画面事实：谁在什么点位，身体朝向谁，道具在哪，摄影机在哪一侧，光线从哪里来。
5. 首帧图需求要使用“参考图用途映射”：场景图只参考空间，SCV 角度图只参考当前镜头空间方向和透视，角色图只参考外观，道具图只参考外观，MAP/SB 只参考空间逻辑，FF 只参考第 0 秒画面。

## Phase 4.5 · 情绪锚点表（输出 · 简短）

> **每段大分镜切片完成后，立即输出该段的情绪锚点表**——这是后续每个分镜的"情绪依据"，也是验证机制的第一层。

### 4.5.1 锚点表格式（**6 列 · 升级版**）

```
【大分镜 #B01 · 情绪锚点表】

| 节拍 # | 情绪关键词 | 服务的剧本动作 | 情境 ID | 核心组合摘要（80%锁死） | 解锁雷区 |
|---|---|---|---|---|---|
| 节拍 1 | 闲聊试探 | 花十假装随口问"你等会去哪" | E07 | 长焦+大光圈+过肩静态 | — |
| 节拍 2 | 害羞犹豫 | 露夏低头搅奶茶不敢直视 | E08 | 过肩+长焦+手持微动 | — |
| 节拍 3 | 鼓起勇气 | 露夏抬头说出邀请 | E09 | 长焦+仰拍+缓推 | — |
| 节拍 4 | 决断接受 | 花十掐烟起身答应 | E11 | 微距标点+静切动 | — |
```

> **说明**：
> - 情境 ID 来自前置速查表（12 个基础 + 3 个进阶 + 用户自定义）
> - 核心组合摘要从 ID 表直接复制，**不允许 Phase 5 修改这部分**
> - 解锁雷区列：若该 ID 解锁了 A 类雷区则标注（如"A1 正面居中"），否则填 "—"

### 4.5.2 锚点表硬约束

- **每段大分镜的节拍数控制在 3-5 个**（少于 3 个节拍 = 戏不够；多于 5 个 = 该拆成两段）
- **节拍数 × 平均每节拍承担数 ≈ 5-8**（与分镜总数对齐）
- **每个节拍必须能用一句话说清"角色情绪/动作"**——含糊的节拍写不出有效镜头
- **节拍之间必须有变化**——4 个"害羞"节拍 = 戏没推进，违反核心原则
- **情境 ID 必须从前置速查 / 附录 E / 用户自定义三处之一获取**——不允许 LLM 临时编造 ID
- **同段大分镜内 ID 重复使用是允许的**（同一情绪持续多节拍），但**核心组合的"动态变化"必须由辅助锚点承担**（避免连续多镜完全一样）

### 4.5.3 锚点表的作用（5 层直达机制中的 Layer 2）

1. **生成前**：每个分镜在 Phase 5 必须明确对应到某个节拍 + 该节拍的情境 ID
2. **生成中**：内部四问的 Q1+Q4 答案直接来自锚点表（节拍编号 + 情境 ID）
3. **生成后**：成片预演验证：
   - 实际情绪曲线 = 锚点表预设曲线
   - 每个节拍**至少 1 个主镜头**满足 ID 表的 80% 核心组合（辅助镜头允许偏离）
   - 解锁雷区是否合法（A 类有白名单理由 / B 类不允许出现）

### 4.5.4 本段情境对照表（输出 · 替代标题里的 ID）

> 锚点表是工程化版本（6 列），**情境对照表是用户友好版本**——给用户一眼看清"每个节拍用了哪个情境思路"。
> 节拍号与情境 ID 在分镜本体中**不出现**，全部归集到此表。

**输出格式**（在分镜本体之前打印）：

```
【本段情境对照】
- 节拍 1：闲聊试探 → E07 暧昧试探
- 节拍 2：退缩犹豫 → E08 内向退缩
- 节拍 3：鼓起勇气 → E09 突破内心
- 节拍 4：动作标点 → E11 干脆决断
```

如解锁雷区：

```
【本段情境对照】
- 节拍 1：仪式肃穆 → E10 仪式威严（解锁 A1 正面居中·白名单 ② 仪式感）
- 节拍 2：转身亮相 → E02 反派登场变体（解锁 A1·白名单 ⑥ 权力凝固）
```

如使用用户自定义 ID：

```
【本段情境对照】
- 节拍 2：扭曲过渡 → ★ EX01 VR 入境扭曲（用户自定义·本会话内有效）
```

### 4.5.5 分镜数量决策（输出 · 一句话说明）

每段大分镜在分镜本体之前必须输出一句简短数量说明：

```
本段选择 X 个分镜，原因：____。
```

**决策规则（内部计算，输出只给一句话）**：

```
Step 0：先按目标平台、建议时长和剧情功能自动判断节奏档位，再判断镜头密度
        - 电影感中速：4-6 秒 1-2 镜；7-9 秒 2-3 镜；10-12 秒 3-5 镜；13-15 秒 4-6 镜。
        - 短视频中高密度：4-6 秒 2 镜；7-9 秒 3-4 镜；10-12 秒 4-6 镜；13-15 秒 6-8 镜。
        - 高密度动作或强钩子：4-6 秒 2-3 镜；7-9 秒 4-5 镜；10-12 秒 5-7 镜；13-15 秒 7-10 镜。
        - 慢节奏但高信息：只在慢节奏白名单或用户指定时使用。
        - 10 秒以上只有 1-2 镜 → 标记慢节奏风险。
        - 只有命中强情绪压迫、重要台词交锋、单镜头调度、反派登场、仪式感、高级悬疑凝视、同场景视频延长或用户指定电影感长停顿时，才允许保留 1-2 镜。
        - 命中白名单也必须写清慢镜头功能；未命中则增加有功能镜头或拆段。

Step 1：先为每个情绪节拍生成 1 个主镜头
        （4 个节拍 → 至少 4 个主镜头）

Step 2：按必要性追加辅助镜头
        - 动作连续性不清     → +1 动作衔接镜头
        - 关键道具/信息要被看见 → +1 物件/信息镜头
        - 情绪转折需身体细节  → +1 表演细节镜头
        - 多人空间关系复杂    → +1 空间关系镜头
        - E03/E06/E11 节奏情境 → 允许 +1 ~ +3 个快切镜头
        - 抽象心理需视听转译  → +1 具象化镜头

Step 3：总数校验
        低于当前节奏档位下限 → 补 1 个建立/反应/收束镜头（**禁止为凑数添加无功能镜头**）
        超过当前节奏档位上限，或普通镜头超过 10 个 → 拆成两个大分镜，不硬塞
        每个新增镜头都要通过 Q2：删了情绪/动作还能成立吗？能成立则删
```

**建议数量倾向**：

| 建议时长 / 节奏档位 | 默认分镜数 |
|---|---|
| 电影感中速 4-6 / 7-9 / 10-12 / 13-15 秒 | 1-2 / 2-3 / 3-5 / 4-6 镜 |
| 短视频中高密度 4-6 / 7-9 / 10-12 / 13-15 秒 | 2 / 3-4 / 4-6 / 6-8 镜 |
| 高密度动作或强钩子 4-6 / 7-9 / 10-12 / 13-15 秒 | 2-3 / 4-5 / 5-7 / 7-10 镜 |
| 10-15 秒但命中慢节奏白名单 | 可 1-2 镜，但必须写明慢镜头功能和继续看的理由 |

| 戏种 | 建议分镜数 |
|---|---|
| 纯静态对白 / 简单暧昧 | 5-6 镜 |
| 普通情绪转折 | 6 镜 |
| 多人仪式 / 多人对峙 | 6-7 镜 |
| 追逐 / 打斗 / 逃亡 / 暴怒爆发 | 7-8 镜 |
| 抽象心理 / 记忆错位 / 超现实 | 6-8 镜（取决于转译复杂度） |

**反模式**：
- ❌ 短剧本强行撑满 7/8（机械取上限）
- ❌ 复杂动作场景机械压到 5（机械取下限）
- ❌ 加无功能镜头凑数

**输出示例**：
```
本段选择 6 个分镜，原因：4 个情绪节拍主镜头 + 1 个手部细节辅助镜头 + 1 个动作标点快切镜头。
```

## Phase 5 · 分镜生成

每段大分镜下生成 5-8 个分镜（具体由 4.5.5 决策机制决定）。

### 5.0 内部四问（每镜必答，不输出 · Layer 3 直达机制）

> **每个分镜生成前，内部完成四问**。四问的答案不进入输出文档，但任何一问失败 → 该镜头不生成或重做。
> **特别说明**：Q4 仅做内部校验，节拍号与情境 ID **不写进分镜标题或正文**——它们只在「本段情境对照」中向用户展示。

```
Q1：这个镜头服务于情绪锚点表的【哪一个节拍 + 哪一个微观瞬间】？
    ✅ 合格答案："服务于节拍 3·露夏抬头瞬间的克服内心障碍"
    ❌ 不合格答案："让画面更丰富" / "建立环境感" / "好看"
    答不出来 → 该镜头无效，删除或重做

Q2：删掉这个镜头，情绪/动作能否成立？
    ✅ "不能成立"——观众会接收不到节拍 3 的关键情绪 → 镜头有效
    ❌ "能成立"——只是锦上添花 → 删除（为切而切）

Q3：有没有更好的视听方式表达同一个情绪？
    比如：用一个吸管搅拌的手部微距 代替 一个露夏侧脸特写，
         哪个更能传递"克服内心障碍"？
    有更好方式 → 替换；没有 → 保留当前镜头

Q4：本镜的情境 ID 校验（内部对账，不进输出）
    
    分两条校验路径：
    
    ▸ 主镜头【分镜 X】路径：
       (a) 情境 ID = E__（来自情绪锚点表节拍 N）
       (b) 核心组合：__+__+__ 已全部应用（80% 权重锁死项）
       (c) 雷区：未触碰 / 触碰 AX 但合法解锁，理由：白名单第 N 项「关键词」
       (d) 标题：【分镜 X】（不带任何编号或 ID）
       (e) 解锁标注：如解锁 A 类，机位/构图字段已含简注
       → 任一不合格 → 重做
    
    ▸ 辅助镜头【分镜 X · 辅助镜头】路径：
       (a) 服务节拍：节拍 N（同样来自情绪锚点表）
       (b) 补充信息类型：空间 / 反应 / 物件 / 细节 / 衔接 / 具象转译 之一
       (c) 是否踩了该 ID 的"反例"清单？→ 否
       (d) 是否踩了 B 类工程性雷区？→ 否
       (e) 焦段/机位/构图允许偏离核心组合，但不违反反例
       → 任一不合格 → 重做或降级删除
    
    ▸ 快切镜头【分镜 X · 快切镜头】路径：
       按辅助镜头路径校验 + 补充检查：
       (f) 是否服务 E03/E06/E11 的节奏需要 或 ≤ 1 秒标点
       (g) 6 字段是否完整（不允许因快而省略）

    特殊：用户自定义 EX 系列
       - 内部记录"此 ID 来自用户在第 X 轮的自定义"
       - 主镜头按用户提供的核心组合校验
       - 辅助镜头规则同上
```

> **Q4 是 Layer 3 直达机制的核心**——它强制 LLM 在生成前对账"主镜头 vs 辅助镜头"的不同标准，但 ID 只用于内部对账，不污染输出。

### 5.0bis 首镜衔接对账（基础衔接默认保留，强连续时加点位对账 · 内部不输出 · Layer 6 直达机制）

> **触发条件**：当前正在生成的是大分镜 N+1（N ≥ 1），上一段 B0N 已生成且已输出过【B0N 跨段衔接卡】。
> **作用**：抵御 AI 视频生成模型逐段独立生成时的状态漂移（轴线翻转 / 服装突变 / 物件状态丢失 / 同景别连切等）。
> **执行时机**：在生成 B0(N+1) 第一个分镜（首镜）之前，必须按上一段的衔接卡 11 项**逐条对账**。
> **强连续增强**：如果本段属于同场景连续、回切同场景、批量生成易穿帮，或用户明确要求保持站位 / 空间调度，则在基础对账之外加点位级对账：A/B/C 点位、移动路线、摄影机安全区、禁止错误站位。
> **普通衔接段**：仍执行基础衔接对账，但不强制使用调度图、点位表和禁止错误点位。

```
【B0(N+1) 首镜衔接对账】（按 B0N 衔接卡 11 项核对）

□ ① 轴线侧 — 本段首镜机位仍在 ___ 侧 ✓
   - 越线 → 必须明示越线情境（合法越轴：仪式性追随 / 主观 POV 切换 / 蒙太奇）
□ ② 景别 — 本段首镜景别 ___，上段末镜 ___
   - 同景别连切 → 调整为一级跳或两级跳，除非声明 jump cut 焦虑感
□ ③ 运镜衔接模式 — 本段首镜运镜与上段末镜组合属于：
   □ 同向（能量持续） □ 反向（心理张力） □ 静切动（情绪激发）
   □ 动切静（情绪沉淀） □ 同质叠加（节奏稳定）
   - 不属于任一模式 → 调整运镜或重做
□ ④ 视线匹配 — 上段末镜角色视线 → 画面 ___ 侧
   - 本段首镜接住该方向 ✓ / 否 → 用反应镜头 / 视线追随 / 物件转场 补
□ ⑤ 角色姿态延续 — 本段首镜 [角色] 姿态延续度 ≥ 60% ✓
   - 跳跃过大 → 加一个过场镜头补足"中间动作"
□ ⑥ 服装一致 — 本段首镜服装与上段一致 ✓
   - 否 → 必须有合法换装情境（剧本明示 / 跳时 / 闪回）
□ ⑦ 道具状态延续 — 本段涉及道具状态与上段延续 ✓
   - 否 → 必须写入"限制"字段强制约束 AI（如「限制：杯中奶茶量保持半杯，与上一镜一致」）
□ ⑧ 光线/时间延续 — 本段光线/时间与上段一致 ✓
   - 否 → 必须在转场类型中声明（明确跳时 / 跨场景）
□ ⑨ 情绪能量延续 — 本段开镜情绪是上段余韵的承接？
   - 是承接 → 保持能量曲线
   - 是合法转折点 → 必须服务于情绪锚点表的节拍变化
□ ⑩ 转场类型一致性 — 上段声明的转场类型与本段实际开镜方式吻合？
□ ⑪ 平台节奏接力 — 本段首镜是否承接上段的观看理由 / 情绪余韵 / 信息增量？
   - 否 → 调整本段首镜钩子或补一个动作 / 信息标点镜头

任一不通过 → 重做本段首镜或回头修上段末镜（衔接卡也同步更新）。
全部通过 → 进入 5.0 内部四问 → 5.1 生成首镜。
```

> **本对账是 Layer 6 直达机制的核心**——它在 LLM 注意力衰减最严重的"段间跨越点"强制对账，与 5.0 内部四问（Layer 3）、5.4 成片预演（Layer 5）形成立体防护。

#### 5.1.3 机位字段强制模板（防摄影术语模糊）

机位字段**禁止**只写「仰拍近景 / 平视中景 / 俯拍全景 / 过肩近景」这类抽象术语。
**必须**按以下结构写清主体相对位置：

```
机位：摄影机位于 [主体/对象] 的 [正面/背后/左前45°/右前45°/左侧/右侧/过肩谁拍谁/主观POV]，
      高度在 [眼平/胸口/腰部/膝盖/地面/头顶]，
      以 [平视/仰拍/俯拍/鸟瞰/倾斜] 拍摄 [主体部位/动作]，
      景别为 [远景/全景/中景/近景/特写/超特写]。
```

**强约束**：
1. 仰拍/俯拍 → 必须说明"拍谁、从哪里拍、高度在哪里"
2. 过肩镜头 → 必须写"过谁的肩拍谁"
3. 多人镜头 → 必须写清主体与次主体身份
4. 微距/超特写 → 必须写主体占画面的位置和比例
5. 如果资产库提供 `SCV` 多角度空间包，机位句尾必须写明本镜推荐场景角度图，例如：`场景角度参考：SC001_V02_反向空景，只参考反打方向、空间透视、门窗/家具相对位置和固定光源，不参考人物或剧情动作。`

**对照例子**：

| ❌ 错误 | ✅ 正确 |
|---|---|
| 仰拍近景 | 摄影机位于少年正前方偏右 15°，高度在少年胸口以下，向上仰拍少年抬头的脸，近景。 |
| 平视中景 | 摄影机位于长老席正前方中轴线，眼平高度，平视拍少年跪在中央与六名长老形成对称关系，中景。 |
| 过肩近景 | 摄影机位于林砚左后方，过林砚右肩拍苏眠低头搅拌奶茶，眼平高度，近景。 |
| 俯拍特写 | 摄影机位于烟灰缸正上方约 30cm 处，垂直俯拍烟头按入烟灰缸的瞬间，超特写，烟灰缸占满画面。 |

#### 5.1.3.1 摄影机行为锁规则

摄影机行为锁用于约束“镜头到底怎么拍”，不是给运镜字段堆名词。04 输出给 06 前，必须把行为锁落到 `机位`、`运镜` 和 `限制` 三个字段里：

```text
机位：摄影机在哪里、离谁多远、高度在哪里、朝向谁或哪个动作。
运镜：摄影机使用什么行为类型、向哪里运动、速度如何、稳定程度如何、从哪里开始到哪里停住。
限制：禁止随机漂移、禁止无动机变焦、禁止越轴、禁止突然换机位、禁止手持强度失控。
```

每个摄影机行为锁至少判断 8 项：

1. **行为类型**：固定 / 手持 / 稳定器 / 跟拍 / 退拍 / 推拉 / 横移 / 环绕 / 升降 / 摇镜 / 甩镜 / 遮挡转场 / 焦点转移。
2. **摄影机位置**：主体正面、背后、左前 45°、右侧、过肩、窗外、柜台外、车内/车外、人物前方倒退。
3. **摄影机距离**：贴身、近景距离、中景距离、远距离观察、前景遮挡后方观察。
4. **高度与角度**：眼平、胸口、腰部、低位、头顶、平视、仰拍、俯拍、倾斜。
5. **运动方向**：推近、后撤、横移、侧跟、背跟、前导倒退、环绕、升起、下降、摇向目标。
6. **稳定程度**：完全稳定、极轻微微移、手持呼吸感、明显手持、剧烈晃动。
7. **速度节奏**：极慢、缓慢、同步跟随、快速、突然甩动、冲击瞬间震动一次。
8. **起止状态**：从哪个构图开始，跟随哪个动作，停在哪个景别或物件上。

| 行为锁 | 适合场景 | 04 可写法 | 禁止项 |
|---|---|---|---|
| 固定锁 | 对峙、审判、仪式感、冷静观察、权力关系 | 运镜：固定镜头，摄影机保持在茶几正前方眼平中景，不推拉不摇移，只让角色动作改变画面。 | 禁止随机漂移、自动推近、无动机变焦。 |
| 手持微动 | 克制焦虑、私密跟随、轻微纪录片感 | 运镜：手持微动，摄影机在角色右前方近景距离，随呼吸有轻微上下浮动，主体始终在画面右三分之一。 | 禁止剧烈晃动、禁止晃到主体出画。 |
| 手持跟拍 | 逃亡、追逐、慌乱移动、主观压迫 | 运镜：手持侧跟角色快步穿过走廊，镜头与角色肩膀保持约 1 米距离，速度同步，转弯时轻微甩动后重新稳住。 | 禁止突然越到角色另一侧，禁止丢失方向。 |
| 稳定器跟拍 | 穿场、进入空间、人物带观众移动 | 运镜：稳定器从角色背后三步距离跟拍，平稳穿过人群，保持角色后脑和肩线在画面中央。 | 禁止手持晃动、禁止穿过墙体或人群。 |
| 前导倒退跟拍 | 角色逼近、压迫感、边走边说 | 运镜：摄影机在角色正前方倒退跟拍，保持胸口高度中近景，角色每前进一步镜头同步后退。 | 禁止后退速度忽快忽慢，禁止角色撞镜头。 |
| 退拍 / 后撤 | 危险逼近、冲击、空间揭示 | 运镜：主体突然冲向镜头，接近瞬间摄影机快速后撤到广角全景，露出身后的空间和阻挡物。 | 禁止无动机后撤，禁止后撤后空间结构改变。 |
| 推近 / 拉远 | 情绪聚焦、真相揭示、孤立人物 | 运镜：从中景缓慢推近到眼睛特写，速度逐渐变慢，在眼神停住；或从手部特写缓慢拉远露出完整房间。 | 禁止推拉同时乱切，禁止只为“电影感”慢推。 |
| 横移 / 环绕 / 升降 | 空间关系、多人调度、权力变化 | 运镜：摄影机沿桌边从左向右横移，依次露出三人站位；或半环绕角色 90°，最后停在其正面。 | 禁止绕到轴线反侧，禁止连续大角度炫技。 |
| 摇镜 / 甩镜 / 遮挡 | 视线引导、快速换角度、自然转场 | 运镜：角色视线转向门口后，摄影机跟随视线快速摇向门缝；前景路人完全遮住画面时切入下一角度。 | 禁止无目标甩镜，禁止遮挡后空间关系反掉。 |
| 焦点行为 | 信息揭示、暗线物件、人物关系转移 | 运镜：固定构图内先让前景杯子清晰，随后 rack focus 到后景角色眼神，摄影机不移动。 | 禁止焦点转移对象不明确，禁止同时推拉造成混乱。 |

选择规则：

- 普通文戏优先使用固定、极轻微推拉、稳定器轻跟，不要强行手持或复杂运动。
- 强情绪、追逐、逃亡、暴怒、主观恐惧可以升级为手持微动、手持跟拍或手持快摇。
- 仪式感、神性、威严、审判、冷静决断默认避免明显手持，除非剧本需要打破秩序。
- 同一段 4-8 秒视频单元最多 1 个核心摄影机行为；10-15 秒最多 2-3 个，且必须能说明情绪或动作功能。
- 如果启用 SCV/MAP/SB，摄影机行为不得越过已锁定的摄影机安全区、轴线、窗内外/柜台内外/车内外关系。

#### 5.1.4 11 必填字段说明

1. **焦段**：变量取值（亲密=85-200mm长焦 / 客观=35-50mm标准 / 环境=14-24mm广角 / 物件=微距）
2. **光圈**：变量取值（情绪聚焦=大光圈虚化背景 / 全景叙事=小光圈大景深）
3. **景深与焦点锁**：必须把光圈效果转成可见控制。写清浅景深/中景深/大景深，焦点第 0 秒锁定在哪里，段内是否拉焦/跟焦，焦点最后落在哪里；写清前景/中景/背景谁清晰、谁轻微虚化、谁完全虚化；微距、道具特写、眼神特写必须点名焦点落点，例如“焦点锁定在烟头红色火星 / 女主右眼湿光 / 手机裂纹”。禁止只写“背景虚化”。
4. **机位**：必须按 5.1.3 模板写清"机位置 + 高度 + 拍摄角度 + 景别 + 主体"。**触碰 A 类雷区且合法解锁时必须简注**：例如 `…正面居中（**A1 解锁·白名单 ③ 对峙瞬间**）`。如启用 SCV，本字段还要说明使用哪张角度图和只参考什么。
5. **构图**：变量取值。**微距/超特写必须写明"什么主体占满画面"**。**触碰 A 类雷区且合法解锁时简注同上**
6. **运镜**：必须写成摄影机行为锁句，不只写名词。中文歧义时加英文（详见第 7 节）。如按需启用 04b 速查库，只把选中的组合转写成具体摄影机行为，不写组合编号或子库名称；例如把“冲击后撤”写成“主体冲向镜头，接近瞬间摄影机快速后撤到广角全景，露出身后的阻挡物并稳住”。固定镜头也要写成“固定在哪里、看向哪里、禁止推拉摇移”。如出现 rack focus / 焦点转移，`运镜` 写摄影机是否移动和焦点转移节奏，`景深与焦点锁` 写清焦点对象、清晰层次和禁止跑焦。
7. **主体动作/表情**：变量取值。只写可见动作、微表情、呼吸、身体细节、口型动作和情绪弧线，不承载完整台词文本。如果本镜承担情绪变化，不能只写情绪标签，必须写成“起始状态 → 微表情变化 → 身体反应 → 结尾状态”的表演过程。动作戏必须写“起手 → 接触点 → 受力结果 → 反应 → 段末状态”，并按类型使用命中的 04b 子库规则；不要只写“激烈打斗”。
8. **台词与语气**：有对白时必须独立写原台词、说话者、语气、音量、语速和口型要求，例如 `台词与语气：苏眠低声、压着哭腔、音量很轻、语速放慢地说：“我知道了。”口型与原台词一致。` 无对白时写 `台词与语气：无对白`。画外音、旁白也写入本字段，并在机位或主体动作中说明画面主体。
9. **光影**：必须写成可执行布光说明。不要只写“电影感光影”“高级光影”“氛围感”。至少覆盖以下 6 项中的 4 项；重点情绪镜头、强连续段和 Seedance 输出段必须尽量覆盖 6 项：
   - 光源来源与方向：窗光、台灯、霓虹、路灯、屏幕光、烛光、门缝光；从左前 / 右后 / 顶部 / 背后 / 侧面进入。
   - 主光与辅光：主光照亮谁，辅光是否保留暗部细节，是否禁止整体补光。
   - 亮区与暗区：人物哪半张脸、哪只手、哪个道具、背景哪块亮；前景、走廊、墙面、背光面哪里必须暗。
   - 轮廓与分离：是否有轮廓光、逆光、发丝光、肩线高光，把人物从背景里分出来。
   - 色温与反差：冷白 / 暖黄 / 霓虹混色；低反差 / 高反差；可写“脸部明暗比约 1:3”。
   - 空气与阴影：薄雾、尘埃、雨雾、丁达尔光束、硬边阴影、柔和阴影、百叶窗切割阴影。
   示例：`光影：右侧台灯作暖色主光，只照亮苏眠右半张脸和手中的杯子；左侧脸颊落入柔暗阴影；窗外冷白月光从左后方形成窄轮廓光勾出肩线；茶几前景压暗，背景走廊低照度；脸部明暗比约 1:3，禁止整体提亮。`
10. **限制**：必须写清保持什么、禁止什么。普通衔接段按原 04 规则写角色、场景、道具、文字、光线限制；强连续段叠加“正确状态 + 禁止错误状态”，例如：`限制：林墨从本视频第一帧开始站在茶几左侧 A2，身体朝向苏眠；不得让林墨出现在门口 A1；摄影机必须位于 C1 安全区，不越过人物轴线。` 如果本段没有人群需求，写 `不允许出现额外人物、路人、群演`；如果启用人群，写 `路人不得看镜头，不得遮挡主角脸部和关键动作，不要复制粘贴同脸路人`。动作戏还要写清禁止身体比例变形、武器忽大忽小、攻击方向错乱、接触点消失、角色瞬移或跳到错误侧。景深镜头还要禁止焦点漂到无关背景、灯牌、路人、空墙、随机道具或错误人物脸上。
11. **下一段衔接**：必须写本镜结束时可被下一段继承的姿态、视线、道具、光线和镜头方向，例如“镜头停在小雅抬头看向画面右侧的反应”“段末出站口外便利店冷白灯牌亮起”。分镜编号只能作为括号备注；强连续段再加下一段首帧点位。

#### 5.1.4.1 情绪表演拆解规则

当剧本出现“悲伤、愤怒、害怕、心动、委屈、压抑、崩溃、冷静、隐忍”等情绪词时，必须转译成可见表演。优先使用以下结构压缩进 `主体动作/表情`：

```text
主体动作/表情：[角色] [起始动作]，[眼神/眨眼变化]，[嘴部/下颌变化]，[呼吸/肩颈/手部变化]，[情绪逐渐压上来或被压住]，[口型动作或说话前后的身体反应]。
台词与语气：[有对白时写说话者、原台词、语气、音量、语速和口型要求；无对白时写无对白]。
限制：不要把情绪演成夸张哭脸 / 咆哮 / 突然大哭 / 过度瞪眼 / 大幅度肢体崩溃；除非剧本明确爆发，否则保持克制。
```

可用微表情词库：

- 眼神：视线下垂、短暂失焦、避开对方、看向地面、抬眼半拍又收回、眼眶微湿但不落泪。
- 眨眼：眨眼变慢、眨眼变频繁、眼皮沉、强忍不眨、眨眼后视线重新聚焦。
- 嘴部与下颌：抿唇、嘴角轻颤、下唇收紧、下颌绷住、喉咙轻吞咽、话到嘴边停住。
- 呼吸与身体：呼吸变浅、肩膀收紧、手指攥住衣角、指节发白、身体后撤半步、重心不稳但站住。
- 声音：音量降低、语速变慢、尾音压住、气声增多、句中短暂停顿。

表情强度必须有阶梯，不能直接跳到最大表情：

```text
0 级：表面平静，只有视线、眨眼、呼吸或手指轻微变化。
1 级：微表情泄露，抿唇、吞咽、嘴角轻颤、下颌绷紧。
2 级：情绪压上来，声音变轻/变硬，脸部肌肉开始失控，身体重心变化。
3 级：压不住，眼泪、颤音、肩膀轻颤、短促吸气出现。
4 级：明确爆发，大哭、怒吼、尖叫、崩溃；必须有 1-3 级铺垫，除非剧本要求突然爆发。
```

示例：

```text
主体动作/表情：苏眠听完后没有立刻哭，眼神轻微下垂，眨眼变慢，嘴唇抿住又松开，喉咙轻轻吞咽，呼吸变浅，嘴角短暂轻颤但努力保持平静，开口时口型很小。
台词与语气：苏眠低声、克制、音量很轻、语速放慢地说：“我知道了。”口型与原台词一致。
限制：不要流泪，不要夸张哭脸，不要皱眉过度，不要突然崩溃大哭，不要大幅度低头捂脸。
```

如果剧情明确要求“大哭”，也不能只写“大哭”。必须写成过程：

```text
主体动作/表情：苏眠先愣住半秒，眼神失焦，眨眼变慢，嘴唇用力抿住；她试图吸气说话却发不出声，眼眶迅速蓄泪，第一滴泪从右眼滑下，肩膀开始轻颤，最后才压不住哭声，低头用手背擦泪。
限制：不要第一帧就满脸泪水，不要张大嘴夸张嚎哭，不要跪地崩溃，不要大幅度捂脸遮住表情；哭泣必须从克制到失控逐步发生。
```

**解锁标注的目的**：让用户能一眼看到"这里居中/头顶贴边等违反默认规则的构图是合法的"——透明化不能藏起来。但**情境 ID 和节拍号不写在分镜本体**，只在前置情境对照表里出现。

#### 5.1.5 主镜头与辅助镜头的分工

每个情绪节拍下，分镜分两类：

| 类型 | 标题 | 是否锁定情境 ID 核心组合 | 用途 |
|---|---|---|---|
| **主镜头** | `【分镜 X】` | ✅ 必须满足该节拍情境 ID 的 80% 核心组合 | 承担该节拍的情绪表达主体 |
| **辅助镜头** | `【分镜 X · 辅助镜头】` | ❌ 允许偏离核心组合 | 补充主镜头无法表达的信息 |
| **快切镜头** | `【分镜 X · 快切镜头】` | 视情况（动作类多为辅助） | 标点动作 / 节奏变化 |

**核心规则**：
- **每个节拍至少 1 个主镜头** —— 主镜头锁定情境 ID 的焦段/光圈/景深与焦点锁/机位/构图/运镜核心组合
- **辅助镜头可使用任意焦段/机位/景别**，包括：
  - 空间关系镜头（35-50mm 中焦展示位置）
  - 反应镜头（中景捕捉次主体反应）
  - 物件信息镜头（微距让观众看清关键道具）
  - 手部/眼神细节镜头
  - 动作衔接镜头
- **辅助镜头必须能内部回答**：
  - 它服务哪个节拍？
  - 它补充了主镜头无法表达的哪类信息？
- **辅助镜头允许偏离核心组合，但禁止违反该 ID 的"反例"或踩 B 类雷区**

### 5.2 快切镜头规则（统一规范）

**触发条件**（满足任一即必须标注 `· 快切镜头`）：
1. 镜头时长约 ≤ 1 秒
2. 运镜字段出现 "快切 / Cut In / 0.5 秒 / 0.5-1 秒 / 极快切"
3. 服务于 E03 紧张追逐 / E06 暴怒爆发 / E11 干脆决断的节奏需要

**强约束**：
- 快切镜头**仍必须写完整 10 个必填字段**——不允许因为快而省略焦段/光圈/景深与焦点锁/机位/构图/运镜/主体动作/光影/限制/下一段衔接
- 快切镜头标题不写情境 ID，只写：`【分镜 X · 快切镜头】`
- 快切镜头**仍要通过内部四问 Q2**——能删除则删除，禁止为节奏乱加
- E03/E06/E11 默认允许快切，但仍受 Q2 约束

### 5.3 "真不需要"的字段处理

- 11 个字段默认都要写。固定镜头也要写成 `运镜：固定镜头`；无对白镜头在 `台词与语气` 字段写“无对白”，并让角色通过动作/表情完成节拍。
- 如果是空镜或物件镜头，主体动作/表情写环境或物件的可见变化，例如“窗帘被风掀起半寸”“手机背面朝上震动一次”。
- `下一段衔接` 不能留空。普通衔接段保持原有简洁写法；强连续段在原写法后追加点位、道具、光线和摄影机安全区。
- **微距/超特写的"构图"字段强制必填**——必须写明主体占满画面。

### 5.4 成片预演（生成完所有镜头后内部检查 · 不输出）

> 这是**三层验证机制的第三层**，生成完毕后在输出前内部过一遍。

```
成片预演检查项（内部 · Layer 5 直达机制）：

  ① 把该大分镜下的所有分镜按顺序在脑中"放电影"
  ② 检查观众实际接收到的情绪曲线 = 情绪锚点表预设的曲线
  ③ 检查分镜衔接 5 维度（轴线/视线/动作/物件/景别跳跃）是否项项过关
  ④ 检查运镜衔接是否落在 5 模式中（同向/反向/静切动/动切静/同质叠加）
  ⑤ 检查构图雷区：
     - A 类艺术性雷区是否合法解锁（命中白名单 + 配套后缀约束）
     - B 类工程性雷区是否完全规避
  ⑥ 检查标题规范（输出干净度）：
     - 主镜头：【分镜 X】 ← 不带节拍号、不带情境 ID
     - 辅助镜头：【分镜 X · 辅助镜头】
     - 快切镜头：【分镜 X · 快切镜头】
     - 任何含"小分镜""节拍 N""Exx"的标题 → 必须清洗
     - 解锁雷区的镜头：机位/构图字段须有"AX 解锁·白名单第 N 项·关键词"简注
     - 节拍号与情境 ID 只能出现在「本段情境对照」里，分镜本体禁止出现
  ⑦ 检查主镜头核心组合（80% 权重 · 主镜头才锁定）：
     - 每个情绪节拍至少 1 个【分镜 X】主镜头满足该节拍情境 ID 的核心组合
     - 缺失主镜头 → 把该节拍下最贴近核心组合的辅助镜头升格为主镜头
     - 若所有镜头都套同一核心组合导致单一化 → 把至少 1 个降格为【分镜 X · 辅助镜头】
     - 增强项使用次数：一段大分镜内最多 1 个镜头用增强项
  ⑧ 检查辅助镜头合规性：
     - 标题已标【分镜 X · 辅助镜头】
     - 内部能回答"它服务哪个节拍 + 补充了哪类信息"
     - 未踩该 ID 的"反例"清单
     - 未踩 B 类工程性雷区
  ⑨ ★ 焦段平衡检查（防镜头语言坍缩）：
     - 单个大分镜内，**除非情境明确要求极端风格**，不允许 70% 以上镜头使用同一焦段类型
       焦段类型四档：广角(≤35mm) / 标准(35-50mm) / 长焦(85mm+) / 微距
     - 静态对白 / 仪式 / 心理戏：允许至少 1 个 35-50mm 空间关系镜头
     - 追逐 / 暴怒 / 被困 / 神性：可用广角，但必须服务空间压力或运动张力
     - 检查不通过 → 把若干主镜头同质组合改为辅助镜头，焦段错开

  ⑨.1 ★ 景深与焦点锁检查（防失焦和虚化乱抢戏）：
     - 每个分镜是否有 `景深与焦点锁` 字段
     - 是否写清浅/中/大景深、焦点起点、焦点落点、前中后景清晰/虚化关系
     - 拉焦/rack focus/跟焦镜头是否写清转移对象、触发时机、持续时间和最终落点
     - 微距、道具、眼神特写是否点名焦点落在具体部位或物件细节
     - 检查不通过 → 补写焦点锁，并在限制字段加入禁止跑焦对象

  ⑩ ★ 跨段衔接核对（仅在生成多段大分镜时执行 · Layer 6）：
     - 本段是否输出了【B0X 跨段衔接卡】11 项？（Phase 5.5 强制输出，缺一不可）
     - 本段是否是 N+1 段（N≥1）？是 → 是否在生成首镜前执行了【首镜衔接对账】（5.0bis）？
     - 跨段 7 维度（详见 12.4.1）是否项项过关：
       1) 轴线 / 2) 视线 / 3) 动作 / 4) 物件 / 5) 景别 / 6) 时间连续性 / 7) 状态延续
     - 转场类型声明（同时刻同场景延续 / 隐含跳秒 / 明确跳时 / 跨场景硬切 / 闪回平行剪辑）
       与本段实际开镜方式是否吻合？
     - AI 易错点是否用"限制"字段强约束（服装/道具/光线/姿态）？
     - 不过 → 重做接缝处镜头（B0N 末镜或 B0(N+1) 首镜）→ 同步更新衔接卡

  任何一项不过 → 重做问题镜头 → 重新验证
  三项以上不过 → 重设计该段大分镜
```

如果在预演中发现**剧本本身的问题**（如情绪跳拍/逻辑不顺）而非分镜问题：
```
【需要你先决策】
成片预演发现二层问题：
- 表层：分镜衔接有断点
- 深层：剧本本身缺一个过渡动作（如露夏从到店到提议中间缺一个犹豫动作）
选择：
- A：我硬拍（加镜头补足过渡，但可能偏离原剧本）
- B：你回 Skill 4 加一句动作/台词，再回来分镜
```

## Phase 5.5 · 跨段衔接卡（默认输出 · 强连续时增强 · Layer 6 直达机制）

> **强制输出**：每段大分镜的所有分镜（含主/辅/快切）生成完毕后、Phase 6 通用后缀拼接之前，**必须**输出本段的【跨段衔接卡】。
> **作用**：把当前段末镜的 11 项关键状态结构化打包，传递给下一段（B0(N+1)）的 5.0bis 首镜对账使用。
> **升级原则**：保留原来的基础衔接卡和“下一段衔接 / 段末状态”写法；强连续段只是在此基础上增加点位、调度图、摄影机安全区、禁止错误站位等约束。
> **普通衔接段**：仍输出完整衔接卡，但不强制使用调度图和点位表。

### 5.5.1 衔接卡格式

```
═════════════════════════════════════════
【B0N 跨段衔接卡】（向 B0(N+1) 传递）
═════════════════════════════════════════

① 末镜机位轴线侧：A 侧 / B 侧（标注两人之间假想轴线的哪一侧；多角色场景注明主轴定义）
② 末镜景别：远景 / 全景 / 中景 / 近景 / 特写 / 超特写
③ 末镜运镜方向：固定 / 推 / 拉 / 横移[方向] / 升 / 降 / 手持 / 跟拍 / 快切
④ 末镜视线方向：[角色] → 画面[方位]（如 露夏 → 画面左外）
                / 无角色（如门帘静止 / 空镜）
⑤ 角色姿态：
   - [角色 1] = ____（位置 + 身体朝向 + 关键动作残留）
   - [角色 2] = ____
⑥ 服装状态：
   - [角色 1] = ____（颜色 / 版型 / 配饰，越具体越好）
   - [角色 2] = ____
⑦ 关键道具状态：
   - [道具 1] = ____（位置 / 数量 / 状态）
   - [道具 2] = ____
   - 环境元素 = ____（霓虹 / 雨 / 烟雾 / 风等）
⑧ 光线/时间：____（光源 + 色温 + 时间感：连续 / 隐含跳秒 / 明确跳时）
⑨ 情绪余韵：____（一句话 + 能量等级：低 / 中 / 高 / 顶点）
⑩ 必延续清单：____ + ____ + ____（明示下一段必须延续哪几项，不可漂移）
⑪ 平台节奏接力：本段钩子完成情况 + 信息增量 + 情绪余韵 + 下一段开场应承接的观看理由

【转场类型声明】（勾选其一）：
□ 同时刻同场景延续（默认 · 必须前 10 项全延续，第 11 项承接观看理由）
□ 同场景隐含跳秒（≤ 1 分钟 · 时间感 + 情绪可微调，其他延续）
□ 同场景明确跳时（>1 分钟 · 必须用过场镜头或字幕标注，状态可重置）
□ 跨场景硬切转场（必须配套：导演意图白名单 / B-roll / 音乐桥）
□ 闪回 / 梦境 / 平行剪辑（必须声明非线性 + 调色/滤镜区隔）
═════════════════════════════════════════
```

### 5.5.2 衔接卡填写硬约束

- **11 项不可缺**：缺任一项 → 5.0bis 对账无法进行 → Phase 5.4 第 ⑩ 项核对必然不通过
- **道具状态必写具体值**：不允许写"延续上一镜"——必须写"半杯奶茶 + 吸管推到杯口右侧 + 烟灰缸内有刚摁灭烟头与一缕余烟"
- **服装颜色与版型不允许省略**：AI 视频模型最容易在此处漂移
- **必延续清单 ⑩ 必须明示 3 项以上**：普通衔接段写角色/道具/光线/情绪等基础延续；强连续段额外写点位、轴线、摄影机安全区
- **转场类型必须勾选其一**：默认是「同时刻同场景延续」；如选其他类型，必须在事件交代里同步说明
- **强连续段必须补充点位**：例如 `林墨=A2 茶几左侧，苏眠=B2 沙发右端，摄影机=C1 茶几前方安全区`；普通衔接段不强制点位化。

### 5.5.3 衔接卡的 5 个使用位置

```
位置 1：B0N 段末（Phase 5.5 输出）
位置 2：B0(N+1) 段首（Phase 5.0bis 内部对账，不输出）
位置 3：B0(N+1) 段大分镜独立前置单元的"本段第一帧状态"（把 B0N 末端状态改写成当前段可见首帧）
位置 4：B0(N+1) 各分镜的"限制"字段（把正确点位、禁止错误点位、道具和光线延续写成强约束 prompt）
位置 5：Phase 5.4 第 ⑩ 项跨段核对（验证）
```

### 5.5.4 衔接卡的最后一段（B0_last）特殊处理

如果 B0N 是本次会话的最后一段（用户剧本结束）：

- 仍必须输出完整衔接卡（11 项不省略）
- 第 ⑩ 项「必延续清单」改填"本场结束"而非延续清单
- 转场类型勾选"本场结束 + 下场（如有）为场景切换"
- 用途：用户后续 `/继续` 添加新剧本时，下一批输出可以承接情绪余韵

## Phase 6 · 通用后缀拼接

如 Phase 0 用户选择启用，则在所有大分镜末尾加一段通用后缀。

### 后缀生成逻辑

不预设档位，根据剧本反推。旧版手感必须保留固定九项结构，不要压成一段泛化说明。建议结构：

```
─── 通用后缀 ───
音效说明：____（生成同步音频/不生成音频；只写对白、环境声和关键同步音效；不生成 BGM，BGM 交给 07 后期声音设计）
一致性约束：____（人物脸型、发型、服装、体态、场景空间、人物位置关系保持连续）
道具约束：____（关键道具数量、位置、朝向、屏幕/裂纹/材质状态保持连续；同一件道具不得复制；道具移动后原位置必须变为空）
文字约束：____（无字幕、无水印、无 Logo、无随机文字；如必须展示手机/纸条/证件/招牌文字，只允许指定内容）
光线约束：____（主光方向、实景光源、亮区/暗区、轮廓光、色温和明暗反差保持连续；禁止整体提亮或新增无来源面光）
风格约束：____（继承 ST/NP 的项目风格、人物审美、场景审美、画面质感、颗粒/渲染媒介和禁止项；必须写成自然语言，不写内部编号）
节奏约束：____（慢停顿、空镜和静默必须服务情绪压迫、悬念、关系变化、信息释放或动作蓄力；不做无功能空镜）
画面规格：____（画幅比例，写实/动画程度，清晰度，颗粒，反差，质感）
段末状态：____（下一段必须继承的角色姿态、手部位置、视线、情绪、道具状态、光线和镜头方向）
```

每一项都根据剧本类型/平台反推，不照搬模板。如果上游资产库已有 ST/CL/NP，通用后缀优先继承它们；如果当前分镜光影与 CL 冲突，以当前真实光源和剧情时段为准，只保留项目风格的质感、反差、颗粒/渲染媒介和风格禁止项。

### 询问最终确认

```
【后缀草案】
[已生成内容]

是否使用？
- "是" → 拼接进文档
- "改 [字段]: [新内容]" → 调整后再拼接
- "不要了" → 不拼接
```

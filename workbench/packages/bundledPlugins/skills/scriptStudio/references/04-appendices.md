# 附录 C：抽象→具象 视听转译案例库（持续积累）

## C.1 心理状态类

```
内心崩溃 →
  · 表演：手指在桌下捏紧另一只手
  · 镜头：桌下手部超特写（微距+大光圈）
  · 辅助：环境音下沉

强忍泪水 →
  · 表演：眼眶微红，鼻尖发红，嘴唇压紧不动
  · 镜头：面部特写（85mm长焦+大光圈）
  · 辅助：呼吸声放大

故作冷静 →
  · 表演：手指无意识摩挲杯沿，节奏比正常快 1.5 倍
  · 镜头：手部特写 + 面部特写来回切
  · 辅助：心跳声若有似无
```

## C.2 关系状态类

```
渐生情愫 →
  · 表演：抬头时机错位 0.3-0.5 秒；身体微微前倾
  · 镜头：双手特写（杯子距离变化）
  · 辅助：环境音渐弱，主体声放大

关系破裂 →
  · 表演：肢体远离；中间出现障碍物（杯子/烟灰缸）
  · 镜头：双人构图但景深拉开（一前一后虚化）
  · 辅助：背景嘈杂声忽然清晰

试探 →
  · 表演：动作慢一拍；眼神短暂上抬再下移
  · 镜头：搅拌动作的手部特写 + 眼神特写
  · 辅助：吸管碰杯壁声放大
```

## C.3 戏剧动作类

```
决断（接受/拒绝）→
  · 表演：物件状态突变（按熄烟头/合上书/放下杯）
  · 镜头：物件微距+快切
  · 辅助：动作音放大成"标点声"

时间停滞 →
  · 表演：所有人冻结
  · 镜头：高速摄影 + 灰尘悬浮
  · 辅助：全静音

不祥预感 →
  · 表演：角色眼神微微飘忽
  · 镜头：环境物件异动特写（蜡烛火苗、纸张、铃铛）
  · 辅助：环境音中插入低频
```

## C.4 类型化转译速查

| 类型 | 高频转译模式 |
|---|---|
| 武侠 | 决斗前 → 衣袖飘动特写 + 落叶悬空 + 环境音骤静 |
| 悬疑 | 信息揭示 → 物件细节微距 + 时间钟表特写 + 心跳音 |
| 喜剧 | 包袱抖出 → 主体表情冻结 + 周围反应快切 + 静音一拍 |
| 爱情 | 心动 → 慢镜头 + 长焦虚化背景 + 主体光线柔化 |
| 恐怖 | 危机临近 → 主体不知情的同时镜头露出威胁源 |
| 动画 | 情绪爆发 → 背景元素夸张化（彩色烟雾/光效/慢镜） |

# 附录 E：情境映射库详表（Layer 4 备查）

> **使用说明**：
> - 每个 ID 列出"核心组合（80%锁死）+ 辅助锚点（15%选 1-2）+ 增强项（5%情绪命中点）+ 反例（不能用什么）+ 配套后缀"
> - Phase 4.5 选定 ID 后，Phase 5 按此处规则合成镜头
> - 速查不命中时回查本附录的"适用情境"细分；仍找不到 → 询问用户授权自定义 ID
>
> **★ 80/15/5 权重规则的作用范围（重要）**：
> - **核心组合（80%锁死）只约束「主镜头【分镜 X】」**——每个情绪节拍至少 1 个主镜头必须完整套用
> - **辅助镜头【分镜 X · 辅助镜头】允许偏离核心组合**，可使用任意焦段/机位/景别（如 35-50mm 空间镜头、反应镜头、物件微距等），但**必须不踩「反例」清单 + 不踩 B 类工程性雷区**
> - **快切镜头【分镜 X · 快切镜头】参照辅助镜头**，但允许只服务节奏/标点功能
> - 增强项（5%）：一段大分镜内最多 1 个镜头使用
> - **反例清单是硬约束**：对主镜头/辅助镜头/快切镜头一视同仁，全部不允许触碰

## E01 · 主角觉醒（写实）

**适用情境**：
- 主角在剧本结构中"完成第一次决断 / 接受使命 / 跨过门槛"
- 写实剧（非漫改/非动画），克制风格
- 例：《拯救大兵》米勒队长决定继续任务、《肖申克》安迪计划越狱

**核心组合（80% 权重 · 锁死必用）**：
- 焦段：中焦 50-85mm
- 光圈：中等 f/4
- 机位：低角度仰拍 · 中景
- 运镜：缓慢轨道推（Slow Dolly In）

**辅助锚点（15% · 选 1-2）**：
- 顺光暖调（黄昏 / 室内暖光）
- 慢动作 0.5-0.75x
- 角色背景留出"天空感"或"开阔感"

**增强项（5% · 仅情绪命中点）**：
- 一个微距标点（眼神坚定瞬间 / 拳头握紧）

**反例（不要这么拍）**：
- ❌ 广角扭曲（破坏写实）
- ❌ 强对称居中（除非命中 A1 解锁）
- ❌ 手持晃动（破坏决断的稳定感）
- ❌ 冷光高反差（应该是温暖的觉醒，不是阴郁的觉醒）

**配套通用后缀**：
- 调色：电影级低饱和 + 暖中性
- 光线：自然光为主（黄昏 / 室内暖光）
- 渲染：写实风格 + 轻微胶片颗粒

## E02 · 反派登场（漫改/古装）

**适用情境**：
- 反派首次正式登场 / 权力凝固瞬间
- 漫改 / 古装 / 风格化作品（非纯写实）
- 例：《黑暗骑士》小丑医院出场、《复联》灭霸响指、《琅琊榜》梅长苏首次亮相

**核心组合（80% · 锁死）**：
- 焦段：广角 24-35mm
- 光圈：大光圈 f/2.0
- 机位：低角度仰拍 + 静态
- 运镜：固定 / 极轻微缓推

**辅助锚点（15%）**：
- 逆光剪影（背景亮 + 主体暗 = A6 解锁）
- 慢动作
- 风 / 烟雾 / 落叶等环境元素加持
- 长焦虚化"群臣朝贺式"背景

**增强项（5%）**：
- 一个鸟瞰镜头展示反派被环境"供奉"
- 或希区柯克变焦放大威严

**反例**：
- ❌ 暖光（反派要冷光）
- ❌ 平视（必须仰视 = 权力关系）
- ❌ 手持晃动（破坏威严）
- ❌ 中景以下景别（反派首次出场要全景或近景到头肩）

**配套通用后缀**：
- 调色：冷色 + 高对比 / 或单色调（红 / 黑 / 金）
- 光线：戏剧化侧光 / 逆光 / 顶光阴影
- 渲染：风格化（漫改 → 番剧分镜风；古装 → 工笔/水墨质感）
- 解锁后缀：必须含"权力凝固 / 风格化构图"

**解锁的雷区**：A1 正面居中（白名单 ⑥ 权力凝固）

## E03 · 紧张追逐

**适用情境**：
- 物理追逐（追杀 / 逃亡）/ 时间紧迫的解谜
- 例：《谍影重重》伯恩跑酷、《疾速追杀》、《1917》

**核心组合（80% · 锁死）**：
- 焦段：长焦 85-200mm
- 光圈：大光圈（背景虚化 = 失焦感）
- 机位：手持呼吸感 + 跟拍
- 运镜：手持快摇（Whip Pan） + 快切

**辅助锚点（15%）**：
- 主观镜头（POV）穿插
- 极短镜头（0.5-1 秒一切）
- 高速摄影 + 突然慢镜（节奏切换）

**增强项（5%）**：
- 一个鸟瞰镜头展示追逐空间关系
- 或子弹时间在关键转折点

**反例**：
- ❌ 固定镜头（破坏紧张感）
- ❌ 缓慢运镜（节奏不对）
- ❌ 长镜头（一个镜头 ≥ 5 秒不行）
- ❌ 对称居中（紧张需要不稳定构图）

**配套通用后缀**：
- 调色：高对比 + 略偏冷（除非户外日光）
- 光线：自然光 / 高动态范围
- 音效：脚步声 + 呼吸声放大；环境音保留
- 渲染：纪录片质感 / 类纪录片晃动

## E04 · 审讯对峙

**适用情境**：
- 审讯室 / 法庭 / 决斗前对峙 / 静态权力博弈
- 例：《沉默的羔羊》Hannibal vs Clarice、《十二怒汉》、《让子弹飞》三巨头碰头

**核心组合（80% · 锁死）**：
- 焦段：长焦 85-135mm
- 光圈：大光圈 f/2.0
- 机位：正面居中（**A1 解锁 · 白名单 ③ 对峙瞬间**） + 静态平视
- 运镜：固定 / 极缓的呼吸感

**辅助锚点（15%）**：
- 双向过肩切换（A 过肩看 B / B 过肩看 A）
- 长焦压缩双方距离
- 顶光制造眼窝阴影（强化压迫）

**增强项（5%）**：
- 一个微距标点（眼神 / 手指 / 嘴角的微动）
- 或希区柯克变焦在权力反转瞬间

**反例**：
- ❌ 手持（破坏对峙的"凝固感"）
- ❌ 广角（双方距离会变远，弱化压迫）
- ❌ 仰拍 / 俯拍（必须平视 = 双方对等的对峙）
- ❌ 快切（对峙要"长镜头压制"）

**配套通用后缀**：
- 调色：低饱和 + 高对比
- 光线：戏剧化顶光 / 单光源
- 解锁后缀：必须含"对峙构图 / 凝固张力"
- 限制：不允许背景音乐（静默才有压迫）

**解锁的雷区**：A1 正面居中（白名单 ③ 对峙瞬间）

## E05 · 孤独沉思

**适用情境**：
- 角色一人独处 / 思考 / 失意 / 等待
- 例：《海上钢琴师》1900 在船上、《银翼杀手 2049》K 走过废墟

**核心组合（80% · 锁死）**：
- 焦段：长焦 135-200mm
- 光圈：大光圈 f/1.8 - f/2.0
- 机位：背影 / 侧脸 + 中远景 + noseroom 留白
- 运镜：固定 / 极缓的拉远

**辅助锚点（15%）**：
- 大量负空间（noseroom / headroom 都很大）
- 自然光 / 窗光 / 路灯单光源
- 角色背对画面或半侧脸（不正面）

**增强项（5%）**：
- 一个空镜（环境物件无人 = 主观投射）
- 或一个反向衔接（推+拉创造抽离）

**反例**：
- ❌ 正面居中（孤独不是对峙）
- ❌ 大光圈不够（背景必须虚化或大量负空间）
- ❌ 暖光过满（孤独需要冷光或单光源）
- ❌ 手持（破坏沉思的静态）

**配套通用后缀**：
- 调色：低饱和 + 偏冷
- 光线：单光源 / 月光 / 路灯
- 音效：环境音 + 心跳/呼吸放大；可选钢琴极简
- 渲染：写实 + 略偏抽象的留白美学

## E06 · 暴怒爆发

**适用情境**：
- 角色情绪从压抑到爆发 / 暴力行为前一刻
- 例：《教父》Sonny 街头打妹夫、《老男孩》Oh Dae-su 走廊战

**核心组合（80% · 锁死）**：
- 焦段：广角 24-35mm
- 光圈：大光圈 f/2.0
- 机位：手持呼吸感 + 近景到中景
- 运镜：手持快摇 + 短暂同质叠加（多镜手持）

**辅助锚点（15%）**：
- 突然变焦（Crash Zoom）
- 主观镜头（角色视角看对象）
- 极快切（0.5 秒一镜）

**增强项（5%）**：
- 一个静切动衔接（前镜固定 → 突然手持爆发）
- 或一个微距标点（拳头握紧 / 牙关咬紧）

**反例**：
- ❌ 长焦（暴怒要广角的扭曲与压迫）
- ❌ 缓慢运镜（破坏节奏）
- ❌ 对称居中（暴怒需要不稳定）
- ❌ 长镜头一镜到底（除非有意"暴怒长镜头"风格如老男孩）

**配套通用后缀**：
- 调色：高对比 + 略偏暖（怒气）
- 光线：高动态范围 / 强阴影
- 音效：动作音放大 + 心跳低频；环境音突然消失（爆发瞬间）

## E07 · 暧昧试探

**适用情境**：
- 角色 A 对 B 有好感但不敢明说，表面闲聊里层试探
- 例：《花样年华》梁朝伟张曼玉对话戏、《爱在三部曲》、本案茶餐厅戏

**核心组合（80% · 锁死）**：
- 焦段：长焦 85-135mm
- 光圈：大光圈 f/1.8 - f/2.8
- 机位：过肩 + 中近景 + 静态
- 运镜：固定 / 极轻微缓推

**辅助锚点（15%）**：
- 手部特写（搅拌、摩挲、握杯）
- 眼神错位（抬头时机错开 0.3-0.5 秒）
- 背景音放大（吸管碰杯壁声、烟头烧灼声）

**增强项（5%）**：
- 一个微距标点（物件状态变化 = 心动的客观对应物）

**反例**：
- ❌ 广角扭曲（破坏私密感）
- ❌ 手持剧烈晃动（破坏冷静克制）
- ❌ 快切多镜（破坏暧昧的"凝固感"）
- ❌ 强光面光（暧昧需要侧光/柔光）

**配套通用后缀**：
- 调色：低饱和 + 暖中性
- 光线：环境光为主（茶餐厅暖黄光 / 窗光柔光）
- 音效：环境嘈杂保留（**B 类限制：保持背景人群声**）
- 渲染：写实 + 微弱胶片颗粒

## E08 · 内向退缩

**适用情境**：
- 角色害羞 / 不敢直视 / 退缩 / 自卑
- 多用于配角或某场戏的特定瞬间，不会持续整段戏

**核心组合（80% · 锁死）**：
- 焦段：长焦 85mm
- 光圈：大光圈
- 机位：过肩拍角色（**重点是从他人视角看他**）+ 近景
- 运镜：手持微动（轻微呼吸感，非剧烈）

**辅助锚点（15%）**：
- 角色低头或侧脸（不直视镜头/对手）
- 手部小动作（摸头发 / 搓手 / 摆弄物件）
- 顶光留出眼窝阴影（强化"看不清表情"）

**增强项（5%）**：
- 一个手部微距（动作慢一拍）

**反例**：
- ❌ 仰拍（仰拍是伟岸，不是退缩）
- ❌ 正面直视镜头（退缩 = 不敢看）
- ❌ 强光（退缩 = 阴影感）

**配套通用后缀**：
- 调色：低饱和
- 光线：弱光源 / 顶光
- 音效：呼吸声若有似无；环境声盖过角色声音

## E09 · 突破内心

**适用情境**：
- 角色克服内心障碍的瞬间（鼓起勇气、说出真相、跨过心理坎）
- 例：《心灵捕手》Will 哭着说"It's not your fault"、本案露夏说出"去我家看猫"

**核心组合（80% · 锁死）**：
- 焦段：长焦 85-135mm
- 光圈：大光圈
- 机位：仰拍 + 近景到特写（从下往上看角色 = 突破感）
- 运镜：缓慢推（Slow Dolly In）

**辅助锚点（15%）**：
- 慢动作（情绪命中瞬间 0.5x）
- 光线突然变强（突破瞬间 = 光线"开"）
- 环境音渐弱（聚焦到角色）

**增强项（5%）**：
- 一个静切动（前镜静态 → 突破瞬间运镜启动）
- 或一个反向衔接（推到最近 → 拉远展示空间）

**反例**：
- ❌ 俯拍（俯拍是压迫，不是突破）
- ❌ 广角（突破需要长焦的私密感）
- ❌ 快切（突破是慢的）
- ❌ 大景深全清晰（背景必须虚化让主体唯一）

**配套通用后缀**：
- 调色：略偏暖（突破 = 释放）
- 光线：突破瞬间光线变强 / 突破光晕
- 音效：环境音淡化 + 主角呼吸/心跳放大

## E10 · 仪式威严

**适用情境**：
- 婚礼 / 葬礼 / 加冕 / 宣誓 / 朝贺 / 祭祀
- 例：《教父》洗礼蒙太奇、《哈利·波特》分院仪式

**核心组合（80% · 锁死）**：
- 焦段：长焦 85-200mm
- 光圈：中等 f/4 - f/5.6（保留景深）
- 机位：**对称居中（A1+A7 双重解锁）** + 平视 + 全景到中景
- 运镜：固定 / 极缓的升降

**辅助锚点（15%）**：
- 强对称布景（左右镜像）
- 多人三角形构图（中心人物 + 两侧次主）
- 顶光 / 蜡烛 / 神秘光源

**增强项（5%）**：
- 一个鸟瞰展示仪式空间整体
- 或一个微距标点（仪式道具特写）

**反例**：
- ❌ 手持（破坏仪式静态）
- ❌ 不对称构图（仪式必须对称）
- ❌ 广角扭曲（仪式要长焦的"凝重压缩"）
- ❌ 快切（仪式是慢的）

**配套通用后缀**：
- 调色：低饱和 + 高对比 / 单色调（红 / 金 / 黑）
- 光线：戏剧化顶光 / 蜡烛 / 神秘光
- 解锁后缀：必须含"强对称构图 + 仪式感 + 风格化"

**解锁的雷区**：A1 正面居中（白名单 ②）+ A7 多人正面平铺（白名单 ①）

## E11 · 干脆决断

**适用情境**：
- 角色完成一个简短而果断的动作（按熄烟头 / 合上书 / 起身离开 / 挂电话）
- 戏剧动作的"标点符号"

**核心组合（80% · 锁死）**：
- 焦段：微距
- 光圈：大光圈
- 机位：俯拍 / 侧拍·超特写
- 运镜：静切动（前镜固定 → 本镜动作发生）+ 快切（Cut In）

**辅助锚点（15%）**：
- 物件状态突变（点燃 → 熄灭 / 张开 → 合上 / 升起 → 落下）
- 动作音放大成"标点声"
- 光斑 / 烟雾 / 火星等动态附属

**增强项（5%）**：
- 一个慢动作（决断瞬间 0.5x）

**反例**：
- ❌ 中景或全景（必须微距 = 标点感）
- ❌ 缓慢运镜（决断是快的）
- ❌ 多人入画（标点镜头只有动作主体）

**配套通用后缀**：
- 音效：动作音放大；环境音瞬间静音 0.5 秒后回归
- 限制：画面中只有 [指定物]，无其他物件
- 渲染：超清细节 + 微距景深

## E12 · 释放释怀

**适用情境**：
- 角色完成一段戏剧动作后的余韵 / 释怀 / 解脱
- 通常是大分镜的收尾镜头

**核心组合（80% · 锁死）**：
- 焦段：中焦 50-85mm
- 光圈：中等到小光圈 f/4 - f/8
- 机位：俯拍 + 全景 + 大景深
- 运镜：拉远（Dolly Out）/ 升降（Crane Up）

**辅助锚点（15%）**：
- 角色回到画面中央但占比小（环境吞没人物）
- 自然光 + 开阔空间
- 慢动作 + 长曝光感

**增强项（5%）**：
- 一个鸟瞰反向衔接（前镜推近 → 本镜鸟瞰拉远）

**反例**：
- ❌ 长焦（释怀需要环境感）
- ❌ 大光圈虚化（需要看到环境）
- ❌ 手持（释怀是稳定的）
- ❌ 推近（释怀是拉远的）

**配套通用后缀**：
- 调色：高调 / 暖色 / 自然
- 光线：自然光 / 黄昏 / 晨光
- 音效：环境音 + 关键同步音效；不生成 BGM，BGM 交给 07 后期声音设计

## E13 · 异化失控（库布里克式）

**适用情境**：
- 角色精神失序 / 系统性异化 / 程式化的诡异感
- 例：《闪灵》杰克打字、《2001》宇航员对峙 HAL、《发条橙》Alex 凝视

**核心组合（80% · 锁死）**：
- 焦段：广角 24mm（轻微鱼眼感）
- 光圈：中等 f/4
- 机位：**强对称居中（A1+A3 双重解锁）** + 平视
- 运镜：极缓的轨道推（Hyper-slow Dolly In）

**辅助锚点（15%）**：
- 镜面对称构图（左右完全镜像）
- 单点透视（消失点正中）
- 直视镜头（角色看观众）

**增强项（5%）**：
- 一个希区柯克变焦（Dolly Zoom）在异化命中点
- 或一个静态长镜头 ≥ 8 秒

**反例**：
- ❌ 不对称（库布里克式必须强对称）
- ❌ 手持（破坏程式化感）
- ❌ 长焦（库布里克偏好广角的扭曲）
- ❌ 快切（异化感需要长镜头压制）

**配套通用后缀**：
- 调色：高饱和 + 单色调（红 / 黄 / 蓝其一）
- 光线：均匀光 / 单色光
- 解锁后缀：必须含"库布里克式强对称 + 单点透视 + 程式化构图"

**解锁的雷区**：A1 正面居中（白名单 ①）+ A3 死压中线（白名单 ①）

## E14 · 被困压抑

**适用情境**：
- 角色被环境 / 制度 / 阶级压制；空间感封闭
- 例：《肖申克》安迪入狱第一夜、《1984》Winston 在 101 号房

**核心组合（80% · 锁死）**：
- 焦段：广角 24-35mm
- 光圈：中等 f/4
- 机位：**头顶贴边（A2 解锁）** + 平视到俯视 + 中景
- 运镜：固定 / 极缓的微移（Micro Move）

**辅助锚点（15%）**：
- 前景物件遮挡（栏杆 / 窗格 / 门框）
- 顶光制造"被天花板压住"
- 主体占画面中下部，上部被环境填满

**增强项（5%）**：
- 一个鸟瞰（顶视）展示角色被空间吞没

**反例**：
- ❌ 仰拍（仰拍是伟岸，不是被困）
- ❌ 留 headroom（必须头顶贴边）
- ❌ 大景深（被困需要密集压迫，不是开阔）

**配套通用后缀**：
- 调色：低饱和 + 偏冷 / 偏黄（潮湿牢房感）
- 光线：顶光 + 阴影 / 单光源
- 解锁后缀：必须含"压迫感 + 闭塞空间 + 头顶填满"

**解锁的雷区**：A2 头顶贴边（白名单 ①）

## E15 · 神性显现 / 顿悟

**适用情境**：
- 神迹 / 宗教体验 / 顿悟瞬间 / 死亡 / 升华
- 例：《肖申克》安迪雨中张开双臂、《宋飞正传》最后一幕、《2001》星孩

**核心组合（80% · 锁死）**：
- 焦段：广角 24-35mm
- 光圈：大光圈 f/2.0（强化光晕）
- 机位：**背景过亮逆光剪影（A6 解锁）** + 仰拍
- 运镜：缓慢升降（Crane Up）/ 缓慢拉远

**辅助锚点（15%）**：
- 强逆光 + 镜头光晕（lens flare）
- 慢动作
- 角色双臂张开 / 仰头 / 拥抱姿态
- 飘动元素（雨 / 雪 / 灰尘 / 落叶）

**增强项（5%）**：
- 一个白屏过渡（瞬间过曝）
- 或一个鸟瞰展现神性空间

**反例**：
- ❌ 顺光（顿悟必须逆光）
- ❌ 暗调（顿悟必须明亮）
- ❌ 手持（神性需要稳定）
- ❌ 快切（顿悟是慢的）

**配套通用后缀**：
- 调色：高调 + 过曝感 + 暖色
- 光线：强逆光 + 神性光晕
- 解锁后缀：必须含"高调过曝 + 神性光线 + 梦境质感"

**解锁的雷区**：A6 背景过亮（白名单 ① 神性显现）

# 第二部分  字段细则

## 第 6 节  台词与语气独立字段规范

### 强约束

**台词必须独立写入 `台词与语气` 字段。`主体动作/表情` 只写可见动作、微表情、呼吸、身体反应、口型动作和说话前后的表演过程。**

格式：`台词与语气：[说话者] + [语气/音量/语速/情绪状态] + "[台词原文]" + [口型要求]`

04 不改写定稿台词，但必须把台词放进可执行的镜头节拍里。长对白不要硬塞进短镜头；应拆到多个镜头、增加反应镜头或在交接给 06 时标注“台词时长偏紧”。需要删字、换句或压缩表达时，回到 `03-dialogue-expert.md`。

台词节拍参考：强情绪慢速/低声耳语约 3-4 字/秒，正常短剧对白约 4-5 字/秒，短视频偏快对白约 5-6 字/秒；超过 6 字/秒默认高风险，只允许争吵、慌乱、快嘴喜剧或抢话。

### 对照范式

```
✅ 正确：
   主体动作/表情：花十微微仰头，吐出烟雾，眼神越过烟雾看向对面，嘴角轻微上挑。
   台词与语气：花十随口、轻声、语速偏慢地问：“你等会去哪？”口型与原台词一致。

✅ 正确：
   主体动作/表情：露夏低头搅拌奶茶，眼神短暂上抬看了对方一眼，
                又移回杯口，开口前停顿半拍，手指继续搅动吸管。
   台词与语气：露夏试探性地、小声、尾音略轻地说：“要不去我家看猫吧。”口型与原台词一致。

❌ 错误：
   主体动作/表情：花十微微仰头，吐出烟雾
   台词：花十："你等会去哪？"
   （字段名错误且缺少语气、音量、语速、口型要求）

❌ 错误：
   主体动作/表情：花十微微仰头，吐出烟雾，看着对面随口问道：“你等会去哪？”
   （完整台词塞回主体动作/表情，会导致 06 台词字段丢失）
```

### 画外音处理

```
✅ 主体动作/表情：画面主体按当前镜头行动，角色没有现场开口，口型不可见。
   台词与语气：（画外音/旁白）低沉、克制、语速偏慢地说：“他不是在说谎。他真的觉得，自己是对的。”
   并在"机位"字段标注"画外音镜头·主体见画面描述"
```

### 无对白镜头

```
主体动作/表情：花十掐灭烟头，缓缓起身。
台词与语气：无对白。
```

## 第 7 节  运镜中英标注规范

### 判断标准

> **中文 AI 视频模型可能识别错的，加英文兜底；中文清晰无歧义，不加英文。**

### 实操对照表

**只写中文（无歧义）**：
- 推 / 拉 / 摇 / 移 / 跟
- 升 / 降
- 急速变焦
- 手持摄像机呼吸感
- 固定（如真要写）

**中文 + 英文（易识别错）**：
- 滑轨（Slider）
- 轨道推（Dolly In）/ 轨道拉（Dolly Out）
- 升降（Crane / Jib）
- 斯坦尼康（Steadicam）
- 变焦推（Zoom In）/ 变焦拉（Zoom Out）
- 希区柯克变焦（Dolly Zoom）
- 鱼眼跟拍（Fisheye Tracking）
- 微移（Micro Move）
- 360 度环绕（360° Orbit）
- 子弹时间（Bullet Time）
- 鸟瞰（Bird's Eye / Top-Down）
- 快切（Cut In）

### 复合运镜写法

允许"自然语言式复合描述"：
```
✅ 横向滑轨微微加前推（Lateral Slider + Slight Push In）
✅ 手持摄像机呼吸感晃动
✅ 缓慢轨道推 + 轻微仰角抬升（Slow Dolly In + Slight Tilt Up）
```

摄影机行为锁写法必须比“复合运镜名词”更具体：

```text
✅ 固定镜头，摄影机位于两人正前方眼平中景，保持茶几在画面中央，不推拉不摇移，角色动作自己进入画面。
✅ 手持侧跟，摄影机在角色右侧约 1 米处同步跟随，轻微呼吸感晃动，转弯时短暂甩动后重新稳住。
✅ 前导倒退跟拍，摄影机在角色正前方胸口高度后退，保持角色上半身中近景，段末停在门口左侧。
✅ rack focus，摄影机固定不动，先让前景手机背面清晰，再把焦点转到后景角色的眼神。
```

不要写：

```text
❌ 运镜：高级跟拍
❌ 运镜：手持
❌ 运镜：固定
❌ 运镜：复杂电影感运动
```

## 第 8 节  @图N 引用机制

### 命名约定（建议，非强制）

```
@图1 = 环境参考图
@图2 / @图3 / ... = 角色参考图（按出场顺序或重要性）
```

### 使用位置

- **大分镜·场景**字段：`内景·茶餐厅·夜晚（参见 @图1）`
- **大分镜·人物位置关系**：可省略并注"参见 @图1 人物位置"
- **分镜·机位**：`过肩 @图2 拍 @图3`
- **分镜·主体动作**：`@图3 微微低头，搅拌奶茶`

### 无参考图模式

如用户未提供：
- 仍可生成分镜
- 但所有 @图N 改为角色名/场景名
- Phase 0 提示"角色一致性会下降"

## 第 9 节  "限制"字段双向使用规范

### 定义

**"限制" = AI 视频模型默认会处理错或忽略的细节，强制要求或强制禁止。**

### 双向使用

**强制要"有"**（AI 默认会忽略）：
```
限制：保持背景音嘈杂的人群声
限制：前景 3-5 名路人从画面边缘擦肩经过并轻微虚化，中景 8-12 名行人与主角同向和反向交错移动，远景 20 人以上持续流动
限制：必须保留烟头的余烬光晕
限制：玻璃杯必须有冷凝水珠
限制：脚步声清晰，每步落地有底鼓感
```

**强制要"无"**（AI 默认会乱加）：
```
限制：不允许出现字幕/水印/任何文字
限制：不允许镜头中出现其他人物
限制：不允许出现额外人物、路人、群演；场景只保留剧本明确角色
限制：不允许背景音乐
限制：不允许角色看镜头
限制：不允许添加额外光源
```

### 使用原则

- **不是每个分镜都要写**——AI 默认能做对的不写
- **AI 易错点优先**——根据经验积累常见错点（详见附录 C）
- **一条限制只控制一件事**——多件事拆成多条

### AI 视频模型常见易错点速查

| 易错类型 | 限制写法范例 |
|---|---|
| 自动加字幕 | 不允许出现字幕、文字、水印 |
| 自动加 BGM | 不允许背景音乐 |
| 自动改场景安静 | 保持背景音嘈杂的人群声 |
| 公共空间变空街 | 按 CR001 人群密度执行：前景/中景/远景分别有人流，路人自然移动 |
| 私密空间乱加人 | 不允许出现额外人物、路人、群演 |
| 路人抢戏或挡脸 | 路人不得看镜头，不得遮挡主角脸部和关键动作，不得围观主角 |
| 自动美颜 | 不允许美颜/磨皮，保留皮肤纹理 |
| 角色看镜头 | 不允许角色看向镜头 |
| 自动加光源 | 仅使用环境光，不要单独打光 |
| 物件出现/消失 | 必须保留[X]在画面中全程可见 |
| 多余手部动作 | 不允许角色出现多余手部动作 |
| 服装变化 | 服装/发型保持与 @图N 完全一致 |

# 第三部分  方法论

## 第 10 节  视听转译方法论

### 核心拷问

> "这句话/这个描述，摄影机拍得到吗？麦克风录得到吗？拍不到/录不到的，**必须转译**。"

### 转译四步法

```
Step 1  识别抽象描述
        在剧本中扫描出所有"心理 / 情绪 / 抽象状态 / 隐喻"描述

Step 2  追问"这个抽象，演员会用身体的哪一部分来演？"
        眼神 / 嘴角 / 手指 / 肩膀 / 呼吸 / 步伐 / 姿态

Step 3  追问"这个身体表演，摄影机用什么镜头能拍到？"
        景别 / 焦段 / 角度 / 运镜

Step 4  追问"光是这个画面够吗？要不要靠声音/光线/物件辅助？"
        环境音 / 拟音 / 道具状态变化 / 光线突变
```

### 转译案例库（开放积累，详见附录 C）

```
"她内心崩溃了"
  → 演员表演：手指在桌下用力捏紧自己的另一只手；
              呼吸节奏短促但表情维持平静
  → 摄影机：桌下手部超特写（微距+大光圈）
  → 辅助：周围环境音轻微下沉

"她很悲伤"
  → 演员表演：眼神轻微下垂，眨眼变慢，嘴唇抿住又松开；
              喉咙轻轻吞咽，呼吸变浅，嘴角短暂轻颤但努力保持平静
  → 摄影机：眼睛近景或嘴部特写，停留足够长让微表情发生
  → 限制：不要流泪，不要夸张哭脸，不要突然崩溃大哭，不要大幅度捂脸
  
"两人渐生情愫"
  → 演员表演：A 抬头时机比 B 早 0.3 秒；
              B 把杯子向 A 方向推了 1cm
  → 摄影机：俯视双手特写（看杯子的距离变化）
  → 辅助：背景音乐淡入（如启用音乐）

"杀气腾腾"
  → 演员表演：肩膀放松但眼神锁定；
              手指无意识摩挲刀柄
  → 摄影机：手部微距 → 切到眼睛特写（dolly in）
  → 辅助：环境音突然安静一拍
```

## 第 11 节  分镜之间的衔接规则（段内 5 维度）

> **适用范围**：本节 5 维度约束同一大分镜**内部**相邻分镜间的衔接。
> **跨大分镜衔接**（段间衔接）另见 12.4 节：跨段衔接 7 维度 = 本节 5 维度 + 时间连续性 + 状态延续。
>
> 衔接 = 让相邻两个分镜在视觉/动作/空间上"接得上"。
> **衔接错乱 = 观众出戏。**

### 11.1 五大衔接维度

#### A. 空间连贯性（180° 轴线规则）

两人对话场景中，**摄影机不能跨过两人之间的假想轴线**。

```
轴线规则示意：
   A ─────●───── B
            ↑
       这条线 = 轴线
   
   ✅ 摄影机在线的同一侧切换（无论怎么换景别/角度）
   ❌ 跨到另一侧 → 观众感觉"两人换位置了"
```

**例外**：仪式性越轴（如 A 起身追到 B 身后，镜头跟着越过去）允许。

#### B. 视线匹配（Eyeline Match）

A 镜：A 看向画面右侧 → 切到 B 镜：B 必须从画面左侧出现，且视线朝向画面左侧（与 A 对望）。

```
✅ A 看右 → B 从左入画 + 看左
❌ A 看右 → B 从右入画 + 看右（变成两人都看同一侧）
```

#### C. 动作衔接（Match Cut on Action）

A 镜末尾的动作 = B 镜开头动作的"延续 60-80%"。

```
✅ A 镜：花十抬手到嘴前 → B 镜（切到长焦特写）：手已经在嘴前抽烟
❌ A 镜：花十抬手到嘴前 → B 镜：手已经放下了（动作跳跃）
```

#### D. 道具/物件状态连贯

物件在前一镜的状态 → 后一镜必须延续。

```
✅ A 镜：杯里有半杯奶茶 → B 镜：杯里仍是半杯（即使切换角度）
✅ A 镜：烟燃了一半 → B 镜（几秒后）：烟应短一些，烟灰应长一些
❌ A 镜：杯子在桌上 → B 镜：杯子在角色手里（无中间动作）
```

> **AI 视频模型最容易在此处出错**，必须用"限制"字段强制约束：
> ```
> 限制：杯中奶茶量保持半杯，与上一镜一致
> 限制：烟头长度比上一镜短 1cm，烟灰更长
> 限制：角色服装/发型/位置与上一镜完全一致
> ```

#### D2. 小道具朝向锁定（手机/照片/证件等）

AI 视频模型经常会把手机、照片、证件、信封等小道具自动转成“正面朝镜头”，甚至把手机背面也生成成屏幕。凡是道具有正反面、信息面、穿帮面时，分镜限制必须写清道具朝向。

```
✅ 限制：手机背面朝镜头，黑色玻璃背板和斜排双摄可见；屏幕正面朝向角色手心，不可见。
✅ 限制：手机屏幕正面朝镜头，只允许显示指定微信 UI；背面不可见。
✅ 限制：照片正面贴在桌面上不可见，观众只看到照片背面。
❌ 手机在角色手里，但没写朝向（模型常自动把屏幕怼给镜头）
❌ 手机背面出现发光屏幕、微信气泡或随机文字
```

手机类道具必须特别写：

- 正面 = 屏幕面。
- 背面 = 摄像头/玻璃背板面。
- 如果剧情不需要看屏幕，优先让屏幕朝向手心、桌面或角色身体。
- 如果剧情需要看 UI，必须明确“屏幕正面朝镜头”，并写清只允许出现哪些中文 UI / 数字 / 图标。
- 在“限制”字段中禁止：手机背面变成屏幕、手机正反面同时都是屏幕、随机 UI、随机文字。

#### D3. 道具单实例锁（场景/首帧已有道具 + PR 道具图）

如果某个关键道具已经出现在场景母版、SCV 角度图或 FF 首帧图里，同时资产库又提供了同一件道具的 PR 参考图，分镜必须把它当作“同一个物体实例”，不要让下游 06 误写成新增道具。

必须在分镜限制或段前置单元写清：

- PR001 对应的是画面里哪一个可见道具。
- 本段 / 全片只允许出现几个。
- PR 图只用于外观、裂纹、材质、颜色或屏幕状态，不新增第二件道具。
- 如果角色拿起、放下或移动该道具，原位置和手中状态必须互斥。

```text
限制：PR001 碎屏手机就是首帧中桌面右下角那一部手机，本段只允许出现这一部手机；PR 图只补裂纹和机身外观，不新增第二部手机。角色拿起手机后，桌面原位置必须变为空，不得桌上和手里同时各有一部手机。
```

#### E. 景别跳跃节奏

| 跳跃幅度 | 效果 | 适用情境 |
|---|---|---|
| 同景别切同景别 | 跳切感（jump cut） | 慎用 / 用于焦虑感 |
| 一级跳（中→近 / 近→特） | 最自然 | 默认推荐 |
| 两级跳（全→近 / 近→大特） | 强冲击感 | 情绪爆发点 |
| 三级跳（远→特） | 极强冲击 | 关键情绪命中 |
| 反向跳（近→全） | 抽离感 / 沉淀 | 情绪余韵 |

**红线**：不要连续 3 镜以上同景别——观众会感觉"摄影机懒"。

### 11.2 衔接错误自查清单（生成完每个大分镜后内部过）

```
□ 是否跨过 180° 轴线（除非有意越轴）
□ 视线方向是否互相匹配
□ 上一镜末尾动作 + 下一镜开头动作能否 60-80% 重合
□ 物件状态是否延续（必要时加"限制"字段约束 AI）
□ 连续 3 镜是否同景别
□ 角色服装/发型/位置是否突变（AI 易错）
□ 公共空间是否判断人群密度；如启用 CR，是否写清前景/中景/远景人数、类型、移动和遮挡规则
□ 私密空间或无路人需求的段落，是否在限制里禁止额外人物、路人、群演
```

## 第 12 节  分镜间运镜衔接规则

> 运镜衔接 = 决定"剪辑节奏"和"情绪流向"。
> 不仅是"一个镜头怎么动"，**更是"两个镜头之间能量如何传递"**。

### 12.1 五大衔接模式

#### A. 同向衔接（能量持续）

上镜推 → 下镜继续推。能量累积、情绪升温。

```
B01-S01：缓慢轨道推（Slow Dolly In）
B01-S02：继续轨道推（Continue Dolly In），切换景别但不停止能量

效果：观众感觉"我们正在不可阻挡地接近某个东西"
适用：揭示真相 / 情感升温 / 恐惧累积
```

#### B. 反向衔接（心理张力）

上镜推 → 下镜拉。能量反转、心理拉扯。

```
B01-S01：推向角色面部特写
B01-S02：从角色背后拉出大全景

效果：观众情绪"被推近"再"被拉离"，产生抽离/孤独感
适用：决断后的孤独 / 高潮后的余韵
```

#### C. 静切动（情绪激发）

上镜固定 → 下镜运动。从平静到爆发。

```
B01-S01：固定·面部特写（角色凝视）
B01-S02：手持呼吸感·全景（角色突然起身）

效果：观众情绪从"凝固"被"激活"
适用：决断瞬间 / 转折点
```

#### D. 动切静（情绪沉淀）

上镜运动 → 下镜固定。从激烈到沉淀。

```
B01-S01：手持快摇（Whip Pan）
B01-S02：固定·物件特写（被丢下的物件）

效果：观众情绪从"混乱"被"凝固"
适用：戏剧动作完成后的静默 / 余味
```

#### E. 同质运镜叠加（风格强化）

多个相同性质的运镜连接 = 形成"作者风格"。

| 运镜组合 | 风格效果 |
|---|---|
| 多个手持呼吸感 | 焦虑/纪录片感（《黑天鹅》《夜行者》风格） |
| 多个长镜头 | 沉浸感（侯孝贤/小津风格） |
| 多个快切 | 节奏暴烈（《疾速追杀》/抖音爽剧） |
| 多个固定镜头 | 仪式感/克制（侯麦/王家卫《花样年华》部分） |
| 推 + 拉 + 推 + 拉 | 心理博弈感（希区柯克对话戏） |

### 12.2 运镜衔接红线

```
❌ 三个连续手持呼吸感 + 第四个突然变固定（除非戏剧动作要求）
❌ 摇 + 推 + 拉 + 升 + 摇（一段戏内运镜方式过多 = 风格混乱）
❌ 大角度运镜（如希区柯克变焦）连续使用 ≥ 2 次（炫技感）
❌ 每个镜头都运动 + 每个镜头都不一样（观众会晕）
❌ 同向衔接超过 4 镜（能量过载，观众疲劳）
```

### 12.3 一段戏的运镜节奏建议

```
开场镜头：固定 / 缓慢运镜（建立空间）
中段镜头：动+静交替（推进情绪）
情绪命中镜头：可启用大幅运镜（如希区柯克变焦 / 子弹时间）
收尾镜头：静止 / 反向运镜（沉淀）
```

### 12.4 风格选择需服从剧本气质

不是"挑一种风格用到底"，而是**剧本气质决定运镜组合**：

| 剧本气质 | 推荐运镜组合 |
|---|---|
| 冷静克制（如本案茶餐厅戏） | 固定为主 + 少量手持呼吸感 + 1-2 个反向衔接 |
| 紧张焦虑（追逐/逃亡） | 大量手持呼吸感 + 快切 + 静切动 |
| 浪漫梦幻（爱情/回忆） | 长镜头滑轨 + 同向衔接 + 慢速推/拉 |
| 暴力对抗（打斗/枪战） | 快切 + 子弹时间 + 同质叠加（密集快切） |
| 悬疑揭示 | 同向推进 + 突然反向拉远（揭示瞬间） |

## 第 13 节  构图雷区清单（**默认禁止 + 白名单解锁**）

> **核心机制**：雷区不是绝对禁令，是"默认禁止 + 特定情境解锁"的双态系统。
> **雷区分两类**：
> - **A 类·艺术性雷区**：可在白名单情境下解锁（库布里克式正面居中、暴力美学断关节等）
> - **B 类·工程性雷区**：永不解锁——这些是 AI 视频生成的**纯技术错误**，无任何艺术理由

### 13.1 A 类 · 艺术性雷区（可解锁）

#### A1. 正面居中

```
默认状态：禁止
默认理由：舞台感 / 破第四面墙 / 视觉平庸
解锁白名单（必须命中其一）：
  □ ① 异化时刻（库布里克式 / 表现精神失序） → 关联 ID：E13
  □ ② 仪式感（婚礼 / 葬礼 / 加冕 / 审判） → 关联 ID：E10
  □ ③ 对峙瞬间（审讯 / 法庭 / 决斗的凝固一刻） → 关联 ID：E04
  □ ④ 强迫观众参与（直视镜头 / 第四面墙击穿）
  □ ⑤ 风格化作者印记（韦斯·安德森式强对称美学）
  □ ⑥ 权力凝固（君主 / 反派的"被供奉"瞬间） → 关联 ID：E02
解锁后强制约束：
  - 必须配套：对称布景 / 静态运镜 / 长焦压缩
  - 通用后缀必须含："强对称构图 / 仪式感 / 风格化"
  - 内部四问 Q4 必须写明"解锁理由 = 来自 A1 白名单第 X 项"
未命中白名单 → 仍按默认禁止
```

#### A2. 头顶贴边

```
默认状态：禁止
默认理由：视觉压迫不适
解锁白名单：
  □ ① 表现"被天花板压住"/ 牢笼感 → 关联 ID：E14
  □ ② 阶级压迫 / 角色被环境吞噬
  □ ③ 监视感（顶部空间被填满 = 被注视）
解锁后约束：
  - 必须配合广角镜头（强化压迫）
  - 通用后缀加"压迫感 / 闭塞空间"
未命中白名单 → 留出 headroom
```

#### A3. 死压中线（主体永远居中）

```
默认状态：禁止
默认理由：构图平庸 / 缺少视觉张力
解锁白名单：
  □ ① 异化 / 程式化（库布里克 / 艾舍尔式镜像） → 关联 ID：E13
  □ ② 童话仪式感（韦斯·安德森式）
  □ ③ 强对称美学的明确意图
解锁后约束：
  - 整段戏所有镜头必须保持对称美学（不能只这一镜对称）
  - 通用后缀加"强对称构图 + 风格化"
未命中白名单 → 用三分法 / 黄金分割
```

#### A4. 眼神无空间（视线指向画面外但该侧无 noseroom）

```
默认状态：禁止
默认理由：空间错乱 / 视觉不适
解锁白名单：
  □ ① 凝视虚空 / 失控 / 心理失序（《现代启示录》库尔兹）
  □ ② 表现角色被"看不见的力量"包围
  □ ③ 主观恐惧（看不到的威胁源）
解锁后约束：
  - 必须配合长焦虚化背景
  - 后缀加"凝视虚空 / 心理失序"
未命中白名单 → 留出 noseroom
```

#### A5. 断关节（框边切在关节处）

```
默认状态：禁止
默认理由：视觉不适 / 画面"残缺感"
解锁白名单：
  □ ① 强调局部（手 / 脚 / 嘴）= 微距/超特写镜头
  □ ② 暴力美学（昆汀式 / 北野武式）
  □ ③ 抽离感叙事（局部代替整体 / 局部蒙太奇）
解锁后约束：
  - 必须是有意为之的"微距/超特写"选择
  - 不能是中景/全景中的"无意切到关节处"
  - 配套微距 / 长焦
未命中白名单 → 框边切大臂中段、大腿中段、胸口或腰部
```

#### A6. 背景过亮（背景比主体亮，主体被吃）

```
默认状态：禁止
默认理由：主体不明 / 视觉中心丢失
解锁白名单：
  □ ① 神性显现 / 顿悟瞬间 / 死亡 → 关联 ID：E15
  □ ② 逆光剪影（角色身份被有意模糊）
  □ ③ 回忆 / 梦境的"过曝"质感
解锁后约束：
  - 必须明示"逆光剪影"或"过曝梦境感"
  - 后缀加"高调过曝 / 神性光线 / 梦境质感"
未命中白名单 → "限制：主体光比背景亮 1-2 档"
```

#### A7. 多人正面平铺（所有人正脸朝镜头）

```
默认状态：禁止
默认理由：舞台感 / 静态合影感
解锁白名单：
  □ ① 全家福 / 法庭 / 仪式 / 集体宣誓 / 教科书风格
  □ ② 强迫观众参与（破第四面墙）
  □ ③ 仪式威严（多人朝贺） → 关联 ID：E10
解锁后约束：
  - 必须配合对称布景
  - 后缀加"仪式感 + 集体凝视"
未命中白名单 → 用侧脸 / 背影 / 半侧 制造朝向变化
```

### 13.2 B 类 · 工程性雷区（**永不解锁**）

> 这些是 AI 视频生成的**技术错误**，**艺术上没有任何理由保留**。强制用"限制"字段规避。

| 雷区 | 描述 | 强制规避（写进"限制"字段） |
|---|---|---|
| **物体穿身** | 树枝/灯柱/路标从角色头顶或身体长出 | "限制：背景物体不与角色身体重叠" |
| **角色服装突变** | 上一镜白衣下一镜灰衣（同场戏） | "限制：服装/发型与上一镜完全一致" |
| **杂乱前景刺眼物** | 前景虚化中出现光斑/反光板边缘 | "限制：前景虚化中无刺眼光斑/异物" |
| **比例失调** | 手比头大 / 透视错乱 / 多手指 | "限制：身体各部位比例符合解剖学" |
| **重复元素无重点** | 背景多个相同形状物让画面无重点 | "限制：背景元素有主次层次" |
| **空鸡蛋构图** | 主体周围全空白无视觉支撑 | 加前景物件 / 框架式构图 |
| **道具状态突变** | 杯里水量、烟头长度突变 | "限制：道具状态与上一镜延续" |

> **B 类雷区出现 = 必修 bug**——不允许在任何情境下保留。

### 13.3 多人构图次级雷区

> 这些不是雷区"独立项"，是 A 类的衍生场景。已由 A1/A7 覆盖。仅速查用。

| 雷区 | 默认规避 | 解锁参考 |
|---|---|---|
| **眼睛同高** | 通过站姿/坐姿/俯仰角制造高低差 | 仪式 / 法庭可解锁（参见 A7） |
| **一字排开** | 三角形构图 / 前后景纵深 | 仪式宣誓可解锁（参见 A7） |
| **视线散乱** | 至少 2 人共同看向焦点 | 表现集体困惑 / 失序时可保留 |

### 13.4 微距/超特写专属雷区（无解锁，强约束）

| 雷区 | 描述 | 规避方法 |
|---|---|---|
| **主体不明** | 微距构图未指明主体 | **强制写明"X 占满画面"** |
| **失焦** | 微距景深极浅，焦点没对在关键点 | 写明焦点："焦点在烟头红色火星" |
| **杂物入画** | 微距镜头里混入与剧情无关的杂物 | "限制：画面中只有 [指定物]，无其他物件" |

> 这些不属于 A/B 分类——是微距镜头的**结构性必填项**，无解锁概念。

### 13.5 类型化构图雷区

| 类型 | 常见雷区 | 规避 |
|---|---|---|
| 武侠 | 角色站姿过于现代（叉腰/手插兜） | 古典站姿："手负于背"/"剑指在前" |
| 现代都市 | 室内构图过于"舞台感"（面对镜头说话） | 自然朝向，避免破第四面墙（除非命中 A1 白名单 ④） |
| 动画 | 物件比例失调（手比头大） | "限制：身体各部位比例符合解剖学"（B 类·不解锁） |
| 悬疑 | 关键道具反而构图弱化 | 关键道具至少给一个独立特写镜头 |
| 爱情 | 双人构图距离过远显疏离 | 物理空间靠近 + 前景遮挡制造亲密感 |

### 13.6 雷区自查流程（生成完每个大分镜后过）

```
对每个分镜检查：

Step 1：是否触碰雷区？
  - 否 → 通过
  - 是 → 进 Step 2

Step 2：触碰的是 A 类还是 B 类？
  - B 类 → 必修，不解锁，写进"限制"字段
  - A 类 → 进 Step 3

Step 3：A 类是否有合法解锁理由？
  - 命中白名单某项 → 在内部四问 Q4 写明"解锁理由 = AX 白名单第 N 项"
                  → 通用后缀必须配套
                  → 通过
  - 未命中 → 该镜头违规，重做
```

## 第 14 节  情绪服务验证机制（三层强制）

> **核心拷问**：每个分镜头是否真的服务于剧本/主体情绪，还是为了切镜而切镜？
> 本节是 Skill 的**核心壁垒**——三层验证强制每个镜头都"有它存在的理由"。

### 14.1 三层验证机制总览

```
┌──────────────────────────────────────────────────┐
│ 层级 │ 时机           │ 输出？ │ 强度          │
├──────────────────────────────────────────────────┤
│ L1   │ Phase 4.5      │ ✅ 输出 │ 情绪锚点表    │
│ L2   │ Phase 5.0/每镜 │ ❌ 不出 │ 内部四问 Q1-Q4 │
│ L3   │ Phase 5.4      │ ❌ 不出 │ 成片预演检查  │
└──────────────────────────────────────────────────┘
```

### 14.2 L1 · 情绪锚点表（详见 Phase 4.5）

每段大分镜下输出 3-5 个情绪节拍。所有分镜必须能映射到某个节拍。

### 14.3 L2 · 内部四问（详见 Phase 5.0）

```
Q1：服务于哪个节拍 + 哪个微观瞬间？（答不出 → 镜头无效）
Q2：删了能否成立？（能成立 → 删，为切而切）
Q3：有没有更好的视听方式？（有 → 替换）
Q4：本镜是主镜头 / 辅助镜头 / 快切镜头？按各自路径对账情境 ID（仅内部不输出）
```

### 14.4 L3 · 成片预演（详见 Phase 5.4）

把所有分镜按顺序"放电影"，验证：
- 实际情绪曲线 = 锚点表预设曲线
- 5 维衔接 + 5 模式运镜 + 雷区规避是否过关

### 14.5 "为切而切"的反模式清单

> 检查自己是不是在为切而切：

| 反模式 | 表现 | 修正 |
|---|---|---|
| **过度炫技** | 6 镜里 4 个希区柯克变焦 | 整段戏只允许 1 个奇技镜头 |
| **景别强迫症** | 强行做"全→中→近→特→大特"的标准切换 | 按情绪需要切，不按教科书 |
| **平均切镜** | 每个镜头都是 2-3 秒 | 长短交错，按情绪节拍 |
| **复刻知名段落** | 强行模仿《教父》《拯救大兵》某段 | 学习其逻辑而非画皮 |
| **追求"高级感"** | 大量空镜、大量长焦虚化、不知所云 | 每个镜头都要回答"服务什么情绪" |
| **AI 视频炫耀** | 加入复杂运镜只为展示 AI 能做到 | AI 是工具，不是目的 |
| **风格不匹配** | 茶餐厅冷静戏用打斗片快切 | 风格必须服从剧本气质（详见 12.4） |

### 14.6 验证失败的处理

如果某个分镜在三层验证中失败：

```
情况 A：L1 锚点对应不上 → 该镜头删除
情况 B：L2 Q2 答"删了也成立" → 该镜头删除
情况 C：L3 成片预演情绪曲线断裂 → 替换镜头或新增过渡镜头
情况 D：L3 衔接 5 维度有 2 项以上不过 → 重做该镜头
情况 E：L3 三项以上不过 → 重设计该段大分镜
```

### 14.7 与用户的对齐机制（透明删改）

如果在验证中删/改了某个用户原始示意中的镜头，**必须在最终输出末尾告知用户**：

```
【镜头调整说明】
- 原 B01-S04（俯拍·全景·展示茶馆环境）已删除
  原因：L2 Q2 = "删除后情绪曲线仍能成立"（为切而切）
  补偿：把时长分给 B01-S03（手部搅拌特写延长）

- 原 B02-S02（希区柯克变焦）已替换为缓慢推近
  原因：L3 检查发现整段戏已有 1 个奇技镜头（B01-S05），违反 14.5"过度炫技"
  替换镜头：……

如不接受，请告知"保留原 BXX-SYY"——我会标注"用户保留·非情绪服务"
```

## 第 15 节  好莱坞导演级思维清单

> 这一节是创作时的"自我提醒"，不直接进文档。

```
□ 每个镜头是否回答了"为什么这么拍"
□ 演员视角与观众视角是否对齐
□ 抽象描述是否全部转译为具象画面
□ 情绪词是否已转译为眼神、眨眼、嘴部、呼吸、身体重心或手部动作
□ 限制字段是否写清情绪禁止项，避免假哭、咆哮、夸张皱眉、过度瞪眼或失控表演
□ 大哭、怒吼、尖叫、崩溃等 4 级情绪是否有 1-3 级铺垫，避免第一帧直接满格爆发
□ 关键情绪点是否给到了特写（保证观众接收）
□ 节奏是否长短交错（不要 6 个长镜头叠加）
□ 如本段是打斗、追逐、强动作或特殊转场，是否已判断是否需要读取 04b 运镜/动作速查库
□ 如启用 04b，是否只选少量组合，并把组合编号转写为具体运镜、动作过程和限制项
□ 如资产库提供 ST/CL/NP，是否已继承项目风格、人物审美、场景审美、画面质感、当前场景光影基调和风格禁止项
□ 每个大分镜前置单元是否已输出 `风格交接`，且没有只写 ST/CL/NP 内部编号
□ 如果项目风格光影与本段真实光源冲突，是否以本段真实光源和剧情时段为准，并保留项目质感、反差、颗粒/渲染媒介和风格禁止项
□ 每个运镜是否已升级为摄影机行为锁：位置、距离、高度、方向、稳定程度、速度、起止状态、禁止项

# fuyaoai-vip 使用手册（V2.0）

更新日期：2026-07-13
适用技能：`fuyaoai-vip`
版本：V2.0（34 文件模块化架构）

这份手册面向使用者，说明怎样调用这个技能、每个阶段能产出什么、什么时候该进入下一个模块。内部规则以 `SKILL.md` 和 `references/` 下的专科文件为准；本手册负责把当前技能能力整理成可直接使用的流程。

## 最近功能更新清单

### V2.0 重大升级（2026-07-13）

- **架构模块化**：从 V1.1.2 的 11 个单文件拆分为 34 个专科子模块（01b 六子模块、02 五子模块、04 五子模块、05 六子模块、06 五子模块），按需读取，避免上下文过载。
- **C 导演轨纯净版成为默认**：06 默认输出格式改为 9 字段导演轨（特别注意 / 素材锚定 / 参考-连续性声明 / 风格锁定 / 场景锚定 / 镜头轨 / 声音轨 / 硬锁 / 段末状态），每镜采用 **一行四段** 压缩格式（镜头功能标签 ｜ 镜头/焦点 ｜ 动作/台词 ｜ 光影/转接），7 镜也能轻松控制在 1900 字以内。
- **素材编号一致性闸门**：交付前强制检查，禁止角色/场景/道具编号跨镜头混用。
- **衔接可见化**：不再允许 `接下一大分镜 / 接分镜2` 等模糊衔接，必须写成模型可执行的动作转接或段末画面状态。
- **景深与焦点锁**：必填字段，写清浅/中/大景深、焦点起点落点、禁止跑焦对象。
- **BGM 移交 07**：06 默认不生成 BGM，只输出环境声 / 对白原声 / 同步音效；BGM 设计和情绪曲线全部交给 07 后期模块。
- **音频扩展**：新增画外音、非人声、多人同一拍出声和音量层级。
- **06 一行四段镜头轨**：每镜压缩为 `[镜头功能标签] | 焦段/光圈/景深/机位/构图/运镜 | 人物动作/表情/对白摘要 | 光影方向/色温/转接方式`，不再逐行展开 11 字段。
- **A 标准字段化详细版**降级为特殊场景使用（1-3 镜高精度控制或教学拆解）。
- **节奏档位自动判定**：01/01b/02 建立或体检平台节奏，04 按每个大分镜自动判定 `电影感中速 / 短视频中高密度 / 高密度动作或强钩子 / 慢节奏但高信息`，06 必须继承执行；用户可只改某一组档位。
- **台词自然语速交接**：03 台词专家会标注台词自然语速风险、停顿和表演节奏；06 不强行提速或擅自删台词，超时则建议回 03 精修或拆连续单元。
- **单组图片参考上限**：项目资产库可以超过 9 张图，但每个 Seedance 单元实际上传和引用的图片参考最多 9 张，超出时先筛选、合并、转文字或拆组。
- **动作密度回填**：04b 动作库会把动作密度和节奏档位建议交回 04/06，动作段默认优先考虑 `高密度动作或强钩子`，但不会为凑数添加无功能镜头。

### 历史升级（V1.1.x ~ V2.0 Beta）

- **05/04/06 视觉风格锁定链路**：资产库进入出图和视频链路前，会确认、反推或暂定 `ST` 视觉风格锁定卡、`CL` 色彩光影设计卡、`NP` 风格防跑偏负面词包；04 负责把它们整理成风格交接，06 负责转成可投喂的自然语言。内置 6 种开箱风格：港风写实 / 真人写实电影 / 日漫赛璐璐 / 3D半写实 / 国风水墨 / 赛博朋克。
- **最终提示词不只写内部编号**：`ST001 / CL001 / NP001` 只用于资产管理。给图像模型或 Seedance 的最终 prompt 必须写成具体风格、人物审美、场景审美、画面质感、光影和负面词，不能只写编号。
- **风格兼容多类型**：不只服务港风，也支持真人写实电影感、日漫赛璐璐、3D 半写实动画、国风水墨、赛博朋克或用户自定义参考图风格，避免"用户选港风但人物跑韩风"等审美漂移。
- **04/06 台词与语气独立字段**：分镜和 Seedance 提示词有对白时必须单独输出 `台词与语气`，保留原台词、说话者、语气、音量、语速和口型要求；`主体动作/表情` 只写可见动作、微表情、呼吸、身体反应和口型动作。
- **人物锚定规则**：多人物、多镜头复用或角色容易混淆时，06 固定写 `将 @图片N 中的[身份/外观/服装]定义为 <角色名>`，后续用 `<角色名>` 指代，避免模型看不懂内部资产编号或把人物串脸。
- **Seedance 任务类型判断**：06 会在代码框外标注任务类型：`多模态参考 / 编辑视频 / 延长视频 / 组合任务`。编辑视频使用 `严格编辑 @视频N`，延长视频使用 `向后延长 @视频N` 或自然延长启动句。
- **纯净提示词去管理话术**：06 的可复制代码框只写当前视频要生成的画面、动作、声音、素材用途、保持项和具体可见禁止项；`未启用 / 无则删除 / 不继承 / 不使用上一场 / 不替代` 等内部管理说明会放在代码框外，未命中的增强字段直接省略。
- **时长与节奏规则**：总时长、画幅、模式和任务类型默认放在提示词代码框外；纯净提示词正文按 `镜头1 / 镜头2 / 镜头3` 推进，不默认写硬时间戳。
- **相邻段连续性建议表**：多段 Seedance 输出前，先判断每两段之间建议使用 `视频延长 / 首帧图 + 调度图 / 只首帧图 / 只调度图 / 普通衔接`。
- **Seedance 视频延长**：同场景顺延时，可建议使用上一段成片 `@视频` 自然延长 X 秒；启动句放在提示词最前面，后面仍接正常 06 字段。
- **首帧图与调度图判断**：高风险首帧、多人复杂站位、窗内外/柜台内外/车内外、强连续和场景首现多人调度，会建议是否需要 FF 首帧图、MAP 调度图或 SB 空间侧别锁定卡。
- **切换新场景不继承强连续**：换场景默认不继承上一场点位表、MAP/SB、SCV 或视频延长逻辑，只保留角色、服装、道具和情绪任务等必要连续信息。
- **摄影机行为锁**：把"固定 / 手持 / 跟拍 / 退拍 / 推拉 / 横移 / 环绕 / 焦点转移"等模糊运镜词，升级为可执行摄影机位置、距离、高度、方向、速度、稳定程度、起止状态和禁止项。
- **04b 运镜速查库升级**：`04b-camera-action-cheatsheet` 已扩展为"摄影机行为锁、情绪运镜与动作戏速查库"，用于强运镜、动作戏、追逐、特殊转场和复杂摄影机调度。
- **光影字段可执行化**：04/06 的 `光影` 不只写"电影感"，而要写清光源来源、主光方向、亮区、暗区、脸部受光、轮廓光、色温和明暗反差。
- **情绪表演拆解**：强情绪镜头不只写"悲伤/愤怒/崩溃"，要拆成眼神、眨眼、嘴部、呼吸、手部、肩颈、身体重心和禁止过度表演项。
- **公共空间人群调度**：公共空间按需启用 CR 人群/群演调度卡；06 中转成可见的 `人群密度` 字段，写清前景/中景/远景人数、移动方向和遮挡规则。
- **07 后期音乐与声音设计**：新增 BGM 情绪曲线、Cue Sheet、音乐搜索词、AI 音乐生成提示词、静默点、音效和版权检查流程。

## 1. 这个技能能做什么

`fuyaoai-vip` 是一个端到端中文剧本创作工作室，适合从一个灵感一路推进到剧本、资产、AI 视频分镜、Seedance 2.0 提示词和后期声音方案。

V2.0 已从 11 个单文件重构为 34 个专科子模块，按需读取，避免上下文过载。

它现在覆盖 8 个模块：


| 模块                   | 用途                                                        | 典型结果                                                                                      |
| ---------------------- | ----------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| 01 剧本创作 / 项目开发 | 从灵感、题材、人物关系开发项目                              | Logline、大纲、项目档案、平台节奏档案                                                         |
| 01b 完整剧本写作       | 把项目档案和大纲扩写成完整剧本（6 子模块）                  | 标准影视剧本 / 小说化叙事剧本 / 分集剧本                                                      |
| 02 剧本医生            | 会诊已有大纲、单集、单场或完整剧本（5 子模块）              | 问题清单、优先级、修改建议                                                                    |
| 03 台词专家            | 诊断和精修对白                                              | 逐句改写、角色语言指纹、潜台词、语气停顿                                                      |
| 05 项目资产库          | 整理角色、场景、道具、参考图和资产编号（6 子模块）          | 资产总表、`@图N` 映射、角色/场景/道具卡、ST/CL/NP 风格锁                                      |
| 04 AI 视频分镜         | 把定稿剧本转成 AI 视频镜头语言（5 子模块）                  | 大分镜、镜头字段、摄影机行为锁、运镜、光影、连续性说明                                        |
| 06 Seedance 2.0 适配   | 把 04 分镜转成 Seedance / 豆包 / 火山方舟提示词（5 子模块） | **C 导演轨纯净版**（默认）、`@图片/@视频/@音频` 素材映射、`<角色名>` 人物锚定、一行四段镜头轨 |
| 07 后期音乐与声音设计  | 为生成视频或粗剪设计 BGM、音效和声音策略                    | BGM Cue Sheet、音乐搜索词、AI 音乐提示词、版权清单                                            |

可选参考库：

- `04b-camera-action-cheatsheet`：只在动作戏、打斗、追逐、强情绪运镜、特殊转场、摄影机行为锁或用户明确要求强化运镜时使用。

## 2. 最简单的调用方式

在对话里直接说：

```text
使用 fuyaoai-vip，帮我从 0 到 1 开发一个竖屏短剧项目。
```

如果你已经有材料，就把材料贴在后面：

```text
使用 fuyaoai-vip，下面是我的项目档案和大纲，请开始写完整剧本，模式=小说化，节奏=短剧，分集=是。
```

如果只想做单一任务，也可以直接说：

```text
使用 fuyaoai-vip，下面这场戏只做台词诊断，不改剧情。
```

技能会自动判断当前处在哪个阶段，并在阶段结束时给出下一步导航。

## 3. 推荐总流程

完整项目推荐按这个顺序推进：

```text
01 剧本创作 / 项目开发
→ 平台节奏档案确认
→ 01b 完整剧本写作
→ 02 剧本医生会诊
→ 01b 回稿改写
→ 03 台词专家精修
→ 05 项目资产库
→ 04 AI 视频分镜
→ 06 Seedance 2.0 提示词适配（如使用 Seedance / 豆包 / 火山方舟）
→ 视频生成 / 粗剪
→ 07 后期音乐与声音设计
```

如果你只想做其中一段，可以直接从对应模块开始。技能会优先判断“最早缺失环节”。例如你想要 Seedance 提示词，但还没有资产库和分镜，技能会建议先走：

```text
05 项目资产库 → 04 AI 视频分镜 → 06 Seedance 2.0 适配
```

## 5. 平台节奏档案

只要项目用于抖音、快手、小红书、视频号、B 站短视频、红果、竖屏短剧或其他短视频平台，技能会建立“平台节奏档案”。

平台节奏档案通常包含：

- 发布平台
- 画幅倾向
- 作品类型
- 目标时长
- 节奏密度
- 前 3 秒任务
- 前 15 秒任务
- 前 30 秒任务
- 呼吸感许可
- 留白上限
- 完播 / 互动目标
- 禁止拖慢点

核心原则是：不是所有东西都变快，而是让慢有价值。慢镜头、沉默、空镜和留白可以保留，但必须承担情绪、悬念、信息、人物关系或视觉记忆功能。

## 6. 05 → 04 → 06 视频生产链路

当前版本强化了 AI 视频生产链路，尤其是资产一致性、空间连续性、首帧稳定、公共空间人群调度和摄影机行为锁。

### 6.1 资产库阶段会检查什么

进入 05 项目资产库时，技能会整理：

- 角色、场景、道具、服装、妆发、风格参考
- 参考图、生成图、定稿图
- 角色 / 场景 / 道具编号
- `@图N` 映射
- 核心人物四视图设定图
- 核心 / 高级角色的 3:2 高级角色设定资料卡
- ST 视觉风格锁定卡
- 空场景母版
- CL 光影设计卡
- NP 风格防跑偏负面词包
- CR 人群 / 群演调度卡
- SCV 场景多角度空间包
- MAP 调度图
- SB 空间侧别锁定卡
- FF 首帧需求卡
- PR 道具单实例锁

重要规则：

- 普通角色默认四视图。
- 主角、重要配角 / 反派、怪物、幻兽、机甲、IP 核心角色可额外生成 3:2 高级角色设定资料卡。
- 场景母版默认必须是空场景，不把主角、路人、群演或随机顾客烘焙进去。
- 公共空间需要人流时，用 CR 人群卡交给分镜和提示词阶段处理。
- 如果同一关键道具已经出现在场景母版、场景角度图或首帧图里，同时还要上传 PR 道具外观图，必须启用 PR 道具单实例锁，写清“PR 只补同一件道具外观，不新增第二个实例”。
- `ST/CL/NP` 是内部资产管理编号；角色图、场景图、首帧图、高级角色资料卡和视频提示词必须把这些编号展开成自然语言。
- 如果风格光影和当前场景真实光源冲突，以当前镜头真实光源和剧情时段为准，同时保留项目风格的画面质感、反差、颗粒/渲染媒介和防跑偏负面项。

### 6.2 AI 视频分镜阶段会检查什么

进入 04 AI 视频分镜时，技能会把定稿剧本转成镜头语言，并检查：

- 每段镜头的焦段、光圈、机位、构图、摄影机行为锁和运镜
- 主体动作和表情是否可见
- 有对白时是否独立保留 `台词与语气`，无对白时是否写明“无对白”
- 光影是否写成可执行布光说明
- 是否存在同场景强连续、回切、批量生成、窗内外 / 柜台内外 / 车内外穿帮风险
- 相邻段之间是否建议视频延长、首帧图 + 调度图、只首帧图、只调度图或普通衔接
- 是否需要 SCV 多角度空间包
- 是否需要 MAP 调度图
- 是否需要 SB 空间侧别锁定卡
- 是否需要 FF 首帧图
- 公共空间是否需要 CR 人群调度
- 是否继承 ST/CL/NP，并整理为交给 06 的“风格交接”
- 每段的下一段衔接和段末状态

### 6.3 Seedance 2.0 适配阶段会输出什么

进入 06 Seedance 2.0 适配时，技能会把 04 分镜转成 Seedance / 豆包 / 火山方舟可用的提示词包。

#### 默认输出：C 导演轨纯净版

V2.0 起，06 默认输出 **C 导演轨纯净版**，采用 9 字段结构 + 一行四段镜头轨：


| 字段                | 说明                                                                                                             |
| ------------------- | ---------------------------------------------------------------------------------------------------------------- |
| **特别注意**        | 本段最高优先级画面/摄影/表演红线                                                                                 |
| **素材锚定**        | `@图片N / @视频N / @音频N` 统一声明                                                                              |
| **参考-连续性声明** | FF首帧/MAP调度/SB侧别/SCV角度/PR道具锁/视频参考 统一收束为一行                                                   |
| **风格锁定**        | ST/CL/NP 展开为自然语言；CG/UE5/MetaHuman/动捕/3A游戏过场等数字风格也在此声明                                    |
| **场景锚定**        | 场景母版 +`@图N` 映射，写清空间方位和时段                                                                        |
| **镜头轨**          | **一行四段**：`[镜头功能标签] | 焦段/光圈/景深/机位/构图/运镜 | 人物动作/表情/对白摘要 | 光影方向/色温/转接方式` |
| **声音轨**          | 环境声、对白原声、同步音效、画外音、非人声、多人同一拍出声和音量层级（不生成 BGM）                               |
| **硬锁**            | Must Keep + Avoid + 素材编号一致性闸门                                                                           |
| **段末状态**        | 本段结束时的画面状态、人物位置、道具位置和情绪状态                                                               |

**一行四段格式示例**：

```text
【镜头1-建立空间】 | 24mm/中景深/低角度仰拍/固定机位 | 沈瑜从柜台后起身，把录音笔推过台面 | 暖黄顶光→侧光，柜台反光分界内/外侧
【镜头2-反应】 | 85mm/浅景深/肩后过肩/轻微手持微晃 | 林昭接过录音笔，指尖停顿，视线从笔移到沈瑜脸上 | 侧逆光勾勒肩线，焦点从笔→沈瑜眼睛
```

7 镜以内轻松容纳在 1900 字安全线内，2000 字为硬上限。超出时先删重复约束和空泛词，再按情绪转折或空间阶段拆段。

#### A 标准字段化详细版（特殊场景）

旧版 A 模式（11 字段逐项展开）降级为特殊场景使用：

- 1-3 镜高精度控制
- 教学拆解或新人上手
- 用户明确要求旧版格式

#### 人物锚定

多主体或角色跨镜头复用时，06 会先做人物锚定：

```text
将 @图片1 中的青年男性、黑金纹饰旧袍定义为 <玄衡>，将 @图片2 中的女性、暗青色战衣定义为 <青鸢>
```

后续镜头直接用 `<角色名>` 指代，不再逐镜复述外观。

#### 素材编号一致性闸门

交付前强制检查：同一角色在所有镜头中必须使用同一个 `@图片N` 编号，禁止不同镜头给同一角色引用不同图片编号；场景、道具同理。发现混用时自动修正并标注「一致性修正」。

#### 衔接可见化

不再允许模糊衔接词：

- ❌ `接下一大分镜` / `接分镜2` / `动作延续`
- ✅ 必须写成模型可执行的：`镜头缓推至沈瑜眼部特写，下一段从此特写开始` / `段末定格在录音笔特写，下一段以录音笔转场`

#### 声音轨规则

- 06 默认**不生成 BGM**，BGM 设计和情绪曲线全部交给 07 模块
- 06 只输出：环境声、对白原声、同步音效（如脚步声/关门声/物件触碰声）
- 新增支持：画外音、非人声（动物叫声/机械声/环境特效声）、多人同一拍出声和音量层级（如「背景人声渐弱至 -12dB，主角对白保持 0dB」）

#### 任务类型标注

06 会在代码框外标注：

```text
任务类型：多模态参考 / 编辑视频 / 延长视频 / 组合任务
建议生成时长：8 秒
画幅：9:16
```

这些元信息不放进纯净提示词代码框，方便复制时只取模型要吃的正文。

#### 自动增强项判断

06 不再要求用户手动选择 A/B/C，内部自动判断是否启用增强项：


| 自动增强项      | 适合场景                                                           |
| --------------- | ------------------------------------------------------------------ |
| 视频延长        | 同场景顺延，下一段是上一段动作、镜头、光线和道具状态的自然继续     |
| FF 首帧图       | 第 0 秒构图、人物初始位置、道具位置、空间内外侧容易跑偏            |
| MAP/SB 调度图   | 多人走位、轴线、遮挡、窗内外、柜台内外、车内外等空间关系容易穿帮   |
| SCV 场景角度    | 核心场景、反打、回切、复杂空间或高穿帮场景需要锁定拍摄方向         |
| CR 人群调度     | 公共空间、街道、商场、车站、学校、医院、营业餐厅等需要真实路人层次 |
| PR 道具单实例锁 | 场景/首帧里已有同一件道具，又上传 PR 道具图，需避免生成第二个同款  |
| 复杂运镜增强    | 一镜到底、手持、跟拍、退拍、遮挡转场、动作戏或强声音叙事           |

## 7. 07 后期音乐与声音设计

当视频已经生成、完成粗剪，或准备发布成片时，使用 07 模块。

可选输出模式：


| 模式                | 用途                                                                |
| ------------------- | ------------------------------------------------------------------- |
| A 快速找音乐版      | 快速判断哪里要音乐、搜什么关键词                                    |
| B 全片 Cue Sheet 版 | 给剪辑时间轴使用，包含音乐进出、淡入淡出、突停、静默点              |
| C AI 音乐生成版     | 输出 Suno / Udio / ElevenLabs Music / Stable Audio 等工具可用提示词 |
| D 声音体检版        | 检查 BGM 是否盖对白、情绪是否过满、结尾是否有声音钩子               |

07 通常需要：

- 粗剪或成片总时长
- 每段视频顺序和时长
- 对白 / 字幕 / 旁白时间点
- 情绪爆点、反转点、沉默点、结尾钩子
- 发布平台和画幅
- 是否商用发布
- 准备用素材库找音乐，还是用 AI 音乐工具生成

如果还没有粗剪时间轴，但已经有 04 分镜或 06 提示词，技能可以先做“预配乐方案”，并标注时间码暂定，等粗剪后复核。

## 10. 阶段结束时会得到什么

每个阶段结束，技能都会输出类似：

```text
【阶段交接】
当前阶段：
已确认内容：
平台节奏档案：
主要问题/风险：
下一步建议：
建议调用模块：
下一步需要材料：
可直接复制调用语：
```

特殊阶段会额外输出：

- 完整剧本写作：`【剧本写作交接】`
- 资产库：`【资产库交接】`
- Seedance 2.0：`【Seedance 2.0 交接】`

这样做是为了让项目能持续往下游走，不会停在某个产物上不知道下一步做什么。

## 11. 术语速查


| 术语                   | 含义                                                                                                           |
| ---------------------- | -------------------------------------------------------------------------------------------------------------- |
| `@图N`                 | 资产库交给分镜使用的参考图编号                                                                                 |
| `@图片/@视频/@音频`    | Seedance / 豆包 / 火山方舟官方提示词中的素材引用                                                               |
| `@Image/@Video/@Audio` | 第三方 API 或旧项目可兼容的英文素材引用                                                                        |
| `<角色名>`             | Seedance 人物锚定标签，用固定句式把某张人物图里的稳定特征定义成可复用角色                                      |
| CH                     | 角色资产                                                                                                       |
| SC                     | 场景资产 / 场景母版                                                                                            |
| PR                     | 道具资产                                                                                                       |
| PR 道具单实例锁        | 场景/首帧中已有某道具且又上传 PR 图时，锁定为同一件物体，防止生成第二个同款道具                                |
| ST                     | 视觉风格锁定卡，用于统一项目风格、媒介类型、人物审美、场景审美和画面质感（内置6种开箱风格）                    |
| CL                     | 光影设计卡                                                                                                     |
| NP                     | 风格防跑偏负面词包，用于约束人物、场景和画面质感不要跑到错误审美                                               |
| CR                     | 人群 / 群演调度卡                                                                                              |
| SCV                    | 场景多角度空间包，含 PLAN 和 V01-V04 空场角度图                                                                |
| MAP                    | 调度图，用于人物点位、移动路线、摄影机安全区                                                                   |
| SB                     | 空间侧别锁定卡，用于避免窗内外、柜台内外、车内外等穿帮                                                         |
| 摄影机行为锁           | 把固定、手持、跟拍、退拍、推拉、横移、环绕、焦点转移等写成可执行摄影机位置、距离、方向、速度、稳定程度和禁止项 |
| 景深与焦点锁           | 04/06 必填字段，写清浅/中/大景深、焦点起点落点、禁止跑焦对象                                                   |
| 软时间节奏             | 不写硬时间戳，只写镜头顺序、前中后段、每镜约多少秒、最后一镜稍停等节奏参考                                     |
| C 导演轨纯净版         | V2.0 默认输出格式，9 字段 + 一行四段镜头轨，7 镜可控在 1900 字内                                               |
| 一行四段               | 每镜压缩为`[功能标签] | 镜头/焦点 | 动作/台词 | 光影/转接`，替代旧版 11 字段逐行展开                           |
| 素材编号一致性闸门     | 交付前强制检查，同一角色/场景/道具在所有镜头中必须使用同一`@图片N` 编号                                        |
| 衔接可见化             | 禁止`接下一大分镜` 等模糊衔接，必须写成模型可执行的动作转接或段末画面状态                                      |
| FF                     | 首帧图 / 首帧需求卡，只锁定第 0 秒                                                                             |
| 视频延长               | Seedance 2.0 同场景顺延时，把上一段成片作为`@视频` 继续自然延长；第三方接入端可用 `@Video`                     |
| A/B/C 首帧风险         | A 必须首帧，B 建议首帧，C 可不用首帧                                                                           |
| Must Keep              | 生成时必须保持的角色、场景、道具、关系和动作                                                                   |
| Avoid                  | 生成时必须避免的问题                                                                                           |

## 12. 维护说明

本手册只解释怎么使用技能，不替代内部规则。

维护时优先级如下：

1. 专科能力变化时，先更新 `references/` 对应文件。
2. 模块顺序、路由、阶段交接变化时，更新 `SKILL.md`。
3. 使用方式、常用调用语、用户可见流程变化时，同步更新本手册。

当前手册已同步以下更新重点：

- V2.0 架构重构：11→34 文件模块化拆分，01b/02/04/05/06 分专科子模块。

- 06 声音轨规则：BGM 移交 07，06 只输出环境声/对白原声/同步音效；新增画外音、非人声、多人同一拍出声和音量层级。
- 新增并明确 `01b 完整剧本写作` 下游流程。
- 新增 `07 后期音乐与声音设计` 模块。
- 明确短视频平台节奏档案。
- 强化 05 资产库的四视图、高级角色设定资料卡、空场景母版、ST/CL/NP（内置6种开箱风格）、CR、SCV、MAP、SB、FF、PR 道具单实例锁。

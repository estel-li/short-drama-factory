# BANK A · 光学 —— 视角、结果短语、锁

**使用规则：**
1. **提示词语言＝输入语言**：中文提问 → 中文提示词；一条提示词只用一种语言。
2. **本表只取中文栏**：A.1 给逐字块，A.4 给结果短语栈，A.5 给四条锁；同一段提示只抄一套。
3. **度数与数字不翻译**：`47°` 就是 `47°`；`20–25 米` 只把单位写成中文，数值不动。

**词表：** `视角` · `景别` · `机位` · `运镜` · `光学`。语料里 `水平视角` 与 `对角视场` 都出现过（同一支 50mm 可写"水平视角约 40°"或"47° 对角视场"）；**本表一律用对角视角**。

## A.1 六档 AOV（视角）逐字块

〔译〕＝中文语料没有整段原文，按英文对照块翻译；括号内的数字与距离为原值。

```text
47° —— 标准常焦，机位 3 至 5 米
47° 对角视场，标准常焦镜头特性，摄影机距主体 3 至 5 米，自然人眼透视。零明显畸变，脸与身体比例
真实，景深舒适，背景可读但不夸张，经典、落地的电影构图。
```

```text
84° —— 经典广角，机位 1 至 1.5 米
84° 对角视场，经典广角镜头特性，摄影机距主体 1 至 1.5 米，必要时略微仰拍。广角带来的强而自然的
纵深扩张，前景身体显得更大更近，环境一直铺到画框边缘，空间上下文深而可读，建筑直线保持笔直、
无鱼眼弧。
```

```text
107° —— 广角矫正，机位 0.5 至 0.8 米
107° 对角视场，广角矫正镜头特性，摄影机距前景主体 0.5 至 0.8 米。贴眼前景巨大，四周环境向画框
四边铺开，全程边到边清晰，直线保持笔直，画面边缘有轻微色散，无圆形暗角、无鱼眼气泡。
```

```text
29° —— 短长焦人像，机位 4 至 6 米
29° 对角视场，短长焦人像镜头特性，摄影机距主体 4 至 6 米。靠焦段拉近，不靠摄影机走近。主体
锐利，背景开始向其身后压缩，脸型讨喜且稳定，背景化进柔滑奶油虚化，主体从环境里清晰地跳出来。
```

```text
18° —— 经典长焦，机位 6 至 8 米
18° 对角视场，经典长焦镜头特性，摄影机距主体 6 至 8 米。强背景压缩，远处元素像是堆叠到主体
身后，薄焦只保眼睛与关键面部特征，前后景一起化进柔焦，画面像被远距离观察。
```

```text
8° —— 超长焦观察，机位 20 至 25 米
8° 对角视场，超长焦观察镜头特性，摄影机距主体 20 至 25 米。极端背景压缩，背景被压平成一片
柔和色块，只有主体锐利，其余全部化进奶油虚化。画面像远处的狗仔、野生动物纪录片或体育转播。
前景遮挡为必选项：虚化的前景物体占画面下方 30 至 45%，作为过大的暗色虚块，从很远处把主体框住。
```

## A.2 距离与用途速查

| 视角 | 相机距离 | 身体占比 | 用于 |
|---|---|---|---|
| 107° | 0.5–0.8 m | 局部/贴脸 | 大尺度地理、沉浸 |
| 84° | 1–1.5 m | 半身~全身 | 环境动作、贴身人物 |
| 47° | 3–5 m | 全身~半身 | 纪实、中性 |
| 29° | 4–6 m | 胸上 | 中景肖像 |
| 18° | 6–8 m | 头肩 | 情绪特写、窥视 |
| 8° | 20–25 m | 头/点 | 观察、狗仔、野生动物 |

## A.3 内容 → 视角（含中文粘贴写法）

| 内容类型 | 视角 | 中文写法（语料原文） |
|---|---|---|
| 脸部肖像、环境仍可见 | 84° | `【景别·广角近景】：摄影机贴近`（俗称"亲密广角"） |
| 中景肖像 | 29° | `脸永远由中焦人像镜头拍摄` |
| 紧的情绪特写 | 18° | `18° 经典长焦隔距锁定目标` |
| 远距离观察 | 8° | `8° 超长焦` + `长焦把纵深压扁`（必带前景遮挡 + 大气霾） |
| 纪实动作 | 47° | `47°（约50mm），机位约2.5米` |
| 广域环境动作 | 84° | `84°对角线视场，直线笔直，无鱼眼` |
| 大尺度地理 | 107° | `【本镜用 12mm 超广角拍摄】` |
| 细节、微距 | 29° 或 18° | `100mm微距长焦，F2.8，焦平面严格锁定`（自成插入镜，不与广角同拍） |
| 压缩式窥视肖像 | 18° 或 8° | `300mm长焦…只有她的脸锐利、毛孔可见`（前景遮挡 + 霾） |
| **不要混** | — | 人脸 + 地理 + 微距在同一拍＝镜头漂移 |

**A.3 对齐口径：** `直线笔直` / `无鱼眼` / `摄影机贴近` 属广角，只管环境与空间；`长焦把纵深压扁` / `只有主体锐利` 属长焦，只管肖像与观察；`焦平面严格锁定` 属微距，自成插入镜。三类混进同一拍＝镜头漂移。

## A.4 结果短语栈

**标注：** 〔语料〕＝案例原文逐字节选；〔译〕＝无原文，按英文版翻译。每档 4–6 条；**配额同英文版：长焦 ≥4 条，广角 ≥3 条**（29°、18°、8° 为长焦档，84°、107° 为广角档，47° 为常焦档）。

**47° · 标准常焦（3–5 米）**

- 〔语料〕`自然人眼透视`
- 〔语料〕`47°（约50mm），机位约2.5米`
- 〔语料〕`47° 标准常焦`
- 〔语料〕`景别差异只靠机位物理远近`
- 〔语料〕`镜头锁定平稳`
- 〔译〕`零明显畸变，脸与身体比例真实，景深舒适`

**84° · 经典广角（1–1.5 米）**

- 〔语料〕`84°对角线视场，直线笔直，无鱼眼`
- 〔语料〕`【景别·广角近景】：摄影机贴近`
- 〔语料〕`画面边缘直线保持笔直`
- 〔语料〕`无镜头眩光,无光线拉丝`
- 〔语料〕`球面广角`（原句：`球面广角/中焦、非变形宽银幕`）
- 〔译〕`前景身体比真实更大、更贴镜头，环境仍铺到画框边缘`

**107° · 广角矫正（0.5–0.8 米）**

- 〔语料〕`【超广角特性·硬性】极大景深——全程一切清晰、无背景虚化、无 rack focus`
- 〔语料〕`超广角里巨大、逼近、耸立`
- 〔语料〕`【本镜用 12mm 超广角拍摄】`
- 〔语料〕`光学:宽广沉浸,镜头按段标注,直线校正、无鱼眼,每段锁定一支镜头`
- 〔语料〕`水平视角极宽、约 100–112°`
- 〔译〕`环境铺到画框四边，边缘有轻微色散，无圆形暗角、无鱼眼气泡`

**29° · 短长焦人像（4–6 米）**

- 〔语料〕`85mm长焦，F1.4极浅景深`
- 〔语料〕`配合浅景深、锐利主体衬幽暗`
- 〔语料〕`脸永远由中焦人像镜头拍摄`
- 〔语料〕`背景刻度线压缩在长焦里`
- 〔语料〕`浅景深、电影感虚化（真实景深、奶油散景）`
- 〔译〕`靠焦段拉近，不是摄影机走近；脸型稳定、主体从环境里跳出来`

**18° · 经典长焦（6–8 米）**

- 〔语料〕`景深浅到只剩一层薄焦平面，其余化进浓重奶油虚化`
- 〔语料〕`焦平面严格锁定在…脖颈侧面`
- 〔语料〕`背景刻度线压缩在长焦里`
- 〔语料〕`配合浅景深、锐利主体衬冷雾`
- 〔译〕`薄焦只保眼睛与关键面部；前后景一起化进柔焦，像被远距离观察`

**8° · 超长焦观察（20–25 米）**

- 〔语料〕`8° 超长焦`
- 〔语料〕`长焦把纵深压扁`
- 〔语料〕`300mm长焦她的面部超大特写`
- 〔语料〕`长焦过肩：右肩在画面左侧前景、柔焦`
- 〔语料〕`几串竖向虚影出现在画框两侧前景，纯粹是压缩造成的——她并不贴着帘子`
- 〔译〕`前景虚化暗块占画面下方 30–45%，把主体框在很远的地方`

**语料支撑：** 六档均有原文（47/84/107/29/18/8）；集中样本为 `red-flag`、`kok-boru-film`，另有 `anerneq`、`zephyr` 等补足。

## A.5 四条反阻尼锁（anti-drift lock）

```text
长焦锁
本镜全段锁定长焦，绝不换镜头、绝不焦段漂移。需要更宽的画面，只把摄影机往后退、保持同一长焦焦段；
背景每一帧都保持压缩与化开。
```

```text
广角锁
本镜全段锁定广角，任何部分都不变成长焦人像。环境始终围绕主体可见，摄影机始终贴近，
画面保持广角的空间扩张与可读纵深。
```

```text
标准锁
无极端广角畸变、无长焦压缩；画面保持自然人眼透视，平实、中性。
```

```text
多镜锁
全片同一颗镜头，X° 对角视场；段内与段间不允许焦段漂移。每段开场写：镜头锁 A＝X°；
每段收尾写：镜头检查 A：X° 保持、无漂移。
```

## A.6 镜头禁区 → 改写法

| 写了 | 会发生 | 改成 |
|---|---|---|
| `广角特写` | 自相矛盾，脸被拉弯 | `84°广角近景`（要环境）或 `18°`（要脸） |
| `长焦全景` / `长焦大远景` | 自相矛盾，模型二选一 | 全片一个视角 + 机位物理远近 |
| `超广角拍脸` | 脸/身体被拉伸外凸 | 要么写成刻意风格（`广角透视变形`），要么换 `29°` |
| `一颗镜头从全景推到特写` | 镜内变焦，景别漂移 | `摄影机绝不推近、拉远、变焦——每段锁定景别` |
| `85mm f1.4` 当视频主控 | 几乎无效 | 写结果：`只剩一层薄焦平面，其余化进浓重奶油虚化` |
| 只写 `不要广角` | 弱偏置，且注入概念 | 先写 `84°对角线视场`，再加一句 `焦段全程锁定` |
| `extreme wide-angle lens` | 模型取最广的刻板印象，脸变形 | `84° … 机位 1 至 1.5 米` |
| `wide shot` 当镜头指令 | 画面变空、人变远 | 视角 + 距离 + 结果短语 |
| `establishing shot` 当镜头指令 | 空景、无人 | `107° … 机位 0.5 至 0.8 米` |
| `tight wide framing` | 自相矛盾，模型二选一 | 二选一，别写"紧的广" |
| `zoom out plus wide-angle` | 镜内两次构图变化 | 单一运镜主轴 |
| 同一镜复合运镜 | 运镜平均、不成立 | `Camera moves from X to Y only`（运镜只从 X 到 Y，没有第二段） |
| 一镜多内容类型 | 镜头漂移 | 拆成插入镜 |
| 只写负向镜头控制 | 弱偏置，且注入概念 | 先写想要的视角，再加一条镜内锁 |

## A.7 多镜一致性骨架

```text
全片统一一颗镜头：29° 短长焦。
镜头 A（0.0–2.5 秒）：29° … 镜头锁 A＝29°。2.5 秒硬切。
镜头 B（2.5–6.0 秒）：29° … 镜头锁 B＝29°，无平滑视角过渡。
每段收尾：镜头检查：29° 保持、无漂移。
```

换视角的唯一合法位置是硬切：`换视角只在硬切处，镜内不变焦。`

# J · 剧情参考路由 —— 什么剧情，怎么写提示词，用什么镜头语言

> **这是操作手册，不是索引。** 每个叶子都是「拿到就能写」的完整配方：重心写哪几节、每节多深、镜头怎么给、光怎么给、声怎么写、哪几条锁必须写死、最容易怎么坏、该开哪几个文件、以及一句可以直接放进提示词开头的配方句。

---

## 怎么用（四步）

1. **先认叶子。** 用每个叶子第一行的 `**识别信号**` 去对用户的原话。对不上任何一个 → 回到 `SKILL.md` §3.1 填剧情卡，别硬套。
2. **再落笔。** 按叶子的 `**提示词重心**`（哪几节加厚、各写多少字）+ `**镜头语言**` + `**光与色**` + `**声音**` 四段直接写；`**配方句**` 放进提示词开头。
3. **然后过锁。** 把 `**必须写死的锁**` 里点的 2–3 条，逐条写成一句锁句，挂在 `正向锁定` 那一节。
4. **最后开文件。** 按 `**加载**` 开 2–5 个文件，别整本读（`SKILL.md` §3.3 的加载预算是硬规则）。

**一个请求命中两个叶子怎么办？** 常见组合：双人对手戏 + 恐怖、群像仪式 + 音乐卡点、劳作 + 微距。规则是**取交集，不叠加**：

- **镜头语言、光、声：取两者更"紧"的那一套。** 双人对手戏用 29°/47° 齐眼、一场一光向；恐怖要长焦压缩 + 单源暗部。交集＝**29° 长焦 + 单源侧光 + 对手戏的轴线**，不是"既齐眼又低角度"。
- **重心：两张清单取并集，但总字数按较紧的那张控制。** 两套都要加厚的节，合并成一节写，不要写两遍。
- **锁：取并集**，五锁本来就该全写，两个叶子只会让某几条更关键。
- **永远不要**把两套光（比如"柔和窗光"和"硬逆光"）同时写进去——那是两块光源，不是交集。

## A · 单人与内心（3 个叶子）

一个人占满画面时，**信息全在微事件里**：脸的微小动作、呼吸、眼睛的落点。这类镜头的失败几乎都不是"演得不够"，而是"每一秒没有具体的事发生"。

### J-A1 · 单人情绪特写

**识别信号：** "他听到消息那一下""她忍住没哭""给我一个表情""眼里有变化""情绪特写""最后定格在他脸上"。
**提示词重心：** 加厚 `动作时间轴`（中文口径 ~1,300 字，1,000–1,600：镜内 3–5 个时间片，每片一个微事件，如"喉结动一下、眼睛先亮"）、`物理`（~650 字：面部肌肉、泪的路径、呼吸、皮肤潮红，逐处写行为）、`光照`（~150–450 字：单源、色温、明暗侧、允许高光清单＝只允许眼底一点光）。`表演` 段 300–500 字（写战术，不写情绪）。可薄：`空间地理` 只写背景与相机距离（150–250 字）、`拍摄模式` 只写"单镜、锁定、总时长"。
**镜头语言：** 29° 短焦人像，相机距 **4–6 米**（用焦段压，不是走近）；机位**齐眼或略低 5°**；**锁定**——不推不摇不呼吸式漂移；允许前景遮挡（对方肩线、酒杯、门框、发梢）压住画面边缘。要更强的压迫感换 **18°**、距 **6–8 米**，此时背景必须完全化开。
**光与色：** **一个源**，侧面或侧逆（窗光 / 台灯 / 火光），色温写数字（3200K 暖 / 5600K 冷）；**相机在暗侧**，脸一半落在阴影里；**曝光优先给眼睛和皮肤高光，不给整张脸**；色比 60:30:10，主色占 60%。
**声音：** 室内底噪（房间自己的低频、远处街道）＋ **3 个带秒数的声事件**（`3.4s 一次吞咽`、`6.1s 椅子吱一声`、`9.8s 远处关门`）＋ 人声处理：有台词就贴耳近麦、气口保留；没台词就写"只有呼吸与房间底噪"。
**必须写死的锁：** ① **首帧占位**——`硬切后首帧已是他的面部特写，眼睛睁开、嘴微张，情绪已在中段。` ② **视线朝向**——`他的视线落在画外右侧某一点，不移开镜头。` ③ **空间走位**——`她占画面中偏左，头部在 y40% 一线，肩线被前景遮住下缘。`
**失效表现：** 死眼、机械眨眼、眼神光发干（解法见 `13-acting` T-13-10，E.2 A15）→ 写"眨眼缓慢刻意、眼睛比头先到半拍"；特写上满脸小动作（E.2 A14）→ 越紧的镜头动得越少，只留眼睛和念头；情绪复位（E.2 A12）→ 把余波写进最后一个时间片；脸被补平、没有真正的黑（E.4）→ 删掉补光句，写曝光优先给眼睛。
**加载：** `13-acting`（表演方法）+ `05-light`（光）+ `04-optics`（视角与距离）+ `banks/G-prompt-depth`（每节多深）+ `banks/E-failure-atlas`（返工时按症状反查）。
**配方句：** `单人情绪特写：29° 短焦、相机 4.6 米、齐眼略低，一个侧逆光源，脸一半在阴影里，只允许眼底一点高光。`

### J-A2 · 独白 / 自述（有台词）

**识别信号：** "他对着镜头说""自白""旁白式自述""回忆叙述""一个人说给谁听""最后一段话"。
**提示词重心：** 加厚 `音频`（中文 ~180–480 字：台词逐字、气口、环境让路 ducking、前后各 ≥1 秒静默）、`表演`（400–600 字：这段台词在跟谁说、战术是什么）、`动作时间轴`（~1,300 字：把台词切成 3–5 个时间片，每片一个动作＋一句话）、`场景背景`（300–600 字：为什么现在说、谁在听）。可薄：`物理`（只写嘴、下颌、喉结、呼吸）、`空间地理`（只写他与背景的距离）。
**镜头语言：** 29° 或 47°，相机 **2.5–4 米**；机位**齐眼**（观众与他平视）；**锁定**，或极缓推——只允许 `10 秒内推进 0.10 米` 这种量级，并写明"推近只靠相机物理前进，焦段不变"；前景遮挡可选（门框、后视镜、栏杆）。
**光与色：** 单源窗光或台灯，侧光；相机在暗侧；曝光优先给眼睛；冷色 5600K 或钨丝 3200K，二选一写死；色比 60:30:10。
**声音：** 台词**逐字**保留原语言；前后各 ≥1 秒静默；环境声在台词下让路（ducking）；**无配乐、无旁白、无字幕**；把气口写进时间轴（`4.2s 吸一口气`、`7.8s 说到一半停住`）。
**必须写死的锁：** ① **台词时长匹配**——句子秒数要放得进镜头，放不进就拆两镜。② **视线朝向**——`他直视镜头` 或 `他的视线落在画外左侧，镜头只是旁观`，二选一，不能含糊。③ **首帧占位**——`首帧他已开口或即将开口，嘴微张，不在等提示。`
**失效表现：** 台词被塞到中段、前半秒变默片（E.2 A3 的听觉版）→ 写"台词在 0.3 秒内起句"；多余语气词、角色自己叫名字 → 只念引号里那句（`banks/H-dialogue-safety` H.1）；口型与声不同步 → 正脸、少遮挡、短句；观众听不清 → 写 ducking，不写"加大音量"。
**加载：** `13-acting` + `08-sound` + `banks/H-dialogue-safety`（台词规则与安全用语）+ `04-optics` + `banks/G-prompt-depth`。
**配方句：** `独白镜：29° 齐眼、相机 3 米锁定，单源窗光从画面左来，台词逐字、前后各留 1 秒静默。`

### J-A3 · 人物出场介绍

**识别信号：** "介绍这个角色出场""他第一次出现""亮相""登场""建立这个人""让观众记住这张脸"。
**提示词重心：** 加厚 `参考图`（中文 ~950 字：先一句汇总好几张、每张 `{{ref N}}` 是什么，再逐张写"拥有什么/不拥有什么"、一句 `100% 匹配参考`）、`空间地理`（~450 字：他与固定地标的关系）、`开场状态`（~560 字/镜：x%/y%、朝向、手在哪、重心在哪）、`物理`（~650 字：衣料坠感、鞋与地面的接触、手上的小动作）。可薄：`音频`（3 个事件即可）、`风格`（一行锚点 + 色比）。
**镜头语言：** 先用 **84°** 或 **107°**（0.5–1.5 米）交代他在空间里的位置，再用 **47°**（2.5 米）落到人；**一镜内不换焦段**，要换就硬切；机位由低到高（先低角让他显得有分量）；允许前景掠过（人群、柱子、烟）。
**光与色：** **两个源**：环境主光（窗/天光）＋ 一个勾轮廓的侧逆；相机在暗侧；**曝光优先给轮廓线**，脸允许半暗；色比 60:30:10，用一个记忆点色（他身上的红、金属的冷）占 10%。
**声音：** 环境底噪 ＋ **一个标志性声事件**（`2.1s 靴底踩碎玻璃`、`5.0s 门在他身后合上`）＋ 无对白；若他开口，只给一句，且 0.3 秒内起句。
**必须写死的锁：** ① **首帧占位**——`开场第一帧他已经完整在场，一个广角，无台词、无新角色进入。` ② **地标邻近**——`他站在门框左缘外侧约一步，肩与门框平行。` ③ **空间走位**——`他位于画面右三分之一，面朝镜头左前方，离最近的柱子约两米。`
**失效表现：** 第一镜是空景、人后进来（`13-acting` 的安置闪反例）→ 用"全员已在位的广角"当第一镜；身份逐镜漂移（E.1 F1）→ 每镜逐字粘贴"描述 + 图"资产对；人物与空间一起平移（E.1 F4）→ 补地标邻近锁；出场太慢、观众前 3 秒不知道看谁 → 把最强的动作或光放在第一秒。
**加载：** `10-assets`（角色/地点板）+ `03-space`（走位与开场状态）+ `02-cast`（外形档案）+ `13-acting`（表演）+ `banks/G-prompt-depth`。
**配方句：** `人物出场：107° 广角 0.8 米交代空间，硬切到 47°、2.5 米落到他身上，单源侧逆光勾轮廓。`

## B · 关系与人群（5 个叶子）

两个人的戏靠**听**，一群人的戏靠**波**。这类镜头最容易死在"两个人的光来自相反方向""所有人同时反应"。

### J-B1 · 双人对手戏（对白驱动）

**识别信号：** "两个人吵架""谈判""审问""对话来回""他对她说""对峙台词"。
**提示词重心：** 加厚 `表演`（每人一段 300–500 字：目标/障碍/战术/节拍，两人**不同战术**）、`动作时间轴`（~1,300 字：按"谁说话、谁听、谁动"切片）、`空间地理`（~450–900 字：两人位置、轴线、中间隔什么）、`开场状态`（~560 字/镜：两人 x%/y%）。可薄：`风格`（一行锚点）、`物理`（只写手、衣、呼吸）。
**镜头语言：** **正反打**：47° 或 29°，相机 **1.5–3 米**，机位齐眼；**轴线锁死**，反打只做 `REVERSE CUT`；过肩时把对方的肩线留在画面边缘；`一个镜头一种内容类型`（别在同一镜里既给脸又给环境）。
**光与色：** **一场一光向**，正反打**不许换侧**；侧光或侧逆；相机在暗侧；曝光优先给两人的眼睛；色比 60:30:10，暖主色 60%（室内）或冷主色（夜外）。
**声音：** 台词逐字＋气口；**重叠**允许，但关键词干净；环境声在台词下让路；没有台词的那一方要有"听"的声（`3.5s 他吸了一口气`）。
**必须写死的锁：** ① **轴线**——`相机始终在窗户一侧，两人之间的轴线绝不跨越；A 永远画面左，B 永远画面右。` ② **视线与身体朝向**——`A 的视线锁在 B 脸上，身体朝画面右 15°。` ③ **多镜连续性**——`每一刀后是同一张脸、同一件外套、同一侧光。`
**失效表现：** 越轴、观众失去方位（E.1 F4）→ 写死轴线那一句；正反打两侧光反向 → 一场一光向；听者一张死脸（E.2 A3）→ 反应从对方话尾之前开始；整场一个战术（E.2 A4）→ 标 2–4 个节拍，每拍换一个战术动词。
**加载：** `13-acting` + `02-cast` + `07-sequence`（正反打与连续性账本）+ `08-sound` + `banks/H-dialogue-safety`。
**配方句：** `双人对手戏：47° 齐眼、1.8 米正反打，相机在窗户一侧绝不越轴，一场一光向。`

### J-B2 · 亲密 / 告白

**识别信号：** "告白""接吻""拥抱""和好""靠得很近""低声说话""两个人额头抵着"。
**提示词重心：** 加厚 `物理`（~650 字：皮肤接触、呼吸、布料挤压、头发垂落方向、眼泪或汗的路径）、`表演`（500–700 字：两人各自的战术，常常是"一个进一个退"）、`光照`（~450 字：柔化但不能平，写清允许高光）、`音频`（~480 字：呼吸、布料、一声环境）。可薄：`空间地理`（只写两人与背景、距离精确到厘米）。
**镜头语言：** 29° 或 47°，相机 **0.6–1.2 米**（亲密的个人区）；机位**略低于眼或齐眼**；**锁定**，或极缓推（`10 秒 0.08 米`）；**前景遮挡**用满（对方肩膀、头发、被子边缘、酒杯）把画面框紧。
**光与色：** **一个柔侧光源**（窗、台灯、火光），色温写数字并偏暖（2700–3200K）；相机在暗侧；**曝光优先给皮肤高光与眼睛**，背景允许沉黑；色比 60:30:10，暖色占 60%。
**声音：** 呼吸是主角（写节奏：`快而浅` → `慢下来`）；布料摩擦、皮肤接触的轻响；一句环境底噪；台词压到最低音量。
**必须写死的锁：** ① **距离**——`两人面部相距约 25 厘米，他的手掌贴在她颈侧。` ② **视线朝向**——`她的视线落在他嘴上，然后抬到眼睛。` ③ **首帧占位**——`首帧两人已在这个距离内，动作已在中段。`
**失效表现：** 塑料皮肤、油光（E.4）→ 写"皮肤有毛孔与细纹，鼻翼有油光但不是塑料"；嘴部变形、亲吻穿模 → 用角度挡住接触点（后脑、肩线），写"接触发生在画外/被头发遮住"；过度表演、两人都在"演深情" → 只写战术，不写情绪；镜头抖成事故 → 锁定，或给极小幅度并写上限。
**加载：** `13-acting` + `05-light` + `06-motion`（接触与布料）+ `09-assembly`（组装）+ `banks/G-prompt-depth`。
**配方句：** `亲密镜：29°、相机 0.9 米略低于眼，单个暖侧光源 3000K，皮肤保毛孔、眼睛有活的眼神光。`

### J-B3 · 对峙 / 威胁（无肢体）

**识别信号：** "威胁""警告他""逼问""两人僵住""谁先动""一句狠话""枪还没掏出来"。
**提示词重心：** 加厚 `表演`（500–700 字：谁在压制、谁的战术在变、哪一下地位翻转）、`动作时间轴`（~1,300 字：**微事件密集**——吞咽、指节、呼吸、桌下握紧）、`空间地理`（~450–900 字：距离、轴线、两人之间隔着什么）、`音频`（~480 字：静默里的声事件）。可薄：`风格`、`物理`（只写手与呼吸）。
**镜头语言：** 47° 或 29°，相机 **2–3.5 米**；机位**略低**（压迫感）或齐眼；**锁定**；正反打交替，**距离可以逐步缩短**（`从 3 米到 1.2 米`）但要在时间轴上给秒数；前景可用（桌沿、杯子、门框）。
**光与色：** **一个硬侧光源**，快速衰减；脸**一半明一半暗**；相机在暗侧；**曝光优先给暗侧那只眼睛**；色温偏冷 5600K 或钠灯 3000K，二选一；色比 60:30:10。
**声音：** **静默是主乐器**；底噪极小；**秒数声事件**（`4.8s 椅子腿刮地`、`9.2s 他把杯子放下`）；台词压低、不喊。
**必须写死的锁：** ① **视线朝向**——`他的视线锁在对方眼睛上，一次也不移开。` ② **轴线**——`相机在门的另一侧，绝不越到两人之间。` ③ **地标邻近**——`他背靠吧台，左手离台面十厘米。`
**失效表现：** 威胁预告（E.2 A9：眯眼、慢转头、停顿）→ 威胁写成日常动作，暴力没有蓄势；越到高潮越响 → 反过来，越严重越轻；提前眨眼/提前移开视线 → 写"眨眼稀少、缓慢、有意"；观众看不懂谁占上风 → 写一次可见的地位断裂（谁先移开视线、谁先坐下）。
**加载：** `13-acting` + `04-optics` + `05-light` + `08-sound` + `07-sequence`。
**配方句：** `对峙：29° 齐眼、2.6 米锁定，单个硬侧光把脸切成一半明一半暗，静默里只有三个秒数声事件。`

### J-B4 · 群像仪式（婚礼 / 葬礼 / 拜佛）

**识别信号：** "婚礼""葬礼""拜佛""祭祖""仪式""一排人同时做一件事""集体跪下"。
**提示词重心：** 加厚 `空间地理`（900–1,200 字：**阵列/对称/间距/层高**，每个关键物在画面的哪一侧）、`开场状态`（每人一段：位置、朝向、手在哪）、`参考图`（群像板 + 地点板）、`物理`（~650 字：衣料垂坠、香火烟、纸钱、花瓣、水）。可薄：`表演`（只写"集体动作的相位差"）。
**镜头语言：** **84° 或 107° 全景**（1.5–3 米）交代阵列，再 `47°` 插入（手、香、烛）；机位**高**（俯拍阵列，显出几何）或**低**（仰望，显出庄严）；**缓慢横移**或锁定；前景用满（香、花、人的肩）。
**光与色：** 自然天光或**单源烛火**；**逆光剪影**是这类镜头的默认（人变成形状，仪式感来自重复）；相机在暗侧；**曝光优先给烟、烛、白布**；色温写数字；色比 60:30:10。
**声音：** 群体底噪（脚步、衣料、低语）＋ **3 个带秒数的事件**（`5.2s 钟响`、`11.4s 诵经起`、`18.0s 全体跪下`）＋ 无台词。
**必须写死的锁：** ① **空间走位**——`阵列共三排，每排五人，间距一米二，主位在画面中央偏左。` ② **地标邻近**——`祭坛在画面右侧三分之一，最近的两个人距它一步半。` ③ **多镜连续性**——`每一刀后是同一套衣服、同一侧光、同样的阵列间距。`
**失效表现：** 人数塌缩、阵列变 3–5 人（E.1 F23）→ 群像当**一个资产**写，只写边缘身体、不写人数；同步群戏（E.2 A10）→ 让反应以波的形式错开（一个人先跪、第二个半拍）；脸重复、一模一样的群演（E.2 A10）→ 写"每张脸都不同、背景的脸失焦"；现代物件混入（E.1 F12）→ 把年代写成规则，重复进每个板与提示。
**加载：** `03-space` + `13-acting`（群戏六条）+ `06-motion` + `10-assets` + `banks/E-failure-atlas`。
**配方句：** `仪式群像：107° 全景、相机 2.2 米高俯拍三排阵列，逆光剪影，单源烛火，烟从画面左下升起。`

### J-B5 · 群戏混乱（多人各自为政）

**识别信号：** "混乱""打群架""哄抢""人群逃散""市场""人挤人""一片乱"。
**提示词重心：** 加厚 `空间地理`（900–1,200 字：**前中后景分层**、每个方向有什么在动）、`开场状态`（各层各写一段）、`物理`+`动作时间轴`（~1,300 字：**各自的小动作不同步**）、`音频`（~480 字：多层底噪）。可薄：`表演`（不写个人战术，写群体行为）。
**镜头语言：** 84° 或 107°，相机 **0.8–2 米**；机位**胸高**（跟随视线的自然高度）或略高；**手持**（允许写明"轻微、可见但受控的晃"）；**分层**：前景一个明确主体、中景一群、背景一团；不要试图让观众看清每张脸。
**光与色：** 环境单源；**曝光优先给前景主体**；背景压暗、允许糊；色温与时间一致；色比 60:30:10，把 10% 的亮色留给前景。
**声音：** **三层**：远景人群底噪、中景具体动作声、贴身主角的呼吸；加 3 个秒数事件（`6.5s 玻璃碎`、`12.0s 一声喊`）。
**必须写死的锁：** ① **空间走位**——`前景主角在画面左下，中景五人在中央，背景人流向画面右流去。` ② **地标邻近**——`他背靠摊位，左手扶着桌沿。` ③ **首帧占位**——`首帧场上已经有八个人在动，没有空景。`
**失效表现：** 人群塌成 3–5 人（E.1 F23）→ 群像当一个资产 + 前景配角，写边缘身体不写人数；所有人往同一方向动（E.2 A10）→ 写"方向各不相同，只有主流向一边"；镜头跟着乱甩 → 写"手持幅度受控"，给的位移上限（`不超过 5 厘米`）；主角被吞掉 → 前景永远留一个清晰主体。
**加载：** `03-space` + `06-motion` + `13-acting` + `banks/E-failure-atlas`。
**配方句：** `混乱群戏：84° 胸高手持、0.9 米贴住前景主角，中景五人与背景人流向画面右流去。`

## C · 动作与身体（4 个叶子）

动作戏的失败只有一个根源：**你没有把质量翻译成运动**。接触、惯性、延迟、反作用、地面压力——这五样写出来，动作就落在物理上，不是落在随机数上。

### J-C1 · 近身格斗

**识别信号：** "打斗""一拳打过去""扭打""扇耳光""推搡""两个人滚在地上"。
**提示词重心：** 加厚 `物理`（700–900 字：**逐部位**写受力——拳、前臂、躯干折叠、膝盖、脚掌抓地，加打击感清单）、`动作时间轴`（~1,300 字：把一次交手切成 3–5 片，每片一个接触）、`音频`（打击声与呼吸）、`光学`（近身用 29°/47°，不要广角畸变）。可薄：`风格`、`空间地理`（只写两人与地面、墙的距离）。
**镜头语言：** **47° 或 29°**，相机 **1–2 米**；机位**胸高或略低**；**手持**（小幅、受控）；**一个动作一个镜头**（不要一镜拍完整套连招）；切在动作上（`HARD CUT 落在动作中段`）；允许前景遮挡（对方肩、手臂、墙）。
**光与色：** **一个硬光源**（顶光、路灯、门缝），快速衰减；背景沉黑；相机在暗侧；**曝光优先给接触点**（不是脸）；色温写数字；色比 60:30:10。
**声音：** 打击声（**写具体的材质声**：`皮革撞皮革`、`骨传导的闷响`）＋ 呼吸（短、破）＋ 环境底噪；无配乐。
**必须写死的锁：** ① **接触点**——`右拳落在对方左颊，接触点距镜头约 1.2 米。` ② **首帧占位**——`首帧两人已经在纠缠中段，不是站定起手。` ③ **多镜连续性**——`每一刀后是同一件外套、同一边脸的伤、同一侧光。`
**失效表现：** 动作飘、像游戏引擎（E.5）→ 逐部位写受力，加打击感清单（`12-verified-rules` T-01：白闪、顿帧、压缩、后退距离、尘屑）；借位消失、拳没打到（E.5）→ 写接触点与接触瞬间的身体反应；武器/道具变两个（E.1 F25）→ 逐帧写数量；复杂动作放中段塌掉（E.1 F22）→ 把最复杂的动作放**最前**，接近过程拆成另一镜。
**加载：** `06-motion` + `12-verified-rules`（打击感 12 项）+ `07-sequence` + `04-optics` + `banks/E-failure-atlas`（E.5）。
**配方句：** `近身格斗：47°、相机 1.4 米胸高手持，单侧硬光，一拳一镜，接触瞬间白闪 2 帧、顿帧 3 帧、受力者后退 40 厘米。`

### J-C2 · 追逐 / 奔跑

**识别信号：** "追""跑""逃""冲刺""追赶""在巷子里跑""他在后面追"。
**提示词重心：** 加厚 `物理`（~650 字：步态五拍、呼吸、地面材质、衣摆与头发延迟）、`动作时间轴`（~1,300 字：路径分段＋每段一个障碍）、`空间地理`（~450–900 字：**路径与转折点**、每个地标在哪）、`光学`（广角贴脸）。可薄：`风格`、`表演`（只写"目标在前方"）。
**镜头语言：** **84° 或 107°**，相机 **0.5–1.5 米**；机位**低**（贴地，让脚步与地面读得出来）或胸高；**跟拍**（后跟或侧跟）；手持；前景掠过（柱子、行人、树叶）制造速度。
**光与色：** 环境光为主；**逆光**（让轮廓与扬尘发亮）；曝光优先给路面与轮廓；冷暖按时间写死；色比 60:30:10。
**声音：** 脚步（写地面材质：`碎石`、`湿砖`、`木地板`）＋ 呼吸（快、破）＋ 环境；**可选**一个低频节奏，但要写明"只在后期"。
**必须写死的锁：** ① **位移路径**——`他从画面左下沿对角线跑向画面右上，穿过第三根柱子右侧。` ② **地标邻近**——`每经过一根柱子，柱子都在他右肩一侧。` ③ **首帧占位**——`首帧他已经在跑，双脚离地一瞬。`
**失效表现：** 脚不着地、腿空转（E.5）→ 写"真实触地、抬膝、反向摆臂、躯干前倾、步幅变化"；每步一样长、像传送带 → 写"步幅与节奏有变化"；人物与背景一起平移（E.1 F4）→ 地标邻近锁；镜头跟着飘 → 写手持幅度上限。
**加载：** `06-motion` + `04-optics` + `03-space` + `07-sequence`。
**配方句：** `追逐：107° 广角、相机 0.9 米贴地跟拍，逆光扬起尘土，路径沿对角线穿过第三根柱子右侧。`

### J-C3 · 车辆驾驶

**识别信号：** "开车""车里""驾驶""追车""骑摩托""卡车驾驶室"。
**提示词重心：** 加厚 `物理`（~650 字：悬挂下沉、车身侧倾、轮胎与路面、刹车距离）、`空间地理`（~450 字：车内布局——方向盘、后视镜、座椅、窗外）、`光照`（路灯频闪/仪表光）、`音频`（引擎、风噪、胎噪）。可薄：`表演`（只写手与眼的操作）。
**镜头语言：** **47°** 车内固定（副驾/后座/仪表台），或 **84°** 车外跟拍；机位**贴仪表台**或**后座平视**；车内**锁定**（模拟固定机位）；车外用**吸盘/跟车**并写"车身相对画面位置不变"。
**光与色：** 夜景：**路灯一根根扫过**（写频率与色温 3000K 钠灯）＋ 仪表冷光 5600K；**曝光优先给脸**，窗外允许过曝；色比 60:30:10。
**声音：** 引擎（写转速变化：`升挡一次`）＋ 风噪＋ 胎噪＋ 一个事件（`7.4s 压过井盖`）。
**必须写死的锁：** ① **车辆位置与朝向**——`车头朝画面右前方，车身相对画框位置全程不变。` ② **地标邻近**——`每根路灯从画面右缘进入、左缘退出，间距约 30 米。` ③ **多镜连续性**——`每一刀后是同一辆车、同一侧的光、同一条路。`
**失效表现：** 车像贴图平移（E.5）→ 写悬挂、侧倾、刹车距离；窗外背景静止 → 写"窗外景物持续向后流过"；方向盘不转 → 写手与方向盘的角度变化；车里多出一个人（E.1 F25）→ 逐镜写车内人数与座位。
**加载：** `06-motion` + `03-space` + `05-light` + `08-sound`。
**配方句：** `驾驶镜：47° 副驾固定、贴仪表台高度，钠灯 3000K 一根根从右缘扫入，引擎升挡一次。`

### J-C4 · 劳作 / 手工（身体可信度）

**识别信号：** "做饭""修东西""生火""织布""打磨""干农活""手上在做一件事"。
**提示词重心：** 加厚 `物理`（800–1,000 字：**工具与材料的接触、形变、碎屑、残留**——这是全包最该写厚的一节）、`动作时间轴`（~1,300 字：把过程拆成"准备→接触→变化→结果"四段）、`光学`（手部特写用 18°/29°）、`参考图`（道具板）。可薄：`表演`（只写专注与呼吸）。
**镜头语言：** **18° 或 29°** 手部特写，相机 **0.3–0.8 米**；**47°** 中景交代人与工作台；机位**与工作台齐平**或略高；**锁定**；**浅景深**只保手与工具。
**光与色：** **实用光源**（火、油灯、窗）——光源必须在画面里看得见或能推出位置；侧光让材质出纹理；**曝光优先给手与工具**；色温写数字；色比 60:30:10。
**声音：** **材质声**（`刀切进木头`、`砂纸摩擦`、`火苗被吹旺`）＋ 呼吸＋ 环境；这一类的声画同步比任何类型都重要。
**必须写死的锁：** ① **接触点**——`右手握刀柄、左手压住木料，刀口与木面成 30°。` ② **道具数量**——`桌上只有一把刀、一块木、一个砂纸卷。` ③ **首帧占位**——`首帧手已经在动作中段，不在准备姿势。`
**失效表现：** 手变形、六指（E.1 F?/E.2）→ 特写只给**一只手 + 一件工具**，另一只手出画；工具穿模 → 写接触点与角度；过程跳步、动作不连贯 → 拆成四个时间片，每片一个可见变化；道具变两个（E.1 F25）→ 写数量；材质像塑料（E.5）→ 逐材质写行为（木：受压形变、轻响；金属：受重弯、回弹）。
**加载：** `06-motion` + `04-optics` + `10-assets`（道具板）+ `banks/E-failure-atlas`（E.5）。
**配方句：** `劳作战：18° 手部特写、相机 0.5 米、与工作台齐平，单源侧光，桌上只有一把刀、一块木。`

## D · 类型与氛围（4 个叶子）

类型不改变骨架，改变的是**装配什么**：恐怖的装配是"看不见"，超现实的装配是"不合逻辑但可拍"，氛围的装配是"空气本身是主角"，微距的装配是"材质即叙事"。

### J-D1 · 恐怖 / 悬念（看不见的东西）

**识别信号：** "恐怖""惊悚""有东西在""不敢看""门后面""走廊尽头""他感觉有人在"。
**提示词重心：** 加厚 `光照`（~450 字：**低照度、单源、快速衰减、允许大面积黑**，写清允许高光清单）、`空间地理`（~450–900 字：门、走廊、遮挡、纵深）、`音频`（~480 字：**极小的底噪 + 秒数事件 + 静默**）、`动作时间轴`（~1,300 字：**延迟揭示**——先声音、再局部、最后才给）。可薄：`表演`（只需恐惧的身体反应：呼吸、僵住、后退）。
**镜头语言：** **29° 长焦**（压缩空间、看不清全貌）或 47°；机位**低或贴角落**；**锁定**（让观众自己去找）；**缓慢推近**（`12 秒 0.15 米`）；**前景遮挡**用满（门缝、栏杆、树叶、人的肩）。
**光与色：** **一个源**（手电、门缝、月光、手机屏），色温**偏冷 5600K**；**曝光给暗部细节**，让黑更黑；大面积允许纯黑；色比 60:30:10，把 10% 留给那一束光。
**声音：** 底噪**极小**（几乎是静默）；**3 个秒数事件**（`6.2s 地板响一声`、`11.8s 呼吸变快`、`15.0s 门自己开了`）；**没有 jump scare 的配乐**——恐怖来自"还没发生"。
**必须写死的锁：** ① **首帧占位**——`首帧威胁已在画外（或画面边缘），人物还不知道。` ② **视线朝向**——`他的视线锁在画外那扇门上，身体还没转过去。` ③ **地标邻近**——`他站在走廊左壁，离那扇门约四米。`
**失效表现：** 提前给全貌、怪物露脸 → 只写局部（手、影、湿脚印、呼吸的白气）；光照太亮、暗部被提亮（E.4）→ 写"曝光给暗部、允许纯黑、没有补光"；威胁预告（E.2 A9）→ 恐怖动作发生在日常里，没有前奏；观众看不懂在看什么 → 给一个清晰的前景主体当参照。
**加载：** `05-light` + `03-space` + `08-sound` + `04-optics` + `banks/C-negative-bank`（按场景类型的约束清单）。
**配方句：** `恐怖悬念：29° 长焦、相机 3.5 米锁定，单源冷光 5600K 从走廊尽头来，画面三分之二沉在纯黑里。`

### J-D2 · 超现实 / 梦境

**识别信号：** "梦""幻觉""超现实""记忆闪回""不合逻辑""时间倒流""漂浮"。
**提示词重心：** 加厚 `物理`（~650 字：**反物理的规则要写清**——漂浮的水、慢十倍的布料、向上落的尘，规则本身要一致）、`风格`（一行锚点 + 夸张色比）、`光照`（非常规色温 + 溢出高光）、`音频`（失真的声）。可薄：`表演`（梦里的人常常是"没有战术的"）。
**镜头语言：** **47° 或 84°**，带轻微畸变；机位**极端**（顶拍、贴地、仰到天）；**缓慢漂移**（不是手持，是"悬浮"）；**不用常规剪辑**——用长镜内的时间错位（`他在同一秒里走完了十米`）。
**光与色：** **多个源但可控**（2–3 个），色温刻意冲突（`3200K 与 6500K 同时存在`）；**曝光允许高光溢出**；色比 60:30:10 但把主色写成非自然色（青、品红、钠黄）。
**声音：** **低频持续音**＋ 反向声＋ 突然的静默；台词可加混响但要写明"这是梦里的空间"。
**必须写死的锁：** ① **空间连续性**——梦也要有地理：`同一个走廊，四个门，门距两米，方向不变。` ② **首帧占位**——`首帧他已经在漂，不是起跳。` ③ **多镜连续性**（若多镜）——`每一刀后是同一条走廊、同一侧的墙。`
**失效表现：** 模型乱变、逻辑崩塌 → 把"不合逻辑"限制在**一条规则**上（只有重力反常，其他物理正常）；过度特效、像 MV → 写"实拍质感、没有粒子特效"；观众看不懂 → 给一个可读的空间骨架。
**加载：** `05-light` + `06-motion` + `07-sequence` + `banks/B-phrase-bank`（风格锚点）+ `banks/C-negative-bank`。
**配方句：** `超现实梦境：47° 轻微畸变、机位贴地缓慢漂移，3200K 与 6500K 同时存在，只有重力反常、其余物理正常。`

### J-D3 · 环境空镜 / 氛围

**识别信号：** "空镜""风景""没有人""氛围""建立镜头""大远景""城市夜景"。
**提示词重心：** 加厚 `场景背景`（300–600 字：这是**唯一以它为主角**的叶子）、`空间地理`（~450–900 字：**尺度三件套**——真实尺寸、占画幅比例、对照物）、`光照`（~450 字：空气分层、色温、曝光优先给天空）、`物理`（~650 字：风、水、尘、雪、烟的方向与层次）。可薄：`表演`（无）、`动作时间轴`（只需 2–3 个微事件）。
**镜头语言：** **107° 或 84°** 大远景；机位**高**（俯拍大地）或**低**（贴水面/地面）；**缓慢横移**或**锁定**；**前景**必须有东西（草、树枝、栏杆、屋檐）压住一角，否则画面会空。
**光与色：** 自然光；**逆光或侧光**（让空气发亮）；**曝光优先给天空/水面**；色温写数字；色比 60:30:10，主色写成具体名词（`铅灰`、`钠黄`、`青灰`）。
**声音：** 环境底噪（风、水、远处城市）＋ **2–3 个秒数事件**（`7.0s 一群鸟起`、`14.5s 远处船笛`）＋ 无对白。
**必须写死的锁：** ① **尺度三件套**——`画面左侧一栋六层楼，高约占画幅 18%，前景路灯高约 1 米。` ② **地标邻近**——`塔吊在画面右三分之一，距地平线约 200 米。` ③ **首帧占位**——`首帧空气里已经有东西在动（雾、尘、水汽）。`
**失效表现：** 画面空、平、廉价（`12-verified-rules` T-02）→ 空气占画面 40–60%、分三层明度；没有尺度 → 三件套同写；构图没有前景 → 加一个 1 米以内的前景物；空气一块平值 → 写"高层卷云 30% 明度、中层雾带 55%、地平线亮带 85%"。
**加载：** `03-space` + `05-light` + `12-verified-rules`（空气分层）+ `06-motion`（风与粒子）。
**配方句：** `环境空镜：107° 大远景、机位贴水面 0.4 米缓慢横移，逆光，空气占画面一半分三层明度。`

### J-D4 · 物质微距 / 质感

**识别信号：** "微距""质感""纹理""水滴""金属""布料""特写细节""让人想摸"。
**提示词重心：** 加厚 `物理`（800–1,000 字：**材质即叙事**——每种表面的行为、反光、形变、残留）、`光学`（微距的距离与景深）、`光照`（掠射光出纹理）、`风格`（质感词）。可薄：`表演`、`空间地理`（只写表面与相机距离）。
**镜头语言：** **18° 或 29°**，相机 **0.1–0.4 米**；机位**与表面平行**或**掠射 15°**；**锁定**；**极浅景深**（只保一条焦平面）；背景完全化开。
**光与色：** **一个掠射光源**（15–30° 掠射角，让纹理出阴影）；**曝光优先给高光**，允许局部溢出；色温写数字；色比 60:30:10，主色由材质本身决定。
**声音：** **材质声**（`水滴落`、`金属轻响`、`布料摩擦`）＋ 静默；这一类的声画同步可以极近。
**必须写死的锁：** ① **尺度**——`水滴直径约 3 毫米，占画幅宽度 6%。` ② **接触点 / 表面**——`水珠停在金属边缘，接触角约 90°。` ③ **首帧占位**——`首帧水珠已经在表面，正在聚集。`
**失效表现：** 塑料感、纹理糊（E.5）→ 写"毛孔、油光、磨损、划痕"这些真实表面词；反光错、像 CG → 写清掠射角度与反射内容（`反射出窗框的一条亮线`）；尺度看不出来 → 给对照物（`旁边一粒盐`）；焦平面乱 → 写"只保一条焦平面，前后化开"。
**加载：** `06-motion` + `05-light` + `banks/A-optics-bank`（六档视角与结果短语）+ `10-assets`（材质板）。
**配方句：** `物质微距：18°、相机 0.15 米、与表面成 15° 掠射，单个掠射光，只保一条焦平面。`

## E · 商业与音乐（3 个叶子）

这三类的共同点：**目标不是叙事，是记住一件东西**。所以重心从"表演/物理"整体移到"产品/节奏/品牌记忆点"。

### J-E1 · 产品广告（15 秒 4 镜）

**识别信号：** "产品广告""15 秒""卖点""电商主图视频""展示这个产品""logo 要出现"。
**提示词重心：** 加厚 `参考图`（产品板：形制、材质、磨损、标签）＋ `空间地理`（台面与背景）＋ `光照`（可控棚拍）＋ `动作时间轴`（**4 镜分配**：0–0.3 秒建立、0.3–6 秒细节、6–11 秒使用、11–15 秒落版）。可薄：`表演`（若有人手，只写手）；`物理`（只写产品与液体的接触）。
**镜头语言：** **29° 产品特写**（相机 0.3–0.6 米，与产品平视）＋ **47°** 使用场景＋ **84°** 环境落版；**每镜一个焦点**；**硬切 3 次**（`0.3s / 6.0s / 11.0s`）；允许微推（`0.05 米`）。
**光与色：** **三点布光或单柔光箱 + 反光板**；色温 **5600K** 中性；**曝光优先给产品标签**（必须可读）；背景干净（`纯色台面`、`无杂物`）；色比 60:30:10，主色＝产品色。
**声音：** 环境底噪＋ **产品声**（`6.8s 液体倒入杯中的声音`、`11.2s 卡扣合上`）＋ 可选一段极简配乐（写明"后期"）。
**必须写死的锁：** ① **产品数量 = 1**——`全片只有一瓶，桌面无第二个同类物。` ② **标签可读**——`标签正对镜头，字迹清晰，占产品宽度 60%。` ③ **首帧占位**——`首帧产品已完整在画面中，光影已定。`
**失效表现：** 产品变形、标签乱码（E.1 F?）→ 产品当资产板逐字绑定，正文只写"100% 匹配参考"；多出第二个产品（E.1 F25）→ 写数量锁；文字在视频里糊掉 → 字在**图片车道**出，视频只引用（`10-assets`）；15 秒塞超过 4 镜 → 按 `banks/F-model-caps` 先算条数，一条 15 秒装 4 镜。
**加载：** `10-assets` + `05-light` + `07-sequence` + `banks/F-model-caps`（时长与条数）+ `banks/I-image-models`（图片车道）。
**配方句：** `产品广告 15 秒 4 镜：29° 产品特写、相机 0.4 米平视，5600K 中性柔光，硬切在 0.3/6.0/11.0 秒。`

### J-E2 · 品牌情绪片（一镜到底群像）

**识别信号：** "品牌片""形象片""一镜到底""群像""城市人文""不要台词，只要氛围"。
**提示词重心：** 加厚 `场景背景`（这一次要写"这支片子想让人记住什么"）＋ `空间地理`（路径与地标）＋ `开场状态`（t=0 全员）＋ `光照`（黄金时刻/自然光）＋ `音频`（环境＋人声碎片）。可薄：`表演`（每个人只给一个动作）。
**镜头语言：** **一镜到底**，**84°/107°**，相机**连续移动**（跟、横、升），机位胸高；**手持或稳定器二选一写死**；路径要写清（`从街口走到广场，再上两级台阶`）；**不允许硬切**。
**光与色：** 自然光，**黄金时刻**（写色温 3500K 与太阳角度）或阴天；**曝光优先给脸**；色比 60:30:10，暖主色 60%。
**声音：** 环境底噪＋ **人声碎片**（不是台词：`远处一句听不清的笑`）＋ 后期配乐位（写明"音乐在后期"）。
**必须写死的锁：** ① **单镜不切**——`全片一个连续镜头，没有任何剪切。` ② **路径与地标**——`镜头从街口起，经面包店、书报亭，到广场台阶止。` ③ **多镜连续**（若拆条）：`拆条后每条的起终点必须同一方向、同一侧光。`
**失效表现：** 一镜到底变成多个剪辑（模型自创切点）→ 写 `No unspecified cuts` 类的正面锁；人物瞬移（E.1 F4）→ 写路径与地标；光在一镜内乱变 → 写"光源固定、曝光固定"；太长装不下 → 按 `banks/F-model-caps` 算条数，30 秒上限时拆成 30+30。
**加载：** `01-story` + `03-space` + `07-sequence` + `08-sound` + `banks/F-model-caps`。
**配方句：** `品牌情绪片：107° 一镜到底、相机胸高连走带升，黄金时刻 3500K，从街口经面包店到广场台阶。`

### J-E3 · 音乐卡点 / MV

**识别信号：** "MV""卡点""跟着音乐切""节奏感""歌词""副歌要对上"。
**提示词重心：** 加厚 `01-story`（段落结构与情绪曲线）＋ `07-sequence`（**切点＝节拍**，写成绝对秒）＋ `音频`（tempo、鼓点位置）＋ `光学`（多景别）。可薄：`物理`（除非有动作）、`空间地理`（MV 常常换场景）。
**镜头语言：** **多景别**：29°（脸）＋ 47°（中景）＋ 84°（环境）交替；机位随节奏变化（鼓点处换角度）；**硬切落在拍点上**；可用 `WHIP CUT` 但语料实测为 0，**优先 `HARD CUT`**；每个段落只给一个主运镜，段落之间靠景别跳——不要连排三个近景。
**光与色：** 高对比或彩色光；**曝光优先给高光**；色比 60:30:10 可夸张；每个场景一个主色。
**声音：** **音乐轨为主**（写明 tempo，如 `120 BPM`、鼓点在第几秒）；口型对齐（若有人唱）；唱段里只留人声与鼓，环境压到极低。
**必须写死的锁：** ① **切点＝秒数＝拍点**——`每个切点都在鼓点上：0.5s / 2.0s / 3.5s / 5.0s。` ② **多镜连续性**——`每一刀后是同一张脸、同一套装、同一首歌的同一段。` ③ **首帧占位**——`首帧已经在动作中，不空镜起。`
**失效表现：** 卡点不准 → 把切点写成绝对秒并与 BPM 对齐（120 BPM＝每 0.5 秒一拍）；口型漂 → 短句、正脸、少遮挡；镜头乱、没有节奏 → 每个段落只用一个主运镜。
**加载：** `07-sequence` + `08-sound` + `01-story` + `banks/F-model-caps`。
**配方句：** `音乐卡点：29°/47°/84° 三档交替，切点全部落在 120 BPM 的拍点上（0.5s / 2.0s / 3.5s / 5.0s）。`

## F · 长篇与连续（2 个叶子）

### J-F1 · 跨镜 / 跨集连续性

**识别信号：** "要接得上""同一个角色""跨集""系列""别换脸""保持一致的风格"。
**提示词重心：** 加厚 `参考图`（**一套资产服务全部镜头**，逐张 `{{ref N}}` 绑定）＋ `正向锁定`（**10–20 条**，每条一个正面状态）＋ `空间地理`（每场一份、原样粘贴）＋ 连续性账本（服/伤/道具/方向/光向）。可薄：`风格`（一次写死，逐字复用）。
**镜头语言：** 各镜**光向一致、轴线一致、景别在预算内**；每镜**重写开场状态**（模型没有上一条的记忆）；换场只换地点，不换"看的方向"。
**光与色：** **同向、同色温、同色比**；换时间（日→夜）必须显式写"光变了，因为时间变了"。
**声音：** **一条共享气氛床**（E.1 F32 的处方）压在连续环境声之上；每镜只加本镜的事件。
**必须写死的锁：** ① **多镜连续性**——`每一刀后是同一张脸、同一件外套、同一侧光。` ② **首帧占位**——`每条的第一帧都已满员、已在中段。` ③ **地标邻近**——`同一个门框在每一镜的同一侧。`
**失效表现：** 换脸（E.1 F1）→ 每镜粘贴"描述 + 图"资产对；光反向 → 一场一光向；人与空间一起平移（E.1 F4）→ 地标邻近；拆条后接不上 → 按 `banks/F-model-caps` F.5 每条重写全部状态；风格漂移 → 风格块写一次，逐字粘贴复用。
**加载：** `07-sequence` + `10-assets` + `02-cast` + `11-project-skill` + `banks/F-model-caps`（F.5）。
**配方句：** `跨镜连续：一套资产服务全部镜头，每镜逐字粘贴描述与 {{ref N}}，一场一光向、一条轴线。`

### J-F2 · 开场钩子（第一镜）

**识别信号：** "开场""钩子""第一镜""前 3 秒抓住人""开头要狠""预告片开头"。
**提示词重心：** 加厚 `动作时间轴`（**0–3 秒密度最高**：第 0.5 秒就要有事发生）＋ `光照`（强对比，第一眼就有形状）＋ `音频`（**一声**，不是一层）＋ `场景背景`（一句话说清"我们现在在哪、谁有麻烦"）。可薄：`参考图`（第一镜常常不需要全部资产）。
**镜头语言：** **29° 或 47°**，**近**（0.5–2 米）；机位**低或歪**（不稳定感）；**手持**；**不给全貌**（只给局部，让观众想知道更多）；第一镜**一个动作**，不交代背景。
**光与色：** **一个硬光源**，强对比；**逆光剪影**或侧光切脸；曝光优先给动作发生的位置；色温写死。
**声音：** **一声**（`玻璃碎`、`一声吸气`、`门被撞开`）＋ 之后立刻静默；无配乐（或只在第 2 秒进）。
**必须写死的锁：** ① **首帧占位**——`首帧已经在事件中段，不是准备动作。` ② **视线朝向**——`他的视线锁在画外那个方向，观众还看不到。` ③ **空间走位**——`他占画面右三分之一，面朝左，离镜头约 1.2 米。`
**失效表现：** 空镜开场、太慢 → 第一帧就要有人或有事件；交代过多、前三秒全是信息 → 第一镜只给一个动作；不够狠 → 把最强的画面放第一秒，第二位再解释；观众不知道看谁 → 给一个清晰主体 + 一个方向。
**加载：** `04-optics` + `05-light` + `08-sound` + `07-sequence`。
**配方句：** `开场钩子：29°、相机 1.2 米低机位手持，首帧已在事件中段，单侧硬光剪影，一声之后立刻静默。`

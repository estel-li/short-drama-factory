## E.2 表演失败 15 条

| # | 症状 | 病因 | 处方 |
|---|---|---|---|
| A1 | 指示性表演：脸直接"做"情绪 | 把情绪当成表演目标 | 把脸从任务里拿开，写目标，给手上一件事 |
| A2 | 演结果：第一秒就在演结局 | 角色被写成知道结局 | 只写他此刻知道的东西 |
| A3 | 等提示：对方说话时一张空脸 | 反应没有提前 | 反应从对方话中开始 |
| A4 | 单战术：全场一个颜色 | 没有节拍变化 | 标节拍，每拍换一个战术动词 |
| A5 | 手势图解：说"大"就张开手 | 手在解释台词 | 手势先于想法、与台词相反、或没有 |
| A6 | 免费情绪：无铺垫的眼泪/暴怒 | 情绪没有代价与阶梯 | 搭梯子：克制 → 破防；情绪要花钱 |
| A7 | 身体不合传记：混混有舞者体态 | 体态没从经历推出来 | 先定重心、节奏、磨损 |
| A8 | 台词太干净：街头角色说书面语 | 语言缺阶层与身份的杂质 | 打断、吞尾音、重复 |
| A9 | 预告暴力：眯眼、慢转头、威胁停顿 | 威胁被演成仪式 | 威胁日常化，暴力没有前奏 |
| A10 | 同步群演：所有人同时同幅反应 | 群演被当成一个开关 | 反应成波，强度各异 |
| A11 | 死停顿：静默里什么都没发生 | 静默里没有装事件 | 填评估或填手上事，否则剪掉 |
| A12 | 情绪复位：强事件后立刻恢复 | 状态被当成开关 | 状态有惯性，余波带进下一拍 |
| A13 | 评价角色：表演在向观众眨眼 | 演员不相信情境 | 完全相信；喜剧当正剧演 |
| A14 | 特写过载：大特写上满脸小动作 | 用大动作填小画幅 | 越紧越少动，只剩眼睛与想法 |
| A15 | 死眼：凝视、不眨眼、眼神光发干 | 眼睛没有微行为 | 扫视、眨眼质量、眼神光、眼先到头 |

## E.3 光学失败 11 条

| 写了 | 会发生 | 改成 |
|---|---|---|
| extreme / ultra / super wide-angle lens | 取最广的刻板印象，脸变形 | 84° 或 107° + 相机距离 |
| wide shot / establishing shot 当镜头指令 | 画面变空，人物被推远 | 视角 + 距离 + 结果短语 |
| tight wide framing | 自相矛盾，模型二选一 | 二选一 |
| zoom out + wide-angle | 镜内两次构图变化 | 单一运镜主轴 |
| f-stop / ISO / 镜头品牌当主控（视频） | 几乎无效 | 结果短语；器材词只给静态资产 |
| 同一镜复合运镜 | 运镜被平均，不成立 | `camera moves from X to Y only` |
| 一镜里多内容类型 | 镜头漂移 | 拆成插入镜 |
| 只写负向镜头控制（"不要长焦"） | 弱偏置，且注入概念 | 先写想要的视角，再加镜内锁 |
| 长焦不写前景遮挡 | 只是模糊长镜，不是远观 | 前景遮挡占画面下 30–45% |
| 广角不写距离 | 相机不走过去，空间不扩张 | 84° 配 1–1.5 m；107° 配 0.5–0.8 m |
| 47° 当默认 | 全片没有镜头性格 | 只在需要"无风格"时用 |

## E.4 照明失败 8 条

| 症状 | 病因 | 处方 |
|---|---|---|
| 平光、脸被补亮 | 模型有强烈的补光先验 | 为逆光曝光，允许脸进深阴影 |
| 画面没有真正的黑 | 曝光优先级缺席 | 写满 8 字段照明合同 |
| 全身油亮、高光铺满 | 高光没有被列举 | 只允许列举的几处高光 |
| 光向跨镜变化 | 光没被当成连续的物理事实 | 一场一条光向，含反打 |
| 视频里写机身/胶片/镜头品牌 | 车道错位：视频不认器材词 | 视频写结果；图片才写器材 |
| 颗粒重到像噪点 | 与模型自带质感打架 | 一行登记即可，别叠三行 |
| 明暗差别随机 | "高对比"只是形容词 | 写比值：2:1 / 4:1 |
| 负向禁令一大段 | 注入概念且只有弱偏置 | 正向写；必要时镜内一句锁 |

## E.5 物理失败 7 条

| 症状 | 病因 | 处方 |
|---|---|---|
| 人物漂浮 | 没有触地与重量转移 | 脚跟触地 → 转移 → 蹬地 → 沉降 |
| 武器没有重量 | 没有惯性描述 | 手臂承重、腕随质量、加速与减速 |
| 脚不着力、滑步 | 摩擦被忽略 | 写接触点与地面压力 |
| 物体瞬移 | 姿态之间没有连续性 | 用"已在途中"的状态块代替过程 |
| 动作像橡皮 | 缺少跟随与延迟 | 布料与头发晚半拍 |
| 游戏引擎感 | 缺少真实材质反应 | 写材质、热、湿、残留 |
| 物理上不可能 | 没有可行性检查 | 动作在时长内做得完吗 |

## 附录 · 可直接粘贴的 8 句（中文逐字；英文原句见英文版同名小节）

```text
不要影棚、不要器材、不要墙
不要轮廓光，不要边缘发光。
板上双手保持空着；每件道具都是独立资产。
永远不要两个太阳：一个光源，一个影子方向。
一厘米都不许更高；拿不准就把他画矮一点
每 1–2 秒一个可见的微事件
拿原始板来、只改变化了的那部分——绝不整板重渲。
先改文字；只有同一处再坏一次才重建资产。
```

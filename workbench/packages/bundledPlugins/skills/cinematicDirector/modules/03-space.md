# 03 · SPACE —— 参考、走位、开场状态

## 这个模块解决什么

空间事故几乎都不是"构图不好看"，而是**参考图被当成了构图**：给一张地点图，模型就把那张图的机位当成这一镜的机位；给一张人物图，模型就把那张图的角度当成这一镜的角度。本模块把"参考"降级为**地理与身份的证据**，把"走位"升级为可丈量的事实（几米、贴着什么、朝哪边、看哪里、在第几层），并用开场状态锁把"漂亮的空镜开场"这个模型强先验掐死。

核心断言：**参考图拥有它拥有的东西，不拥有它没被授权的机位。**

**深度基线：本模块产出的两节——`参考图`（中位 1,552 字，占全文 12.7%）与 `空间地理`（中位 894 字，占 7.3%）——合计约 2,400 字，是整条提示词里占比最大的两块；6 镜 30 秒的整条应在 8,000 字符以上（上限不设）（`banks/G-prompt-depth.md`）。这两节写薄了，整条就空。**

**何时加载：** 画面里有 ≥2 个人；有地点参考图 / 身份参考图 / 道具参考图；需要跨镜连续性；对白正反打；开场状态里必须已经有人物。
**不加载：** 单人单物特写、纯质感空镜、不需要空间关系的产品镜。

## 提示

### T-03-01 · 地点参考图是地理，不是构图
**为什么：** 模型会把参考图的机位、取景、地平线当成这一镜的答案；一旦继承，你写的镜头语言全部失效，而且每一镜都会回到同一个机位。
**失效表现：** 每个镜头都像同一张地点照的重拍；明明写了低机位，出来还是平视广角；正反打两边朝向一样。
**说：** 参考图只供地理、材质、氛围、地标与光向；本镜的机位、取景与构图由提示词给出。 [译]

### T-03-02 · 先把地点翻成一张平面图，再写走位
**为什么：** 走位句只有在"地图已存在"时才能写具体；地图把"这个空间是什么样"从"这张照片拍成什么样"里拆出来。
**失效表现：** 人物浮在场景里；前后景关系每镜不同；同一个门在两镜里出现在相反的两侧。
**说：** [译] 九项必填：机位 · 朝向 · 前景 · 中景 · 背景 · 地标位置 · 人物位置 · 移动路径 · 光向；配套声明坐标约定用 `【方位以画面里看到的为准（camera-relative）：左右＝画面左右、前后＝靠近/远离镜头】`（语料 `cully-hill-boys#153`）

### T-03-03 · 参考层级固定：身份 > 空间/动作 > 光学/光 > 风格
**为什么：** 参考图之间会互相打架；没有优先级时，最后写进去的那张（通常是风格图）会重涂整帧，包括脸。
**失效表现：** 风格参考把人物肤色、脸型一起换了；地点图把已经锁好的光向翻掉；改风格就改坏身份。
**说：** 身份、空间走位、动作、光学与光照，优先于任何风格参考。 [译]

### T-03-04 · 参考图是真相，散文只是锚
**为什么：** 身份活在条件图 / Soul ID 里；长段外貌描写会和参考图竞争，并且靠"噪声"赢——模型会综合两者的平均，而不是保留参考。
**失效表现：** 参考图对了但脸不像；越描述越不像；同一角色在不同镜里脸型浮动。
**说：** 参考图是脸、身体、比例、服装、材质与身份的唯一真相；提示词只补本镜需要的锚点。 [译]

### T-03-05 · 最小锚点公式：只写这一镜要用的东西
**为什么：** 每个锚点都是一次可以被模型重新解释的机会；锚点越少，身份越稳。写"角色一生的伤"只会让模型加戏。
**失效表现：** 提示里塞满面颊结构、服装细节、与画面无关的旧伤；人物身上出现你没要求的东西。
**说：** @角色：年龄 + 身份/体型 + 当前状态 + 关键可见锚点 + 与动作有关的手上状态。100%符合参考。 [译]

### T-03-06 · 开场状态锁：t=0 时全部人物已在场在位
**为什么：** 生成模型有强烈的"先来一个漂亮开场广角"先验；t=0 的状态不写死，它就把预算花在风景上，然后人物迟到、位置随机。
**定位：** 这一条锁的对象是"模型在 t=0 时该看到什么"，用文字写死；它不要求你提供一张首帧图，也不假设参考图就是首帧。
**失效表现：** 开头 1 秒空镜；人物半秒后才入画；t=0 的画面里只有天花板；闪白空切。
**说：** 开场状态（t=0）：所有主体已就位、已在场；之后不再有人入画。 [译]

### T-03-07 · 可丈量的邻近，替代关系词
**为什么：** `near` 是一个分布，`within 1 meter` 是一个约束——后者可以在成片里被检查。空间准确度不够时，模型会自己发明关系。
**失效表现：** 角色"在附近"飘着；道具在手里和在地上之间随机；人和地标的距离每镜不同。
**说：** 站在烧毁的车一米以内，一只手搭在烧焦的引擎盖上。 [译]

### T-03-08 · 躯干与视线是两条独立通道
**为什么：** 模型会把朝向和视线纠缠成一件事；分开写，等于强制它做两次独立决定，关系才成立（背对而视、身体朝她眼睛看门）。
**失效表现：** 一转身眼睛也跟着甩走；对话时人物不看着对手；"背对镜头"结果脸转了过来。
**说：** 躯干朝窗；眼睛始终锁在她身上；台词落完，头才转。 [译]

### T-03-09 · 七事实写全一个主体
**为什么：** 走位句只有在"屏幕位置 / 世界位置 / 距离 / 面向 / 视线 / 移动方向 / 前中后层"都齐了才算完整；缺一项，模型就补一个默认值 [推断：由缺项后的实际输出归纳]。
**失效表现：** 只写了"他在左边"，结果他在前景还是后景每镜不同；同一个人一会儿在前景一会儿在背景。
**说：** 画面左 · 前景 · 离门 1 米 · 躯干朝画面右 · 视线朝窗 · 不移动。 [译]

### T-03-10 · 每张参考图只"拥有"它能拥有的
**为什么：** 把职责写死，参考图之间就不会越权；也能让 agent 检查"这份参考是不是用错了地方"。
**失效表现：** 用地点图管人脸；用风格图管镜头角度；用道具图管光线；参考图越多，画面越乱。
**说：** 身份＝脸/身体/年龄/比例/服装/独特锚点；地点＝建筑/材质/地理/氛围/地标/光向；道具＝形状/尺度/材质/手部接触/状态；载具＝型号/涂装/车牌/车门/位置/运动/损伤/反射。

### T-03-11 · 用世界地标定机位，不用画面左右
**为什么：** 画面词（`lower-left`、`receding right`）会被模型镜像——它分不清"人物的左"和"观众的左"。世界地标不会：`at the FAR END of the bar, away from the entrance`、`from HIS RIGHT-front`。
**失效表现：** 左右反了；镜头跑到人物另一侧；同一条街上两个镜头的方向相反；枪口/亮门把机位吸过去。
**说：** 机位在吧台最里端、远离入口，从他右前方看 —— 右肩离镜头最近。镜头绝不越到他左侧。 [译]

### T-03-12 · 一条提示只允许一个地点 TAG；地点太宽就声明"只出现这部分"
**为什么：** 两个地点参考会互相拉几何——模型会取错的那一个，把整条街、整面墙拉进画面。
**失效表现：** 场景里出现本不该有的走廊/外墙/栏杆；两个镜头的同一房间布局不同。
**说：** 本段只出现该地点的[某一部分]入画 —— 画面里每一面墙都属于[地点]。 [译]

### T-03-13 · 两个人长得像＝空间灾难，先发「谁是谁」
**为什么：** 同类角色同框是模型最弱的区域；它会把两张脸、两套衣服混成一套。解法是提前把差异做成可见事实，而不是事后祈祷。
**失效表现：** 打斗中两人换脸；A 的衣服穿到 B 身上；两人融合成一个身影。
**说：** 谁是谁：@A 是画面左那个穿浅色派克大衣的高个；@B 是画面右那个穿深色派克大衣的矮个。两人绝不混、绝不换。 [译]

### T-03-14 · 密度分配：控制点写密，其余写薄
**为什么：** 提示的总信息量有限；把词花在身份、走位、开场状态、视线、光向上，剩下的让风格块统一处理，模型才有余量执行你的约束 [推断]。
**失效表现：** 背景细节写了五行，主角的站位只有一句；画面精致但关系全错。
**说：** 高密度区：`身份锚点 · 空间走位 · 开场状态（t=0）· 视线 · 光向`；低密度区：背景陈设、天气修辞、形容词堆。 [译]

### T-03-15 · 空镜不免费：开场就该携带空间信息
**为什么：** 空镜是模型的默认答案，不是叙事选择；只有被明确要求时才写，而且第一个瞬间就必须讲清"我们在哪"。
**失效表现：** 每条提示都从天空/远山开始；剪辑点全是空镜；观众永远不知道人在哪。
**说：** 开场那一刻就带着空间信息：一个看得见的地标、一种材质、一个 t=0 的距离。 [译]

### T-03-16 · 隐藏的部分要写进每一个区块
**为什么：** 只在一处写"脸不露"，模型会在别的区块把脸补回来——每个区块都是一次独立的生成指令。
**失效表现：** 该藏的脸在反打里出现了；该在画外的动作被拍全；手伸进画面变成了整条胳膊。
**说：** 不露脸 —— 只给手与小臂，每个区块都这么写。脸永不入画。 [译]

## 速查表

### T-03-17 · 空间地理写到 900 字：靠点名，不靠形容词
**为什么：** 900 字不是形容词堆出来的，是"点名"堆出来的——每件家具、每个距离、每一条影子方向都是一个可渲染、可检查的事实；把这些事实写满，字数自然到 900。
**失效表现：** 只写"一个房间，有人站在桌边"，模型自己发明房间，第二镜就换了一张房间；家具位置每镜不同；影子朝两个方向。
**说：** `空间地理：院子十二米见方；花亭在画面右三分之一、离新娘四米；座椅三排、最近一排离走道一米二；落日从画面右后方低角度来，桌椅影子朝画面左前方拉长；机位留在走道左侧这一条轴线上；左右一律以摄影机为准。`

### T-03-18 · 参考图写到 1,500 字：每张图 1–3 句，说清它管什么
**为什么：** 参考图这一节中位 1,552 字，是整条里第二重的一块。它不是"把图挂上去"，而是逐图声明它管哪一部分事实：6 张图 × 每张约 250 字，加起来就是 1,500 字。
**失效表现：** 只写"已上传参考图 1–3"，年龄、身高、衣物湿透程度全靠模型猜；同一角色两镜之间发型长度不同、大衣干湿不同。
**说：** `参考图 2（人物）：45 岁、身高一米八二、肩宽体壮；短寸头被雨打湿后贴在额角；深灰羊毛大衣吸水后颜色变深、左肩压出一道褶；右手提着黑色帆布包。这张图提供身份与服装状态；机位与构图由本镜决定。`

**地点平面图（九项，写走位前必须齐）**

| 项 | 写法 |
|---|---|
| 机位 | 世界地标 + 从人物哪一侧看 |
| 朝向 | 镜头看向什么（不是"朝左"） |
| 前 / 中 / 后景 | 每层各一个可见物件 |
| 地标位置 | 主地标 1–2 个，可用作距离锚 |
| 人物位置 | 屏幕位 + 世界位（贴着什么） |
| 移动路径 | 从哪到哪，经过什么 |
| 光向 | 源在哪、从哪侧来、色温一致 |
| 纵深关系 | 谁挡谁、谁在前景形成遮挡 |

**一人七事实（缺一项就会被模型补默认值）**

`屏幕位置 · 世界位置 · 与地标/他人距离 · 躯干面向 · 视线方向 · 移动方向 · 前中后层`

**弱词 → 强词**

| 弱（分布） | 强（约束） |
|---|---|
| near / around / beside | `within 1 meter` · `touching` |
| somewhere / in the area | `back against the wall` · `hand on the door handle` |
| nearby | `standing directly under the sign` · `boots inside the root circle` |
| 画面左右 | `his right-front` · `the far end, away from the entrance` |

**开场状态锁（逐字块，需要时整段粘贴）**

```text
开场状态（t=0）：所有主体已就位、已在场；之后不再有人入画。
t=0 时空间关系就已可读：谁在哪、朝着什么、手上拿着什么。
```

**参考职责（谁管什么）**

| 参考类型 | 拥有 | 绝不拥有 |
|---|---|---|
| 身份 | 脸、身体、年龄、比例、服装、独特锚点 | 机位、构图 |
| 地点 | 建筑、材质、地理、氛围、地标、光向 | 机位、取景、构图（除非明确要求） |
| 道具 | 形状、尺度、材质、手部接触、状态 | 光线、构图 |
| 载具 | 型号、涂装、车牌、车门、位置、运动、损伤、反射 | 机位 |
| 风格 | 质感、影调、颗粒、调色 | 身份、走位、动作、光学、光 |


### T-03-19 · 参考分四层，每层只控自己那几项
**为什么：** 参考图不是"一张全能的图"，它**只在自己的层级内说话**。把层级分清，才能既保住身份与几何、又允许机位自由；分不清就会出现"地点板把机位也定了""风格板把脸也改了"。
**失效表现：** 地点参考一连用了三四条，每个机位都跟板子的构图一样；换一张风格参考，人物的脸跟着变；道具在手里，但形状每镜不一样。
**说：** 按这张表分层使用参考——

| 参考层级 | 它控制的（只这一列） | 它不控制的 |
|---|---|---|
| **身份参考** | 脸、身体、年龄、比例、服装、独特锚点 | 构图、机位高度、光向 |
| **地点参考** | 建筑、材质、地理、氛围、地标、（相关时的）光照方向 | **机位角度、取景、裁切** |
| **道具参考** | 形状、尺度、材质、手部接触、状态 | 摆在画面哪里、被谁拿 |
| **载具参考** | 型号、贴花、车牌、车门、位置、运动、损伤、反射 | 机位与运镜 |

两条优先级要写死：**地点参考不覆盖所需的机位角度**（除非用户明确要求从板子的角度拍）；**风格参考不覆盖身份、空间走位、动作、光学与光照**。

## 自检（本模块相关）

**`空间地理` 薄 100 字 → 厚 400 字（同一场草坪婚礼）**

```text
薄（约 100 字）：空间地理：午后草坪婚礼。新娘站在花亭下，入口在左侧，宾客席在中景。
```

```text
厚（约 400 字）：空间地理：院子十二米见方、前后将近九米深，草坪被踩出两条浅道。
花亭立在画面右三分之一、离新娘四米，四根立柱，白纱从顶棚垂到地面。
宾客座椅三排，共四十八把木椅；最近一排离走道一米二，最后一排贴着院墙。
入口在画面左侧、院门内侧，门帘被风吹起一角；香槟桌在画面左前角，桌布垂到草上。
落日从画面右后方低角度进来，所有影子朝画面左前方拉长，花亭的影子横过走道。
摄影机站在走道左侧、与花亭同一轴线，全天只用这一个轴线；左右一律以摄影机为准。
纵深分三层：前景香槟桌与两只倒扣的杯子，中景走道与座椅，背景花亭与院墙。
地面是修剪过的草坪，靠近花亭处被踩秃了一小块；院墙是旧红砖，墙头爬着常春藤。
```

- [ ] 地点参考只用于地理；本镜机位是**写出来的**，不是继承的
- [ ] 走位前有平面图；九项齐
- [ ] 每个重要主体写全七事实；距离可丈量
- [ ] 躯干与视线分别写了；需要时加了"不会跨到另一侧"的锁
- [ ] 开场状态已写死：t=0 时该在场的人与物都已到位
- [ ] 一条提示只有一个地点 TAG；地点过宽时声明了"只出现这部分"
- [ ] 身份用最小锚点 + `100% matches the reference`，没有与参考竞争的长段描写
- [ ] 机位/朝向用世界地标表述，没有裸露的画面左右
- [ ] 隐藏的脸或动作被写进了每一个区块
- [ ] 两个相似角色有「谁是谁」声明与 t=0 即可辨的差异

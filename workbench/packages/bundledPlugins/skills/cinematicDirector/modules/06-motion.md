# 06 · 运动 —— 物理、动作、时间

## 这个模块解决什么

模型不知道质量，除非你把质量翻译成运动：接触、惯性、延迟、反作用、地面压力。于是默认画面会飘、会滑、会瞬移、会像游戏引擎。本模块给出一份可勾的物理清单、步态/武器/液体/粒子的机制分表、时间块写法，以及"动作在时长内做不做得完"的可行性检查。

**`物理` 是 640 字的一节，不是一句"要真实"。它是全包最容易写空的一节。** 实测中位 **640 字**（p25 398 / p75 1,029），占全篇 5.2%——这一节是一整段**逐材质的行为清单**，写成一句话就等于把这一节让给模型的默认值。

**何时加载：** driver=action；跑跳打、摔倒、搬运、车辆、液体、火、烟、雪、雨；risk=liquid/fire、crowds；任何"动作很飘/很假/像 CG"的返工。
**不加载：** 静态肖像、纯对话且人物基本不动、纯空镜。

## 提示

### T-06-01 · 动作必须有因果
**为什么：** 每个动作都要有施力者、受力者与反作用；写出这条链，模型才会把动作接在重力上而不是接在随机数上。
**失效表现：** 人物起跳没有蹬地；被推的人后退但推的人没前倾；物体自己移动。
**说：** `他靴子蹬住路缘，重心先向前转移，然后人才离地。[译]`

### T-06-02 · 重量要看得见
**为什么：** 质量感来自加减速与跟随，不是来自"很重"这个词。
**失效表现：** 钢管像塑料；箱子提起来像气球；倒地没有惯性。
**说：** `钢管有可见的重量：手臂先加速它，手腕再接住这一记停住。[译]`

### T-06-03 · 接触点必须写明
**为什么：** 手在哪儿、脚踩哪儿、物体靠哪儿，是可渲染的几何；不写，模型会自己发明一个不成立的接触。
**失效表现：** 手穿模、悬空、握在刀刃上；脚离地半寸还在走。
**说：** `右手在门把手上，左掌平贴门框，两只靴子都在根部圆圈内。[译]`

### T-06-04 · 走路五拍
**为什么：** 走路是最容易暴露"假"的动作；五拍给模型一条可执行的时间链。
**失效表现：** 滑步、上下颠、脚不打弯、像在传送带上。
**说：** `脚跟触地 → 重量转移 → 髋部移动 → 前掌蹬地 → 身体沉降。`

### T-06-05 · 跑步不能飘
**为什么：** CG 跑的通病是脚不着地、手臂不反向、步幅均匀；写实跑有明确的反向与变化。
**失效表现：** 人在飘、腿在空转；两臂同向摆；每一步力度一样。
**说：** `真实触地、抬膝、反向摆臂、躯干前倾、步幅变化，每一步都把身体重量压在接触点上。[译]`

### T-06-06 · 武器有重量
**为什么：** 武器是质量的极端情况；不写惯性，动作会在姿势之间瞬移。
**失效表现：** 刀在姿势之间跳；手腕角度不变；挥动没有加速与减速。
**说：** `手臂承担可见重量，手腕角度随质量转动，动作有加速与减速；刀身每一刻都接在上一刻的挥动轨迹上。[译]`

### T-06-07 · 液体要有黏度
**为什么：** 血、泥、水、汗的差别是流变学差别；只写"有血"会得到贴图。
**失效表现：** 血像油漆均匀覆盖；水滴走直线；湿过的地方是干的。
**说：** `血会附着、滴落、涂抹、积聚、染色；血滴走抛物线；湿过的接触面留下可见残痕。[译]`

### T-06-08 · 粒子顺风，分三层
**为什么：** 大气颗粒若只在背景，画面就没有纵深；若方向不统一，风就不存在。
**失效表现：** 雪往两个方向落；烟只在远处；火没有热浪。
**说：** `粒子顺风向运动，分布在前景、中景、背景三层；热空气与冷空气交界处产生热浪扭曲。[译]`

### T-06-09 · 时间块写法
**为什么：** 显式时间分区会约束潜空间的时间轴，避免几拍动作被压进一拍。
**失效表现：** 该三秒完成的动作两秒结束、剩下一秒空转；或几个动作粘在一起。
**说：** `0:00–0:03 他走到门前。0:03–0:06 他听。0:06–0:09 他推开门。[译]`

### T-06-10 · 一块只做一件事
**为什么：** 一个时间块塞两个互相矛盾的动作，模型会把它们平均成一个不成立的动作。
**失效表现：** 边后退边前进；边坐下边站起；手同时开门又关门。
**说：** `一个时间块只做一个动作，运动朝一个方向连续推进。[译]`

### T-06-11 · 可行性：时长内做不做得完
**为什么：** 单镜连续镜头里，动作必须真的能在时长内发生；写不下就等于要求模型快进。
**失效表现：** 八秒里塞了二十秒的动作，最后全片都在赶。
**说：** `本镜里的一切都能在可用的 8 秒内物理发生。[译]`

### T-06-12 · 落地要有反作用
**为什么：** 地面压力与缓冲是"真的落地"的唯一证据；没有它，人像被粘在空中。
**失效表现：** 跳下落地不弯膝；重物放下没有下沉；脚步没有声音感（视觉上）。
**说：** `落地先弯膝，重量沉进地面再起身。[译]`

### T-06-13 · 布料与头发有延迟
**为什么：** 跟随动作（follow-through）是质量的二级证据；布料和头发永远晚半拍。
**失效表现：** 大衣和动作完全同步；湿头发像头盔；转身时衣角不飞。
**说：** `布料与头发比身体晚半拍，然后回落。[译]`

### T-06-14 · 车辆有质量
**为什么：** 车是唯一会把"惯性"写满整个画面的物体；悬挂、转向、刹车距离都是可写的。
**失效表现：** 车像贴图平移；刹车瞬间停住；转弯没有侧倾。
**说：** `车的质量体现在悬挂下沉、缓慢的车身侧倾和刹车距离上。[译]`

### T-06-15 · 用状态块代替过程
**为什么：** 模型拍不好过渡、拍得好状态；把过程拆成 2–3 个"已经在中途"的状态，比写完整动作链稳。
**失效表现：** 想要"把枪从腰后拔出"，得到手在腰上摸索、枪没出来。
**说：** `已经是拔枪中段：枪已离开腰带，枪口正在抬起。[译]`

### T-06-16 · 变速要明说
**为什么：** 实时与慢动作是两种完全不同的运动学；不声明，模型会自己选，通常选错。
**失效表现：** 该慢的爆发变成实时；该实时的走路变成升格。
**说：** `全程实时。` / `只在冲击瞬间用 40% 慢动作。[译]`

### T-06-17 · 动物人群先按三件套近似 —— 本包未覆盖
**为什么：** 源技能文件只给了"人群反应成波"与物理清单，没有动物运动学；把它当作已知规则会误导。
**失效表现：** 动物四足步态错、人群各自为政或完全同步。
**说：** 先按 T-06-01/02/03 的因果-重量-接触三件套近似，人群另见 02 的 T-02-18。**此项为已知缺口，标 UNKNOWN，需实测补。**

### T-06-18 · `物理` 必须逐材质写行为
**为什么：** `物理` 这一节中位 **640 字**（p25 398 / p75 1,029，占全篇 5.2%），写的是**每种材质各自的运动行为**；只写"重力真实、质感厚重"，这一节就只剩一句话，等于空着。
**失效表现：** 全篇只有"真实物理"四个字；湿衣服飘、湿头发甩、水花像贴图、椅子被压没有形变；上一镜滚走的罐子下一镜回到原位。
**说：** `湿布料粘着皮肤、拖、坠着走；干布料翻动、鼓起、回落。湿头发一缕缕慢慢剥离、慢半拍；干头发随动、回弹。水挂在表面、聚成股、滴落，砸进水面立起水冠、散出水环、留下湿痕。金属受压弯下去、松手回弹、余震一次。木头受压微微形变、叫一声轻响。鞋底咬着地面、手掌压进物件、身体把家具压出形变并留下痕迹。[译]`（逐材质的完整查表见下方「材质 → 行为查表」）

### T-06-19 · 千字物理不如一句"行为"
**为什么：** 约束采样的是**机制**，不是形容词——"重力真实"是观感描述，"湿帽衫粘着身体拖、坠着走"是机制描述，后者能被执行，前者只能被猜。640 字是一串行为句堆出来的，不是一段形容词。
**失效表现：** 通篇"真实、厚重、有重量感"，出来一个物理上不成立、却"看起来厚重"的动作。
**说：** `湿帽衫粘着身体、拖、坠着走，褶皱积在手肘和腰侧；湿头发一缕缕慢慢剥离、慢半拍，发梢拖在水面上。[译]`

## 速查表

**物理清单（写出得越多，飘的概率越低）**

| 组 | 要写的量 |
|---|---|
| 基本 | 重力 · 质量 · 惯性 · 摩擦 |
| 接触 | 接触点 · 地面压力 · 碰撞 · 反作用 |
| 传递 | 重量转移 · 跟随（布料/头发延迟） |
| 流体 | 液体流向 · 血液黏度 · 湿润残留 |
| 环境 | 积雪累积 · 热浪扭曲 · 风对粒子的方向 |
| 机械 | 车门铰链阻力 · 武器重量 · 车辆质量 |

**机制速查**

| 动作 | 必须包含 |
|---|---|
| 走 | 脚跟触地 → 重量转移 → 髋部移动 → 前掌蹬地 → 身体沉降 |
| 跑 | 真实触地 · 抬膝 · 反向摆臂 · 躯干前倾 · 步幅变化 |
| 持械 | 手臂承担重量 · 手腕随质量转动 · 加速与减速 · 轨迹连续 |
| 液体 | 附着/滴落/涂抹/积聚/染色 · 抛物线 · 湿痕 · 黏度与方向 |
| 粒子 | 顺风 · 前中后景 · 累积 · 冷热交界的热浪 |

**薄（约 60 字）→ 厚（约 640 字）对照 —— 同一件事，两种写法**

薄：
```text
白纱拖尾在草地上有摩擦；沙面被拖出一道浅痕。风先动纱、再动发丝、最后动衣角，三段依次落下。
```

厚（逐材质，十八条相加约 640 字；每条都可单独粘进 `物理`）：
```text
白纱拖尾扫过白沙：纤维先挂住草茎、再一根根松开，沙面留下一道被拖出的压痕，边缘的沙塌落回填，压痕留到下一镜还在。花瓣下落慢于重力直觉、带横向漂浮，落地只塌一次，边缘向上卷起，被鞋底踩到就贴着带走。旧木椅受压时榫卯先叫一声轻响，椅面往下弯两指、木纹绷紧，人起身后回弹到原形、余震一次，椅脚在木地板上蹭出半步。汗从鬓角一线下来，绕过颧骨停在下颌，聚成一颗、挂住、再掉，滴在衣领上洇开一片深色。风分三段传导：先动纱，半拍后动发丝，再半拍后动衣角。水被靴子踩开时立起水冠、散出水环，退下去留下湿痕，湿痕边缘慢慢变暗。金属手环在腕上滑动、撞到桌沿停住，桌面留下一个浅坑，余震让它又跳了半下。雪落在她肩上先积成一层，被人一碰就整块塌下去，靴底把雪压实成一片灰白。烟从她嘴边吐出、先向下扑，再被热气流托起，绕过肩线散开。血从伤口一侧渗出、沿下颌线走到下巴尖、挂住，滴进锁骨的凹陷，颜色由亮转暗。湿斗篷的下摆甩起来带着水珠，水珠沿切线飞出去，在墙面上留下放射状的小点。玻璃杯被推倒、沿桌面滚出弧线、停在桌沿，杯底的水在桌上画出半圈。门铰链被推开时先涩住、再突然松开，门板回弹一次撞在墙上，墙灰落下一点。火舌被风压低了半寸、又窜回来，热浪把上方的空气推得发抖，灰烬往上飘。湿靴子踩上岸边的碎石，碎石在靴底翻转、挤开旁边的石子、留下一个鞋跟印。他呼出的白气先聚成一团、再被风扯成横向的一条，三秒后散尽。她停下时布料还在动：先斗篷、再发梢、最后手里的布条，三段依次落定。罐子滚到哪就还在哪，水渍还在，被压弯的椅背还是弯的。
```

**时间块模板（逐字可用）**

```text
0:00–0:03  [主体位置] [动作] / [运镜行为] / [道具状态]
0:03–0:06  …
0:06–0:09  …
一个时间块只做一个动作。一切都能在可用时长内物理发生。
```

## 自检（本模块相关）

- [ ] 每个动作都能说出施力者、受力者与反作用
- [ ] 有一个以上的接触点是写明的（手、脚、物体靠点）
- [ ] 位移类动作写了步态或轮式机制，不是"他走过去"
- [ ] 液体/火/烟/雪写了方向、层次与残留
- [ ] 有时间块，且每块只有一个动作
- [ ] 动作总量在时长内做得完
- [ ] 变速（实时/慢动作）已声明
- [ ] 动物或人群镜头：已标记为 UNKNOWN，并退回因果-重量-接触三件套近似
- [ ] `物理` 是**逐材质**写的吗？（湿/干布料、湿/干头发、水、金属、木、三类接触各一条）
- [ ] 这次动作的**后果留到下一镜**了吗？（罐子滚到哪就还在哪）
- [ ] 成稿里还有否定句吗？（"不要/不许/无…"一律改写成正面状态）

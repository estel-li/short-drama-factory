# 04 · OPTICS —— 镜头即结果

## 这个模块解决什么

模型不认识"85mm""f/1.4""Cooke S4"这类器材元数据，它认识的是**看得见的画面结果**：背景被压平、只有眼睛是实焦、前景是黑色虚化块。同时它对相机与人之间的**物理距离**极其敏感——只给视角不给距离，机器会自己走过去，压缩感就没了。本模块给出内容→视角的决策、六档 FOV（视角）的距离配方、结果短语配额、反阻尼锁（anti-drift lock）与运镜写法。

**何时加载：** 需要选景别或视角；risk=faces/hands（广角畸变、长焦压缩）；driver=action（宽/长切换）；单镜构图；任何"镜头味不对"的返工。
**不加载：** 纯对白配乐蒙太奇但已指定固定中景时；纯图像资产（走 10）。

## 提示

### T-04-01 · 镜头写成看得见的结果
**为什么：** 训练语料里"背景被压平、只有主体是实焦"这类描述和画面强相关，而"85mm、T2.0"只是弱相关的标签。
**失效表现：** 写了全套器材参数，出来仍是手机中景；或者视角对了但景深完全不对。
**说：** 主体背后的背景压平、焦点锐利地落在眼睛上、其余全部化进柔焦。 [译]

### T-04-02 · 一镜一类 —— 每颗镜头只承载一种内容类型
**为什么：** 人脸特写、环境地理、微距细节同时出现时，模型会把镜头平均到"安全的中间值"，即镜头漂移（lens drift）。
**失效表现：** 该宽的变得中庸、该长的没有压缩；一个镜头里既想看清脸又想看清全城。
**说：** 本镜只有一种内容类型：肖像。 [译]

### T-04-03 · FOV 必须配相机距离
**为什么：** 视角只决定画面范围，距离决定透视、身体比例与遮挡；同一视角配不同距离是两个完全不同的镜头。
**失效表现：** 写了"29° 特写"但没写距离，相机走进人物脸上，压缩感消失。
**说：** `全片统一一颗镜头：50mm等效、47°对角视场的标准变形宽银幕镜头 —— 景别差异只靠机位物理远近。`（语料 `red-flag#52`）

### T-04-04 · 用长焦够到，不要走过去
**为什么：** "近"是距离词，会指挥相机移动；长焦的近距离感来自焦段而不是脚步。
**失效表现：** 越写"紧""近"，人物越大越广，背景越清楚。
**说：** 靠焦段够到近景，不靠身体靠近；相机留在远处。 [译]

### T-04-05 · 长焦必须有前景遮挡
**为什么：** 8° 超长焦的说服力来自前景虚化块，没有它，超长焦只会读成"模糊的长镜头"。
**失效表现：** 主体是实的、背景是糊的，但画面很平，没有"远距离观察"的感觉。
**说：** 必须带前景遮挡：虚化的前景物体占画面下方 30–45%，成为大块暗虚化。 [译]

### T-04-06 · 广角靠身体进画
**为什么：** 广角的空间扩张来自"相机贴着前景身体"，不是来自"更广"。
**失效表现：** 广角拍出来像标准镜；环境没有包住人；边缘没有透视夸张。
**说：** 84° 对角线视角，相机距主体 1–1.5 米，前景身体更大更近，环境顶到画框边。 [译]

### T-04-07 · 每镜锁一个 FOV
**为什么：** 漂移之所以发生，是因为提示里没有任何一句话禁止镜内重新构图。
**失效表现：** 同一条镜头从半身慢慢变成全身，再变成大远景。
**说：** `段内与段间不允许焦段漂移。`（语料 `red-flag#52`）

### T-04-08 · 只在镜间换 FOV
**为什么：** 视角变化必须是剪辑事件；镜内平滑变焦会被读成"AI 在找构图"。
**失效表现：** 镜内缓慢推拉变广；两个镜头之间的视角变化没有硬切承接。
**说：** 镜头性格只在硬切处变；镜内不许平滑变焦。 [译]

### T-04-09 · 不要用景别当镜头指令
**为什么：** "wide shot""establishing shot"是剪辑概念，不是光学概念；模型会把它们当作"画面要空"的信号。
**失效表现：** 想要广角压场，结果得到一张没有人味的空景；人物被推得很远。
**说：** 用 `84° … 距 1–1.5 米` 代替 `wide shot`；用 `107° … 距 0.5–0.8 米` 代替 `establishing shot`。

### T-04-10 · 复合运镜要带坐标，无坐标的叠加不写
**为什么：** 一个镜头里推+摇+升，模型会把三个动作平均成一个不成立的运镜。但只要**给出主轴与两端的坐标**（起始高度、终止高度、起始位置、终止位置），复合运动反而比单一运动更能锁住画面——因为两端都是可核对的量。
**失效表现：** ① 画面同时推进又在横移，最后停在谁也说不清的位置（**没给坐标**的典型症状）；② 起终点都写清了，画面仍然沿一条可复述的轨迹移动（**这是正常的**，不要误判）。
**说：** 没坐标时——`相机只从门口到桌子。`；有坐标时——`航拍视角从雪山天际线缓慢下摇至雪原，相机从 15 米高度下降至 5 米，最终停在人物后方的低角度。`

> **判据只有一条：这条运动能不能用"从哪到哪"复述出来。** 能，就写复合；不能，就砍回一个主轴。

### T-04-11 · 相机是操作员，不是参数
**为什么：** 物理化描述（机位高度、站位、离人多远、谁挡谁）比"电影感构图"更能约束画面。
**失效表现：** 构图随机翻转；机位高度每次不同；光从哪边来和相机在哪边对不上。
**说：** 机位固定在阴影侧的腰高，主体占画面左三分之一，画面右留空。 [译]

### T-04-12 · 手持是呼吸，不是抖动
**为什么：** 真实手持是肩扛质量 + 呼吸 + 微修正；"random shake / digital jitter"只会得到电子噪点式抖动。
**失效表现：** 画面像被风扇吹；或者要手持却给出了云台般的顺滑。
**说：** `每段锁定景别的固定机位，只有手持呼吸感。`（语料 `red-flag#1`）

### T-04-13 · 结果短语有配额（长焦 ≥4 / 广角 ≥3）
**为什么：** 单一结果短语可能被忽略，四条互相印证的短语才会把镜头推向同一侧。
**失效表现：** 只写了"背景虚化"，结果背景依然清晰；只写了"广"，画面并不贴人。
**说：** `前景肩部奶油般虚化，背景砖墙/框匾/红灯柔焦；浅景深。`（语料 `cully-hill-boys#77`）

### T-04-14 · 反阻尼锁写在镜内
**为什么：** 锁写在同一段提示里才和"这一镜"绑定；写进全局负向块是弱偏置。
**失效表现：** 前三秒对，后五秒自己变广；同一个提示换个种子就漂。
**说：** 本镜的任何部分都不变成广角或标准镜覆盖；更宽的取景靠相机退远、保持同一长焦，而不是换镜头。 [译]

### T-04-15 · 微距与广角分开成镜
**为什么：** 细节与环境是两类内容，硬塞进同一拍只会两败；细节要单独给一个插入镜。
**失效表现：** 想要"环境里的一枚弹壳"，得到一张既看不清弹壳也不像环境的中间景。
**说：** 插入镜：18° …… 薄焦只保弹壳。 [译]

### T-04-16 · 47° 只用于"无风格"
**为什么：** 47° 是模型的舒适中间值，也是它漂移的默认归宿；只有当你确实需要"中性人眼感"时才指定它。
**失效表现：** 每条提示都写 47°，成片没有镜头性格；或该长焦的地方被 47° 悄悄替换。
**说：** 47° 对角线视角，自然人眼透视，零明显畸变。 [译]

## 速查表

**六档视角（完整结果短语与逐字块见 `banks/A-optics-bank.md`）**

| FOV（视角） | 相机距离 | 用于 | 一句话结果 | 坑 |
|---|---|---|---|---|
| 47° 标准 | 3–5 m | 纪实感、中性叙事 | 自然人眼、零畸变、背景可读不夸张 | 模型的默认舒适值，容易变成没性格 |
| 84° 经典广角 | 1–1.5 m | 贴身人物+环境、环境动作 | 前景身体变大变近、环境顶到画框边、直线不变形 | 脸会变形；别和长焦内容混拍 |
| 107° 广角矫正 | 0.5–0.8 m | 大尺度地理、沉浸 | 前景压过来、边缘仍有直线、边缘轻微色散 | 绝不能拍脸 |
| 29° 短长焦 | 4–6 m | 中景肖像 | 靠焦段拉近、脸型稳、背景开始压缩 | 不写距离就会被走近 |
| 18° 长焦 | 6–8 m | 情绪特写、压缩式窥视 | 背景强烈压缩、薄焦只保眼睛、被远观感 | 没有眼睛锚点会显得平 |
| 8° 超长焦 | 20–25 m | 观察、狗仔、野生动物 | 背景压成色块、只有主体实焦、前景遮挡 | 不写前景遮挡就只是模糊长镜 |

**内容 → 视角**

| 内容 | 视角 |
|---|---|
| 脸部肖像、环境仍可见 | 84° |
| 中景肖像 | 29° |
| 紧的情绪特写 | 18° |
| 远距离观察 | 8°（+前景遮挡+大气霾） |
| 纪实动作 | 47° |
| 广域环境动作 | 84° |
| 大尺度地理 | 107° |
| 细节、微距 | 29°/18°，自成插入镜 |

**四条反阻尼锁（anti-drift lock，逐字可用）**

```text
长焦：本镜的任何部分都不变成广角或标准镜覆盖。更宽的取景靠相机退远、保持同一长焦，
不靠换镜头。每一帧背景都保持压缩、保持化开。

广角：本镜的任何部分都不变成长焦肖像覆盖。环境始终在主体四周可见，相机始终贴近，
画面始终保持广角的透视扩张与可读纵深。

标准：不要极广畸变、不要长焦压缩。画面保持自然、落地、人眼中性。

多镜：全段镜头＝X°，不可协商。每镜开头写：镜头锁 SHOT A = X°。
每镜结尾写：镜头校验 SHOT A：X° 保持，无漂移。
```

**镜头禁区（写了会掉进模型的错误先验）**

| 别写 | 改写成 |
|---|---|
| extreme / ultra / super wide-angle lens | 84° 或 107° + 距离 |
| wide shot / establishing shot 当镜头指令 | 视角 + 距离 + 画面结果 |
| tight wide framing | 二者选一 |
| zoom out + wide-angle | 单一运镜主轴 |
| f-stop / ISO / 镜头品牌当主控 | 可见结果短语（静态资产见模块 10） |
| 同一镜里复合运镜 | 从 A 到 B 一条主轴 |
| 只写负向镜头控制（"不要长焦"） | 先写想要的视角，再加一句镜内锁 |

## 自检（本模块相关）

- [ ] 这一镜只有一种内容类型，且写在提示里
- [ ] 给了 FOV，并且给了相机到主体的米数
- [ ] 长焦镜头有前景遮挡；广角镜头有身体贴机位
- [ ] 长焦结果短语 ≥4 条，广角结果短语 ≥3 条
- [ ] 有一条镜内反阻尼锁
- [ ] 没有出现景别词（wide / establishing）当镜头指令
- [ ] 运镜只有一条主轴，没有复合动作
- [ ] 多镜序列里每镜自带 `镜头锁`，只在硬切处换视角

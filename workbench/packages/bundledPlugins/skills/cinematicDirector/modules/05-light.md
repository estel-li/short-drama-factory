# 05 · 光照 —— 照明合同

## 这个模块解决什么

光不是风格装饰，而是优先级约束：曝光决定肤色、材质、剪影和视线落点。如果光写在风格形容词之后，模型会退回它最擅长的默认值——均匀、平、亮、无阴影。本模块把光写成一份可检查的合同（谁亮、谁暗、相机站哪边、为什么曝光），并给出逆光配方、变平后的升级句、以及调色比例的写法。

**深度基线：`光照` 是 450 字的一节，不是一句话。** 实测中位 451 字（p25 303 / p75 625），占全文 3.7%；这 450 字来自把下面七件事一件件答完。

**何时加载：** 夜戏、火光、雨雪、窗光、单一实用光源；genre=horror（低调/逆光）；画面"太平、太亮、太均匀"；risk=liquid/fire（高光与质感）；任何需要剪影或轮廓的主镜。本模块的逆光配方（contre-jour）是整套光法里最可复用的一条。
**不加载：** 需要正面平光的证件/产品图（走模块 10）；完全依赖参考图光照且不作调整的插入镜。

## 提示

### T-05-01 · 光是约束不是滤镜
**为什么：** 曝光一旦确定，后面的肤色、材质、剪影都被它锁死；把它写成"电影感光线"等于没写。
**失效表现：** 每个镜头都像棚拍补过光；同一场戏里光向每镜不同。
**说：** `本镜的光照是硬性约束，不是风格选择。` [译]

### T-05-02 · 逆光就为逆光曝光
**为什么：** 模型有强烈的补光先验（把脸照亮、把细节留全）；只要不明确指定曝光优先级，它就会自动给脸补光。
**失效表现：** 想要剪影，结果脸被照亮；背景过曝但人脸很平。
**说：** `全镜为逆光曝光，不为脸曝光；剪影与轮廓线扛住整个画面。` [译]

### T-05-03 · 说出暗面
**为什么：** "相机在暗侧、光在远侧"是可检查的几何事实，"戏剧性打光"不是。
**失效表现：** 相机和光源在同一边；该有轮廓光的一侧是平的。
**说：** `机位始终在 @HERO 的暗侧；晨光来自画面右后方、他身体的侧面。` [译]

### T-05-04 · 脸可以掉进阴影
**为什么：** 深阴影不是错误，是选择；把"允许脸黑"写出来，模型才敢压曝光。
**失效表现：** 暗部被提亮成灰；脸部细节过全，失去神秘与危险感。
**说：** `除非明确提亮，脸一直落在深阴影里；只有轮廓光、边缘光、湿面反光、眼神光与环境反弹能显出细节。` [译]

### T-05-05 · 平光是最常见的失败
**为什么：** 平光不是"中性"，是模型的安全解；一旦画面变平，下次生成必须显式升级。
**失效表现：** 每个镜头都均匀亮；没有一处真正的黑；人物像贴上去的。
**说：** `不打正面主光、不做平光曝光、不做美颜补光、未要求不加棚灯。` [译]

### T-05-06 · 对比度写比例
**为什么：** "2:1""4:1"是可执行的比值；"高对比"只是形容词。
**失效表现：** 明暗差别随机，有时几乎无差；同一个场景两镜对比度不一致。
**说：** `单一顶光主光，柔和 2:1 光比，平滑衰减。` [译]

### T-05-07 · 光源方向与色温要具体
**为什么：** 方向决定阴影走向与剪影形状，色温决定是清晨、正午还是钠灯；两者都必须落成可指认的事实。
**失效表现：** 阴影朝两个方向；雨戏用了正午色温；火光却是冷白。
**说：** `画面右侧一道低角度硬阳光，3200K，影子向画面左侧横过院子。` [译]

### T-05-08 · 列出允许的高光
**为什么：** 高光是画面里唯一"亮到溢出"的东西；不指定，模型会把高光铺满全画面（湿、油、CG 亮）。
**失效表现：** 全身油亮；水面、金属、皮肤都在发光；没有真正的暗。
**说：** `只允许这些高光：湿路缘、钢管边缘、一次眼神光。` [译]

### T-05-09 · 调色比例从参考里推
**为什么：** 60/30/10 是可命中的目标；但比例必须来自用户指令、场景或上传参考，自己编会和资产打架。
**失效表现：** 调色与参考图两张皮；每个镜头主色都不一样。
**说：** `· 色：60%暖赭、30%深炭黑、10%锈红。` [译]

### T-05-10 · 静态资产用器材词，运动镜头用结果词
**为什么：** 两条车道的语言不同：图片模型用胶片/机身/镜头品牌锚定"质感登记"，视频模型对器材词不敏感、对画面结果敏感。
**失效表现：** 把 `ARRI Alexa LF, Cooke S4, T2.0` 写进 Seedance 提示 → 无效果；把"背景压平"写进图片提示 → 质感不对。
**说：** 视频：`背景压平压缩、一层柔和暖色调罩住画面。` [译] / 图片：`Photorealistic ARRI Alexa LF anamorphic Cooke S4 lens at T2.0, organic 35mm Kodak Vision3 250D film grain.`（器材串，按型号原名保留）

### T-05-11 · 别和模型自带质感打架
**为什么：** 某些图像模型原生自带胶片颗粒与质感；再叠三行颗粒词只会过曝质感，不会更"电影"。
**失效表现：** 颗粒重到像噪点；画面脏而不是厚。
**说：** `柔和的电影感衰减，极细颗粒。` [译]（一行登记即可；模型差异见 `banks/D-block-orders.md` 的日期表）

### T-05-12 · 一场一光向
**为什么：** 光是连续的物理事实；跨镜换方向，观众会认为时间或地点变了。
**失效表现：** 正反打里两人脸上的光来自相反方向，却没有动机；剪到一起像两个片场。
**说：** `本场每个镜头同一光向，含反打。` [译]

### T-05-13 · 亮度层级：背景亮、人暗
**为什么：** 观众先看最亮处；把背景压在人物之上（或之下）是最省事的注意力控制。
**失效表现：** 人物比背景亮，画面没有纵深；或者人物和背景一样亮，粘在一起。
**说：** `窗户是画面里最亮的东西；人物在它前面读作一团暗形。` [译]

### T-05-14 · 禁止清单只留真正会犯的
**为什么：** 负向词会注入概念；只保留模型真正常犯的四个（平光、补光、棚灯、CG 亮），并写在正向规则旁边。
**失效表现：** 一大段"不要过曝不要死黑不要脏"——既没用，又把这些词喂给模型。
**说：** `不要平正光、不要美颜补光、不要棚灯主光、不要 CG 亮面。` [译]

## 速查表

### T-05-15 · 450 字的光照要问完七件事
**为什么：** 光照一节的中位是 451 字——它是一整段，不是一句"黄昏、逆光、氛围感"。这 450 字来自把七件事一件件答完，而不是把形容词写长。
**失效表现：** 只写"黄昏、逆光、很暖"，出来是平光加一层橙；脸比背景亮；高光铺满全画面；同一场戏两个镜头的色温对不上。
**说：** `源：唯一主光是低角度落日，在画面右后方；另有一盏柔光灯在画外左侧，只作眼底一档提亮。色温 3400K，阴影侧天光 6800K。机位在暗侧。曝光给背景高光与纱边的透光。允许的高光只有：湿草上的一道亮、纱边透光、眼底一点光、发丝金边。`

| # | 要问的事 | 写成什么 |
|---|---|---|
| 1 | 源 | 几盏、什么灯、画内还是画外 |
| 2 | 色温 | 数字：`3400K` / `5200K` / `6800K` |
| 3 | 方向 | 从画面哪一侧来、仰角多少、影子朝哪 |
| 4 | 摄影机在明侧还是暗侧 | "机位在暗侧"这一句决定剪影成立 |
| 5 | 曝光优先给谁 | 背景高光、脸、还是轮廓线 |
| 6 | 允许的高光清单 | 只允许这四处：…（正面列举） |
| 7 | 每个失效的正面替代 | 脸留阴影 / 环境反弹当补光 / 光源全在画内 / 高光只落在真实湿面 |

**照明合同：每镜必写 8 项**

| 字段 | 例子 |
|---|---|
| 主光源 | 单一低角度落日 / 单只顶灯 / 窗光 |
| 光的方向 | 从相机右侧来，略偏后 |
| 相机与光的关系 | 相机在暗侧 |
| 主体的明暗面 | 面向相机的一侧全暗，肩线有轮廓光 |
| 背景亮度 | 天空是画面最亮处 |
| 曝光优先级 | 为逆光曝光，不为脸曝光 |
| 允许的高光 | 湿路缘、钢管边缘、一次眼神光 |
| 禁止的失败 | 平光、补光、棚灯、CG 亮 |

**逆光配方（逐字可用；语料无中文原文，[译]）**

```text
主体始终夹在摄影机与更亮的背景之间。摄影机保持在主体的暗侧。
除非明确提亮，脸一直落在深阴影里。只有轮廓光、边缘光、湿面反光、
眼神光与环境反弹能显出细节。不打正面主光、不做平光曝光、
不做美颜补光、未要求不加棚灯。
```

**画面变平后的升级句（逐字可用；[译]）**

```text
全镜为逆光曝光，不为脸曝光。允许脸沉进压死的阴影。
剪影与轮廓线扛住整个画面。
```

**调色比例模板（[译]）**

```text
克制的低饱和调色：以 [冷色/主色] 为主，[暖色元素] 是唯一的暖对比，
深压死的黑位，克制写实的调色，柔和低对比，强烈的电影式明暗对照。
60% [色相]，30% [色相]，10% [色相]。
```

**“光太平”的三种修法**

| 症状 | 加这一句 |
|---|---|
| 脸被补亮 | 为逆光曝光，允许脸进阴影 |
| 没有方向 | 单一主光源 + 从相机某侧来 |
| 全是高光 | 只允许列举的四处高光，其余压暗 |

## 自检（本模块相关）

**`光照` 薄 70 字 → 厚 450 字（黄昏草坪婚礼的逆光）**

```text
薄（约 70 字）：光照：唯一光源是落日，低角度、在画面右后方；逆光让白纱透亮、发丝出细光，脸留在阴影里、只靠轮廓读出来。
```

```text
厚（约 450 字）：光照：黄昏草坪婚礼，逆光。
源：唯一主光是落日，仰角约 8°、在画面右后方；另有一盏柔光灯在画外左侧，强度约为主光的八分之一，只作眼底一档提亮，不参与造型。
色温：主光 3400K，阴影侧天光 6800K；同一条手臂上能看见两种色温的过渡。
方向与影子：光从画面右后方低角度进来，影子朝画面左前方拉长、横过草坪；白纱的褶把影子切成细条。
摄影机：机位在人物暗侧、画面左侧，全天留在走道左侧这一条轴线上；每一镜的人物都是逆光剪影。
曝光优先：为背景高光与雾状轮廓曝光，脸靠最后四分之一档的自然回光读出，允许沉入压死的阴影。
允许的高光（只有这四处）：草坪上一道被压过的湿亮、纱边的透光边缘、眼底一点光、发丝与草梢的金边；画面其余部分留在暗部。
光的正面状态：脸留在阴影里，只有轮廓光与地面反弹揭示细节；皮肤保留本身的油光与瑕疵；所有光都来自画面里看得见的光源；高光只落在真实的湿面与金属边缘。
```

- [ ] 8 个字段都写了，尤其是曝光优先级与相机站哪边
- [ ] 至少有一句"允许的阴影/允许的黑"
- [ ] 高光是列举出来的，不是全画面
- [ ] 调色有比例，且比例来自参考或场景设定
- [ ] 视频镜头没有把机身/镜头品牌当主控；图片资产才用器材词
- [ ] 同一场戏的每个镜头（含反打）光向一致
- [ ] 没有把负向禁令写成一大段清单
- [ ] 色温是数字（如 3400K / 6800K）吗？有一份"允许的高光清单"吗？

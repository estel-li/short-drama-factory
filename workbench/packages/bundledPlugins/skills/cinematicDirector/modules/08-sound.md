# 08 · 声音 —— 对白、有源声与配乐

## 这个模块解决什么

声音是本套技能里**最薄**的一环：源技能文件关于声音只有约 40 行——对白纪律、几个时间数字、一条"前情音频"技巧，其余（配乐设计、混音、音效层、对口型、多语）都没有。本模块把能用的部分全部留下并压成可执行规则，同时在最后一节把缺口**显式列出**，让你知道哪些地方不能假装有答案。

**`音频` 是 480 字的一节——而且它是 12/12 部片都写的唯一块，最不该省。** 实测中位 **483 字**（p25 318 / p75 769，占全篇 4.0%）：底噪 + 一串带时间点的声事件 + 远近层次，写成"有环境声"一句话就等于没写。

**何时加载：** driver=dialogue；任何有台词的镜头；需要静默或呼吸感的戏；有源声（diegetic sound）与配乐（score）需要分开的镜头；risk=conlang/accents。
**不加载：** 纯音乐蒙太奇（尚无可靠规则，见缺口表）；纯环境空镜。

## 提示

### T-08-01 · 只念脚本里的那句
**为什么：** 模型会自由加词、加语气词、加人名；多出来的每句话都要在剪辑里修掉。
**失效表现：** 出现台词本上没有的"嘿""等等"；角色自己叫出同伴名字。
**说：** `只念引号里的那句台词，逐字照脚本；台词之外的时刻只有呼吸与空间声。[译]`

### T-08-02 · 非说话时嘴唇静止
**为什么：** 模型倾向于让所有角色都在"微动嘴"，读起来像配音错位。
**失效表现：** 听的人嘴也在动；没有人说话时嘴唇仍在开合。
**说：** `嘴唇随台词开合，台词之间闭合；其他角色安静地听。[译]`

### T-08-03 · 默认只有现场声与图像
**为什么：** 配乐、字幕、旁白是模型最容易自作主张加的三样；写成正面状态，成片才只有画面与现场声。
**失效表现：** 画面出现英文字幕；情绪戏自带钢琴；出现解说音。
**说：** `画面填满整个画幅，只有图像内容；声音只有现场声与画内人声。[译]`

### T-08-04 · 立即开口：0.3 秒内起句
**为什么：** 需要在镜头开头就说话的戏，若不指定，模型会把台词塞到中段，前半秒变默片。
**失效表现：** 前两秒只有动作，台词被压到后段，句子被截断。
**说：** `这句台词在镜头开始后的 0.3 秒内起句。[译]`

### T-08-05 · 呼吸感：前后各 ≥1 秒静默
**为什么：** 情绪重量常来自台词前后的静默；不给数字，模型会把台词前后都填满声音。
**失效表现：** 台词紧贴镜头边界；说完立刻切走，没有余韵。
**说：** `台词前后各留至少 1 秒静默。[译]`

### T-08-06 · 台词清楚：环境声在台词下让路
**为什么：** 雨、风、机器声会和台词抢频段；不写让路（ducking），成片听不清词。
**失效表现：** 台词被雨声掩埋；需要重录或后期降噪。
**说：** `环境声在台词下让路；人声贴耳、干净、情绪受控。[译]`

### T-08-07 · 前情只用音频，不进画面
**为什么：** 上一场的话常需要作为情绪上下文，但一旦写成文字描述，模型会把它画出来（出现不在场的人）。
**失效表现：** 画面里出现上一场的人物或物件；台词被当作画面指令。
**说：** `前情只走音频：画外传来「我告诉过你别回来。」，画面留在当下的空间。[译]`

### T-08-08 · 音色锁定：逐字粘贴，绝不逐场改
**为什么：** 观众靠音色认人；每个镜头微调一次 Voice 段，长片里就会像换了三次演员。
**失效表现：** 同一角色在三场戏里音高、口音、语速不同。
**说：** 见模块 02 的「音色公式」，整段原样粘进音频/声音字段。

### T-08-09 · 情绪靠更轻，不靠更响
**为什么：** 最有威慑力的台词是说得最轻的一句；压低音量会让全场凑近。
**失效表现：** 每场高潮都在吼；越到后面越吵，情绪反而没层次。
**说：** `事情越严重，他的声音越轻、越贴近耳语。[译]`

### T-08-10 · 台词后不要立刻复位
**为什么：** 状态有惯性；说完就"恢复正常"会让整场像演完收工。
**失效表现：** 说完重话立刻微笑；被击中后一秒就恢复。
**说：** `说完他还留在那句话里：呼吸仍然短，下颌仍然绷着。[译]`

### T-08-11 · 有源声与配乐分开写
**为什么：** 有源声（画面里的收音机、雨、脚步）属于物理世界，配乐属于剪辑层；混在一起写，模型会二选一。
**失效表现：** 想要画内收音机，结果得到全片配乐；想要配乐，结果只有环境声。
**说：** `声音只有现场声：屋里的收音机、屋顶的雨、碎石上的靴子。[译]`

### T-08-12 · 对白长度要配得上时长
**为什么：** 一段台词塞进过短的镜头，模型会加速或截断；过长的镜头里，台词说完后人物会空转。
**失效表现：** 句子被砍半；或说完后两秒无事发生。
**说：** 先估句子秒数（**词速在源文件中没有给出，标 UNKNOWN**），再用 T-08-05 的静默补足；宁可拆成两镜。

### T-08-13 · 抢话可以，关键词要干净
**为什么：** 真实对话里句子会互相踩尾，但关键词不能被盖住；完全整齐的轮流说话像广播剧。
**失效表现：** 每人说完整一句再换人，像念稿；或互相盖到听不清任何词。
**说：** `句子可以互相踩尾，但关键词必须干净。[译]`

### T-08-14 · 静默里必须有事发生
**为什么：** 停顿只有装进"评估、决定、拒绝回答"时才成立；否则是空洞的等待，观众会以为卡了。
**失效表现：** 几秒静默里两张脸都不动；停顿与情绪无关，像掉帧。
**说：** `这段静默是一次评估：他把回答咽回去，然后开口。[译]`

### T-08-15 · 声音连续性要跨镜登记
**为什么：** 画面有连续性清单，声音却常被漏掉；同一场景两镜环境声不同，剪起来像换地点。（源文件未设此条，属**推断**，与连续性清单同理。）
**失效表现：** 正反打里雨声忽大忽小、忽有忽无；室内镜突然有街声。
**说：** `本场每个镜头共用同一条环境声床。[译]`

### T-08-16 · `音频` 要写带秒数的声事件
**为什么：** `音频` 这一节中位 **483 字**（p25 318 / p75 769，占 4.0%），而且它覆盖 12/12 部片；真实提示词写的是"底噪 + 一串带时间点的声事件 + 远近层次"，只写"有环境声"就只剩一句，声音全交给模型的默认值。
**失效表现：** 全片一层底噪；该响的地方一片安静；声音与画面各走各的。
**说：** `底噪：日光灯电流、房间本身的低频。7.6s 远处金属刮擦；12.0s 布料摩擦；15.7s 一滴水砸进水面；21.4s 全片最响的一下。远近三层：远处走廊脚步、中景椅木轻响、贴身他的呼吸。声音只有现场声与画内人声。[译]`

### T-08-17 · 声音和画面共享一个时钟
**为什么：** 声事件的时间点必须和 `动作时间轴` 用同一个时钟；同一个秒数上画面也发生一件事，声画才会被听成同一件事，否则模型把两条时间轴各走各的。
**失效表现：** 滴水声在 15.7s，画面 18.2s 才落水；最响的一下落在没有动作的空白里。
**说：** `15.7s 一滴水砸进水面正中，同一秒水面立起水冠；21.4s 全片最响的一下，同一秒门被撞开、木屑飞出。[译]`

## 速查表

**对白时间数字（全部来自源技能文件，可直接用）**

| 需求 | 写法 |
|---|---|
| 立即开口 | 镜头开始 0.3 秒内起句 |
| 留白呼吸 | 台词前后各 ≥1 秒静默 |
| 台词清楚 | 环境声 duck 到台词之下 |
| 声音质地 | close, clean, emotionally controlled（贴耳、干净、情绪受控） |
| 前情 | 只走音频，绝不进画面 |

**音频正面清单（逐字可用；[译]）**

```text
只念引号里的那句台词，逐字照脚本。声音只有现场声：空间底噪、画内的人声、物件与身体的声。
嘴唇随台词开合，台词之间闭合。画面填满整个画幅，只有图像内容。
```

**声音三选一（先定层，再写句）**

| 这一镜需要 | 写什么（可粘贴） | 换成什么说法 |
|---|---|---|
| 只有物理世界的声音 | `声音只有现场声：屋里的收音机、屋顶的雨、碎石上的靴子。[译]` | 情绪形容词、乐器名 → 具体声源 |
| 只有静默与呼吸 | `只有呼吸与房间底噪。[译]` | "安静的""压抑的" → 具体声源 |
| 有台词 | 台词原文 + 0.3 s / ≥1 s + ducking | 字幕、旁白、背景音乐 → `画面填满整个画幅，只有图像内容。` |

**薄（60 字）→ 厚（480 字，六个时间点）对照**

薄（只有底噪）：
```text
环境声：雨声、室内底噪。
```

厚（六个时间点 + 三层 + 人声关系；整段可粘进 `音频`）：
```text
底噪：屋顶的雨落在瓦上一片细响，木屋结构的低频吱嘎，日光灯管的一线电流声，房间自己的空腔感，一只狗在远处叫了两声又停。0.8s 风把窗纸推响一下：纸面先鼓起来、再贴回去，接着是窗框的一记轻响。3.2s 远处马车碾过湿石：蹄铁在石面上磕出四声，一声比一声远，车轴跟一声闷响，缰绳抖了一下。7.6s 屋檐的水线断开：一串水砸在台阶石上，先散成一地碎响、再由散变实，水顺着石缝往下走。12.0s 他的湿外套在椅背上摩擦：布面粘住木头、被拉开，水从衣角滴到地板上，一声一声间隔变长。15.7s 一滴水从梁上落下、砸进桌面水洼正中：立起水冠、散出水环，水花落在纸面上洇开一小片。18.4s 火柴划响：硫黄先嘶一声、木头随后接上，火苗立起来时空气呼一下。21.4s 全片最响的一下：门被撞开，门板砸在墙上、木屑落在地板上，余震让桌上的杯子跳了一格。24.0s 楼上有一次挪椅子：木头在木地板上挪出半尺，然后停住；隔着两条街还有一记关门声，闷得只剩一个轮廓。收尾：所有声退到只剩雨和呼吸，那口气在喉间停半秒才吐出来。远近三层：远处街上的雨与人声、中景衣料与椅木、贴身他的呼吸。人声只走画内：他压低的一句「别开门」，说完只剩呼吸。声音只有现场声与画内人声。画面填满整个画幅，只有图像内容。
```

## 自检（本模块相关）

- [ ] 只出现脚本内的台词，没有多余词、没有画外人声
- [ ] 非说话角色嘴唇静止
- [ ] 字幕、旁白、配乐三件事都做了明确取舍（要或不要）
- [ ] 开头就说话的镜头写了 0.3 秒规则；需要余韵的写了 ≥1 秒静默
- [ ] 台词清楚：写了环境声让路
- [ ] 有前情台词时，写成"只走音频、不进画面"
- [ ] 有台词的角色的 Voice 段是逐字粘贴的；音色没有逐场改动
- [ ] 台词长度与镜头时长匹配；本模块未覆盖的部分已标 UNKNOWN，没有编规则
- [ ] `音频` 里有**带秒数的声事件**吗？（底噪 + 至少 3 个时间点 + 远/中/贴身三层）
- [ ] 这些时间点和 `动作时间轴` 对得上吗？（同一个秒数上画面也在发生同一件事）
- [ ] 成稿里还有否定句吗？（"无配乐/无旁白/无字幕"一律改写成正面状态）

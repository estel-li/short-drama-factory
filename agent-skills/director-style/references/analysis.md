# 参考片分析与证据

工厂输出的是供当前 AI 查看、试听和推理的材料，不在后台另接视觉或音频模型。先核对 source_sha256、选定 range、是否有 video/audio 通道和实际提取状态。prepared 只表示证据就绪；job done 不代表风格分析完成。

自动提取包括带原片绝对时间码的采样帧、总览图、像素变化候选切点、帧差、试听音轨和连续片段。采样量有上限，长片会增大间隔；候选切点可能由运动、闪光或曝光变化触发。音频 RMS/峰值只描述能量，不能据此填出配器、情绪、对白、音色或精确 BPM。

## 实际观察

- 美术与构图：查看不同场景、景别和明暗条件；记录色彩关系、材质、主体尺度、留白、前中后景，不以一帧代表全片。
- 摄影与动作：查看连续片段／密集时序帧，追踪主体位置、遮挡、摄像机变化和动作阶段。动作片拆开蓄力、发力、接触、受击和恢复，并观察空间方向能否连续读懂。
- 剪辑与特效：核对切口两侧、镜头时长分布和特效出现/结束时刻；判断是镜头内变化还是剪辑手段。区分经常使用的规则与只出现一次的情节效果。
- 声音：实际试听对应音轨或片段，记录对白、音乐、环境、动作音效和静默各自的作用；观察声音领先、同步或延后于画面。无法听音的工具应记录 audio coverage 为空，声音维度保持未分析。

工具不能播放动态视频时，可查看片段对应的密集时序总览；覆盖声明只限实际看过的范围，快速动作遗漏部分降低 confidence 并写限制。低帧率序列不能证明精确的接触时间、完整动作轨迹或语义音画同步。

## 写成可执行规则

每条规则包含：id、dimension、observation、guidance、when、avoid、basis、confidence、evidence。

例如“有力量感”缺少操作含义；可写成“发力前用较稳定的中景交代方向，接触处切至短近景，之后保留身体和环境反馈；仅在动作段使用”。不要硬编码未经测量的镜头毫米数、物理灯位或配方参数。

dimension 可取 visual、composition、camera、editing、action、effects、sound。basis 是 frames、motion 或 audio；声音必须有音频依据，动作/摄影/剪辑需要 motion 依据。evidence 和 coverage 都采用原片绝对秒数，不能混入提取片段从零开始的播放时间。

coverage 是作者声明的实际查看范围，不是程序自动证明看过。未分析的维度写入 limitations，不补全为假事实。规则应保留适用场景；使用 scene_patterns 将对白、打斗、回忆等场景映射到不同 rule id。

仿拍所需 shot_structure 是作者核对过的镜头顺序和功能，最多150镜。候选切点不能直接当成确认镜头。每镜写原片 start/end、purpose、framing、movement、action、transition、sound 和适用规则，按时间排序且不重叠。描述动作功能，替换剧情时不要依赖原片人物名或原句台词。

发布前复查规则是否能迁移到新人物与新故事，以及素材/模型不支持的部分是否明确。样例文件只演示字段，必须基于用户参考片重新填写。

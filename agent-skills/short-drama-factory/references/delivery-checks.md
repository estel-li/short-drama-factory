# 正式成片验收

按用户要的交付深度执行。普通预览保留项目、成片和已做检查；正式发布前覆盖以下三类证据。验收过程只读源视频，保存检查记录；没有能力执行的项目明确标为未验收。

## 完整媒体与接缝

读取 quality 中的媒体验收报告，核对实际宽高、帧数、音频、时间戳与所选版本。正式交付可对每个候选文件再完整解码；使用当前应用 Python 获取自带 FFmpeg 的真实路径：

```powershell
$ffmpeg = & $appPython -c "import imageio_ffmpeg; print(imageio_ffmpeg.get_ffmpeg_exe())"
& $ffmpeg -v error -xerror -i $candidateVideo -map '0:v:0' -map '0:a:0' -f null -
```

先把 appPython 和 candidateVideo 设为本次验证的绝对路径，检查退出码及 stderr；这一步不会生成视频。不能只用“文件非空”或只看第一帧证明全片完好。

使用成片版本的实际剪辑时间轴，检查每个切口的前后帧和短段播放。帧间差、黑帧检测只能筛选候选；硬切、换页、闪白本来就可能变化很大，需对应镜头设计。反过来，低帧差也不能证明没有重复帧或音频跳变。重点听句首句尾是否被截、音画是否同时切、前镜末帧接续是否自然。

## 台词／音频／字幕三方核对

以用户定稿原文为基准，同时核对生成音频、SRT/ASS 文字与烧录字幕画面。VAD 或音频包络仅给出声音活动，不识别每个字，也不能从嘈杂环境声直接反推每句台词的真实起点。精确的逐句核验需要试听、人工标注或另有可用的语音识别流程，不能声称工厂已经自带 ASR 验收。

记录错字、漏句、重复、说话人错误，以及字幕开始／结束相对**已核实话音**的偏差：字幕早出、晚出、提前消失、延迟消失分开报告；与事件或语气的关系也要查看。覆盖率说明检测方法和分母，100% 检测人声覆盖不代表台词正确或字幕可放行；明显提前会剧透或错挂说话人，也应修正。

只错字幕时间时，可修改分镜的 `dialogue_timings`（逐句 start/end，使用原镜头时间轴），保存完整 story 后执行 finish。正文台词没变时这属于后期字段，不应重生成 H3。改了实际要说的字则同步 prompt 并重生成，不能只换字幕掩盖旧音频。注释时间使用最终成片时间轴，改变剪辑后需重查。

## 文字页、遮罩、尾板（按需）

工厂内置字幕、注释、遮罩与后期版本；来源经验中的专用合成和尾板脚本不在本技能包内，也不是工厂接口。只有用户要求这些额外交付时才制作，明确输入、输出、工作目录和依赖。不能运行一个不存在的脚本或沿用它的默认旧项目路径。

文字页和源镜头做显式映射，最好保存 UID、原镜时间及成片时间，不把会顺延的镜号硬编码为永久身份。按版本新建输出目录，避免覆盖上一版。相同底色文字页之间优先预览硬切效果，叠化可能造成文字重影；不是所有切口都要加转场。

遮罩依据当前镜头、真实画幅和运动重新核对；旧版矩形不能盲套。来源的“制度板不模糊”只属于其项目约定，不成为本技能全局规则；遵循当前用户的保护／遮盖要求。

字体先检查简体字覆盖、实际字重、描边和缩小观看效果。密集汉字用过重字形叠加粗描边可能糊成块，但不一律禁用某种字体或字重。文字页逐档测量行宽、行数和占高，到最小可读字号仍装不下就分页／按授权精简，不能仅减少字号却不检查边界。

ASS 先读实际 PlayResX/PlayResY 与输出尺寸。工厂当前设置为实际画幅；不能套用固定的“960/288”倍率。近似脚本坐标缩放是输出高度/PlayResY，实际字形高度还受字体、ScaleY 和描边影响，以烧录样张为准。同时间多条字幕需要核对层级、定位和阅读顺序，不能靠文本行顺序推断最终布局。

## 依赖与交付记录

先用**实际运行应用的解释器**检查 `av`、`imageio_ffmpeg`、`numpy`、`onnxruntime` 等所需模块；不要按“系统 Python／便携 Python”名称推断安装情况。当前锁定依赖包含 numpy；旧包或不完整安装仍可能缺失。若所有原片完成、仅 finish 缺依赖，保留原片，按授权修复运行环境后重跑后期，不先重生成全片。

按用户要求交付实际存在的干净版／字幕版／额外尾板版，不固定到来源的 544×960。交付说明记录项目和版本 ID、原文版本、实际规格、文件及哈希、所做检查、未验证项和复现命令。台词本、Word 或 PDF 仅在要求时制作；调用相应文档能力并验证真实依赖，不把 python-docx 等加入本技能 HTTP 客户端的必需环境。

# 按素材与创作目标选择工作流

先查询 `sdf capabilities`，需要具体方案参数再读 `/api/video/workflows`、`/api/config` 的 profiles 或 `/api/images/models`。以当前实例返回的 ID、支持模式、必需槽位、采样约束和资源状态为准。本页只保留选择原则。

## 视频决策

| 必须实现的目标 | 工作流方向 | 不能混淆的边界 |
| --- | --- | --- |
| 指定配音必须保留 | `h3-audio-drive`，绑定 `source_audio` | 普通 Audio 参考不等于原声锁定；原声保留不保证精确口型 |
| 画面保持，只改声音 | `h3-foley`，绑定 `source_video` | 不能同时要求换人物、动作或画风 |
| 延续上一段动作与声音 | `h3-motion-context` | 使用一段上下文；只需上一镜实际末帧时用普通 I2VA 接续 |
| 按源视频轮廓换风格 | `h3-canny-control` | 轮廓约束不等于人物身份锁定 |
| 中途经过指定构图 | `h3-keyframe-guide` | 中段引导不是逐像素硬贴；仅首尾要求可用普通关键帧模式 |
| 常规创作与试镜 | 已就绪的原生或加速方案 | 不按名称／步数承诺质量、时间；先保留用户明确选择 |
| 提高新生成镜头尺寸 | `pdd-upscale` | 包含重新生成，不是现有 MP4 的通用无损放大 |

**mode** 决定文字、首尾帧或多模态输入；**profile/workflow** 决定采样、加速、锁音画或控制。`options.profile` 是项目级设置。混合不兼容工作流应分项目制作或采用用户接受的组合方式，不能假设逐镜填写 profile 会生效。

外部 AI 完整创作时默认 `auto_reference:false`，显式绑定需要的素材。自动提取角色参考可能改变后续实际模式和依赖范围；LightX2V、拟音、轮廓控制等兼容性必须查实例支持列表。不能因为输入不兼容而悄悄退回 T2VA。

## 时间与性能

用 `/api/duration-plan` 和执行计划的对齐帧数制定时间轴。H3 24fps、帧数 `17k+5`；4 秒请求实际 107 帧。4 秒／96 帧源片不能满足同等标称镜长的锁画面任务。

多帧接续还需计算上下文开销并去掉重复头部；短原声可能补静音。详细限制见 [高级媒体契约](h3-advanced.md)。遇到这些警告应说明它们对当前内容的影响。

优先复用合适且已就绪的方案。试镜规模依据用户需求与本机成功记录选择；显存、卸载、参考素材、帧数、冷加载共同影响耗时。未测量时报告未知，不套用另一台机器的耗时或功耗阈值。

## 图片决策

从 `/api/images/models` 查看 `reference_modes`、`max_reference_images`、`transparent_support` 与推荐采样参数。`image_model` 是生图模型；`provider/model` 是可选文字优化服务。

Qwen 多图语义参考与其他架构的单张原图 VAE 重绘是不同能力。需要多图身份融合、透明背景或指令编辑时，使用实际声明支持的模型；不丢弃用户多余参考图来勉强匹配。切换架构后由当前 AI 调整提示词，不默认再调用文字服务。

资源准备见 [模型与环境](workflow-models.md)，素材与图片操作见 [图片接口](images.md)。项目 MIT 许可证不代替模型权重的使用许可。
